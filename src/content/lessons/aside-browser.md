## 1. Aside는 무엇일까?


**Aside** 는 AI가 들어 있는 웹 브라우저예요. 크롬과 같은 바탕(크로미움)으로 만들어서 쓰는 법은 크롬과 비슷해요. 다른 점은 옆에 있는 AI에게 일을 시키면 **AI가 직접 사이트를 열고, 클릭하고, 입력해서 일을 끝낸다** 는 거예요.

| | 챗봇 (Claude · ChatGPT 대화창) | AI 브라우저 (Aside) |
| --- | --- | --- |
| 돌려주는 것 | **답** (글) | **끝낸 일** (표 · 파일 · 채운 양식) |
| 일하는 곳 | 대화창 안 | 내가 로그인한 웹사이트 · 내 컴퓨터 파일 |
| 잘하는 일 | 설명 · 초안 쓰기 | 여러 사이트 돌며 모으기 · 반복 클릭 · 다운로드 · 정리 |
| 조심할 것 | 사실 확인 | 사실 확인 + **AI가 한 행동** 확인 |

### Aside에게 일 시키는 네 가지 방법

![글자 고르기 → 사이드 패널 → 작업 → 루틴, 작은 일에서 큰 일·반복하는 일 순서](/images/aside-browser/four-ways.svg)

| 방법 | 여는 법 | 이럴 때 |
| --- | --- | --- |
| 글자 고르기 | 페이지에서 글자를 드래그 | 한 문단 요약 · 번역 |
| 사이드 패널 | **Ctrl + S** (맥은 ⌘ + S) | 지금 보고 있는 페이지로 일하기 |
| 작업 (Task) | 새 탭의 **Ask AI** · **Ctrl + Shift + E** | 여러 사이트·파일을 오가는 일 |
| 루틴 | 📍 Settings › Routines | 매주·매일 정해진 때 저절로 |

### 요금 한눈에

| 요금제 | 값 | 들어 있는 것 |
| --- | --- | --- |
| Free | 0원 | 월 **500크레딧**, 루틴 3개, 비밀번호 금고, 메모리 |
| Pro | 월 20달러 | 무료의 3배, **Ultrabrowse**(깊은 조사), 루틴 무제한 |
| Max | 월 200달러 | 무료의 40배 |

> 📌 **Claude나 ChatGPT 구독을 연결** 하면 그 모델로 일할 때는 그 구독의 사용량을 써요. Aside 크레딧은 Aside가 주는 모델을 쓸 때 줄어요. 무료 크레딧은 매달 1일(세계 표준시)에 다시 채워져요.

## 2. 다 같이 설치하고 안전하게 설정하기

### ✋ 실습① 설치 · AI 연결 · 안전 설정 (25분)

**설치와 시작**

1. `aside.com/download` 에서 내 컴퓨터에 맞는 설치 파일을 받아 설치해요. (윈도우는 x64 / ARM64 중 고르기)
2. Aside를 열고 **계정을 만들거나 로그인** 해요.
3. **브라우저 데이터 가져오기**: 크롬의 방문 기록 · 쿠키 · 북마크를 가져올 수 있어요. 쿠키를 가져오면 로그인 상태도 함께 넘어와서, AI가 그 계정으로 들어갈 수 있어요.
4. **비밀번호 금고(Aside Vault)** 를 설정해요.
5. 첫 작업을 시작할 수 있는 화면이 나오면 설치 끝.

> ⚠ 연수용·공용 노트북이라면 **브라우저 데이터 가져오기는 하지 않는 편이 안전해요.** 내 노트북이라도 업무 계정이 로그인된 프로필은 가져오기 전에 한 번 더 생각해요.

**AI 연결하기**

📍 Settings › Models › Providers › Connect

![Settings의 Models 화면: ①연결된 Claude 구독 ②기본 모델 ③일 종류별 모델](/images/aside-browser/models-marked.jpg)

1. **Connect** 를 누르고 **Subscription** 아래에서 쓰는 구독을 골라요.
   - `Claude Subscription` — Claude Pro 또는 Max
   - `ChatGPT Subscription` — Codex를 쓸 수 있는 ChatGPT 구독(Plus · Pro · Business)
2. 뜨는 창에서 로그인하고 허용하면, Providers 목록에 ① 처럼 **Subscription** 으로 보여요.
3. 구독이 없으면 그대로 두어요. 맨 위 **Aside (Free)** 로 무료 크레딧을 써요.

아래 **Task models** 는 일의 종류마다 쓸 모델이에요. 처음에는 그대로 두면 돼요.

| 칸 | 하는 일 | 예 (위 화면) |
| --- | --- | --- |
| ② Default model | 새 작업의 기본 모델 (마지막에 쓴 모델이 기본이 돼요) | Opus |
| ③ Fast | 곁일 · 요약 · 메모리 정리 | Haiku |
| Standard | 하위 작업 · 메모리 다시 정리 | Sonnet |
| Deep | 어려운 판단 · 계획 · 종합 | Opus |
| Visual | 그림 · 화면 · CAPTCHA 읽기 | Sonnet |

**안전 설정 먼저 (3분이면 돼요)**

![작업 권한, 비밀번호 금고, 승인 기다리기의 세 겹 안전장치와 사람의 약속](/images/aside-browser/safety-layers.svg)

1. **작업 권한** — 📍 Settings › Agents 아래쪽 권한 칸. 새 작업의 기본값은 **Guard** 예요. 정해 준 폴더에서만 일하고 다른 폴더는 물어봐요. 그대로 둬요.
2. **비밀번호를 AI가 쓸 수 있는 때** — 📍 Settings › Passwords › Access policy for AI agents → **While unlocked**(금고가 열려 있을 때만) 또는 **Never**.
3. **메모리 보관 기간** — 📍 Settings › Memory › Configure → **30 days**.

<!-- 📸 캡처 예정: C02 권한 화면, C03 비밀번호 정책, C04 메모리 설정 -->

> 📌 Aside 비밀번호 금고는 비밀번호를 **웹사이트 칸에 직접 채워 줄 뿐, AI에게 보여 주지 않아요.** 그래도 은행·나이스처럼 중요한 사이트의 비밀번호는 금고에 넣지 않는 걸 권해요.

## 3. 가벼운 기능부터

### ✋ 실습② 글자 고르기 · 사이드 패널 · 탭 나란히 (15분)

**① 글자 골라 요약·번역**

영어로 된 기사에서 한 문단을 드래그하면 작은 메뉴에 **Summarize**(요약) · **Translate**(번역) 가 떠요. 누르면 바로 결과가 나와요.

📍 Settings › Lasso 에서 나만의 단축 메뉴를 더할 수 있어요. `{text}` 자리에 고른 글자가 들어가요.

```prompt 단축 메뉴: 4학년 눈높이로 풀기
아래 글을 초등학교 4학년이 이해할 수 있는 쉬운 말로 3문장 이내로 풀어 줘. 어려운 낱말은 괄호 안에 뜻을 붙여 줘.

{text}
```

**② 사이드 패널 — 지금 보는 페이지로 일하기**

1. 교육청 누리집의 **공지사항 목록** 을 열어요.
2. **Ctrl + S** (맥은 ⌘ + S)로 사이드 패널을 열어요. 위쪽에 지금 페이지가 **붙어 있는지** (페이지 제목·주소) 확인해요.
3. 아래처럼 써서 보내요.

```prompt 사이드 패널: 공지 → 연수 일정 표
이 페이지의 공지 중 교원 연수와 관련된 것만 골라서
제목 · 게시일 · 신청 마감일을 표로 정리해 줘. 마감일이 없으면 '없음'이라고 써 줘.
```

<!-- 📸 캡처 예정: C07 페이지가 붙은 사이드 패널, C08 결과 표 -->

> 💡 붙은 페이지를 빼면 페이지 없이 새로 시작해요. 쓰다 만 글은 그 탭에 저장되어 있다가 다시 돌아오면 남아 있어요.

**③ 탭 나란히 보기**

**Ctrl + Shift + \\** (맥은 ⌘ + Shift + \\)를 누르면 두 페이지가 나란히 떠요. 자료 페이지와 입력할 양식을 같이 볼 때, AI가 일하는 페이지를 지켜볼 때 좋아요.

| 단축키 | 하는 일 |
| --- | --- |
| Ctrl + S | 사이드바 열고 닫기 |
| Ctrl + E | Ask Aside (바로 묻기) |
| Ctrl + Shift + E | 새 작업 |
| Ctrl + Shift + \\ | 탭 나란히 |
| Ctrl + Shift + T | 닫은 탭 다시 열기 |

## 4. 작업 맡기기

### 일 잘 시키는 문장

![일 잘 시키는 문장 = 어디서 + 무엇을 + 어떤 모양 + 멈출 곳](/images/aside-browser/task-sentence.svg)

- **어디서**: 사이트 이름이나 주소, 파일·폴더
- **무엇을**: 찾을 정보, 할 일
- **어떤 모양**: 표 · 엑셀 · 5줄 요약 · 출처 주소
- **멈출 곳**: "예약 신청은 하지 마", "보내기 전에 멈춰"

> ⚠ "일 좀 처리해 줘"처럼 막연하면 엉뚱한 사이트로 가요. 돈 · 개인정보 · 보내기 · 신청이 걸린 일은 **멈출 곳** 을 꼭 적어요.

### 작업 창의 고르는 칸

| 칸 | 고를 것 |
| --- | --- |
| 모드 | **Default** (평소 브라우저) / **Incognito** (로그인·기록 없이) |
| 권한 | **Read only** (보기만) / **Guard** (기본: 정한 폴더만) / **Full access** (컴퓨터 전체) |
| 작업 폴더 | 파일을 다룰 폴더 하나 |
| 모델 | 일의 크기에 맞게 (Pro는 **Ultrabrowse** 로 깊은 조사) |

### ✋ 실습③ 체험학습 장소 비교표 — 여러 사이트 조사 (15분)


1. 새 작업(**Ctrl + Shift + E**)을 열어요.
2. 아래 문장을 붙여 넣고 보내요.
3. AI가 사이트를 찾고 돌아다니는 과정을 지켜봐요.
4. 완성된 표에서 **확인한 페이지** 주소를 눌러 한두 개만 직접 확인해요.

```prompt 작업: 체험학습 장소 비교
초등학교 4학년 현장체험학습 장소를 비교하려고 해.
국립경주박물관, 국립대구박물관, 국립중앙과학관 누리집에서
단체 관람 운영 시간, 관람료(초등학생 단체), 예약 방법, 휴관일을 찾아서 표로 정리해 줘.
각 정보를 찾은 페이지 주소도 함께 적어 줘. 예약 신청은 하지 말고 정보만 모아 줘.
```

![작업 화면: ①보낸 요청 ②일하는 시간 ③찾아본 페이지 목록](/images/aside-browser/task-running-marked.jpg)

- ① 보낸 요청이 오른쪽에 보여요.
- ② **Working for 30s** 처럼 일한 시간이 보이고, 누르면 과정을 펼쳐 볼 수 있어요.
- ③ 어떤 말로 검색했고 어떤 페이지를 열었는지 그대로 보여요.

**일하는 도중에 바로잡기**

작업이 도는 동안에도 말을 보낼 수 있어요.

```prompt 작업 중 한 줄 바로잡기
관람료는 무료인지 유료인지만 짧게 적어 줘.
```

![일하는 도중 ①바로잡는 말을 보내자 ②AI가 다시 생각하는 화면](/images/aside-browser/steer-marked.jpg)

📍 Settings › Agents › Chat 에서 도중에 보낸 말을 어떻게 받을지 정해요.

| 방식 | 하는 일 | 이럴 때 |
| --- | --- | --- |
| **Steer** | 지금 하는 일에 바로 반영 | 방향을 당장 바꿔야 할 때 ("그 사이트 말고 이 사이트") |
| **Queue** | 지금 일이 끝난 뒤에 반영 | 하던 일은 마치고 덧붙일 때 |

**결과 — 실제로 받은 표 (일부)**

## 5. 반복 일은 루틴, 기억은 메모리

### ✋ 실습⑤ 월요일 아침 공지 요약 루틴 (10분)


**루틴** 은 정해 둔 때에 Aside가 저절로 일하는 기능이에요.

| 종류 | 하는 일 |
| --- | --- |
| 일정 루틴 (cron) | 정한 시각마다 **새 작업** 을 시작해요. 예: 매주 월요일 아침 요약 |
| 이어하기 루틴 (heartbeat) | 정한 때에 **같은 대화를 깨워** 이어서 해요 |

1. 📍 Settings › Routines → 새 루틴을 누르면 **Create routine** 창이 떠요.
2. **Title**: 알아보기 쉬운 이름 — 예: `월요일 공지 요약`
3. **Prompt**: 아래 지시문을 붙여 넣어요.
4. **Repeat** `Weekly` · **On** `Monday` · **Time** `8:00 AM` 으로 일정을 정해요.
5. **Model**: 요약 정도는 가벼운 모델(예: Sonnet)이면 충분해요. **Notifications** 를 켜 두면 끝났을 때 알려 줘요.
6. **Create** 로 만들고, 목록에서 **Run now(지금 실행)** 로 한 번 돌려 결과를 확인해요.

```prompt 루틴: 월요일 아침 공지 요약
경상북도교육청 누리집 공지사항에서 지난 7일 동안 올라온 글 가운데
초등 교원 연수 · 공모 · 행사 안내만 골라
제목, 마감일, 링크를 5줄 이내로 요약해 줘.
```

<!-- 📸 캡처 예정: C17 루틴 목록, C18 Create routine 창(받음·파일 다시 받기), C19 실행 결과 -->

- **루틴 추천받기**: 루틴 목록에서 **Find routine suggestions** 를 누르면 Aside가 내가 자주 하는 일을 찾아 루틴 초안을 만들어 줘요. 고쳐서 **Activate**.
- 무료 요금제는 루틴 **3개** 까지 켜 둘 수 있어요.

> ⚠ 루틴은 **내 컴퓨터가 켜져 있고 Aside가 실행 중일 때만** 돌아가요. 노트북을 덮어 두면 그 시간 루틴은 건너뛰어요.

> 📌 대화를 **Delete(삭제)** 하면 그 대화가 만든 루틴도 함께 지워져요. 루틴을 남기려면 **Archive(보관)** 를 써요.

### 메모리 — Aside가 기억하는 것


Aside는 작업이 끝날 때마다 중요한 것(사람, 기관, 결정, 잘 되던 사이트 경로)을 **메모리** 에 적어 두고 다음 작업에 써요. 그래서 같은 설명을 매번 하지 않아도 돼요.

📍 Settings › Memory

- **Overview**: 기억한 내용을 보고 **직접 고쳐요.** 틀린 내용은 지워요.
- **History**: 언제 무엇을 기억했는지 바뀐 기록
- **Configure**: 메모리 켜기·끄기, 보관 기간(**Never forget · 30 days · 90 days**)

<!-- 📸 캡처 예정: C20 메모리 Overview -->

> 📌 메모리와 작업 기록은 **내 컴퓨터** 에 저장돼요(다른 컴퓨터로 옮겨지지 않아요). Aside는 기본적으로 내 기록·파일·비밀번호를 AI 학습에 쓰지 않는다고 안내해요.

## 6. 안전하게 쓰기


- **학교 행정 시스템은 맡기지 않아요.** 나이스 · 업무포털(K-에듀파인) · 은행 · 결제 사이트에 로그인한 채로 일을 시키지 않아요.
- **학생 정보가 보이는 화면에서 쓰지 않아요.** AI가 그 화면을 읽어요.
- **멈출 곳을 적고, 승인 화면은 읽고 눌러요.** 보내기 · 게시 · 결제 · 신청은 작업이 멈추고 승인을 기다려요. 무엇을 하려는지 읽고 눌러요.
- **AI가 모은 정보는 다시 확인해요.** 날짜 · 금액 · 연락처는 원래 페이지에서 확인해요.
- **페이지 속 '숨은 지시'를 조심해요.** 웹페이지나 메일 속에 AI를 속이려는 글이 숨어 있을 수 있어요. 모르는 사이트·메일을 열어 둔 채 큰일을 맡기지 않아요.
- **권한은 좁게.** 평소에는 **Guard**, 파일이 필요 없으면 **Read only**. **Full access** 는 쓰지 않아요.
- **공용 컴퓨터라면 지우고 나와요.** 📍 Settings › Security & Privacy › Delete browsing history, 그리고 작업 대화는 **Delete**.
- **크레딧 확인**: 📍 Settings › Plan & Usage 에서 남은 크레딧과 작업별 사용량을 봐요. 큰 모델·긴 대화일수록 많이 써요.

### 승인 화면 미리 보기 (해 보기)

```prompt 보내기 전에 멈추기 연습
내 메일에서 새 메일 쓰기를 열고, 받는 사람은 비워 둔 채
제목 '테스트', 내용 '안녕하세요'까지만 써 줘. 보내기 전에 멈춰.
```

## 7. 심화 — 클로드 코드와 연결하기


Aside에는 **명령어 도구(CLI)** 와 **MCP 연결** 이 있어서, 클로드 코드가 Aside에게 브라우저 일을 시킬 수 있어요. "파일 일은 클로드 코드, 웹 일은 Aside"를 한 대화에서 이어 하는 거예요.

1. 📍 Settings › Developers 에서 **Aside CLI** 를 설치해요.
2. 터미널에서 바로 시켜 볼 수 있어요.

```bash
aside "국립경주박물관 누리집에서 이번 달 휴관일을 찾아 줘"
```

3. 클로드 코드에 Aside를 연결해요. (터미널에서 한 번만)

```bash
claude mcp add aside -- aside mcp
```

4. 클로드 코드에게 이렇게 시켜요.

```prompt 심화: 클로드 코드 → Aside
Aside로 국립경주박물관, 국립대구박물관 누리집에서 단체 관람 예약 방법을 찾아 줘.
찾은 내용을 이 폴더에 '체험학습_비교.md' 파일로 정리하고, 출처 주소도 적어 줘. 예약은 하지 마.
```

> 📌 클로드 코드는 「AI 에이전트로 학교 업무 자동화하기」 교안에서 자세히 다뤄요.
