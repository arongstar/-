## 1. 왜 '수업 웹앱'일까?

디지털·AI 수업을 하다 보면 퀴즈 사이트, 패들렛, 투표 도구, 체험 사이트를 오가느라 **로그인과 링크 안내에 시간을 많이 써요.** 수업 웹앱은 이 모든 활동을 **주소 하나**에 모아요.

| | 여러 도구를 오가는 수업 | 수업 웹앱 하나로 |
| --- | --- | --- |
| 입장 | 도구마다 링크·코드·가입 | QR 한 번, 닉네임만 |
| 진도 | 학생마다 다른 화면 | 교사가 '지금 미션' 알림, 앞서가기 막기 |
| 참여 | 빠른 학생만 계속 | 미션별 도장·XP·반 탐험 에너지로 모두 끝까지 |
| 결과 | 도구마다 따로 확인 | 교사 화면 한 곳에서 실시간 현황·결과 카드 |
| 정리 | 기록이 여기저기 남음 | 수업 끝에 '기록 모두 지우기' |

> 💡 이런 웹앱을 만드는 데 코딩 전문가가 필요한 것은 아니에요. 원작자도, AI 탐험 기지도 **AI 코딩 도구(Claude Code 등)와 대화하며** 만들고 고쳤어요. 6장에서 우리 반 버전으로 바꾸는 방법을 다뤄요.

4. 해 보면서 "우리 반 아이들은 어디서 막힐까?"를 학습지 여백에 적어 봐요.

## 3. AI 탐정단 80분 수업 따라가기

**학습 목표**

- **1차시:** 생활 속 AI를 찾고, AI가 데이터로 배운다는 것을 직접 실험으로 확인할 수 있다.
- **2차시:** AI가 틀릴 수 있는 이유를 알고, AI를 책임 있게 사용하는 약속을 만들 수 있다.

| 차시 | 미션 | 학생 활동 | 도장 조건 | 시간 |
| --- | --- | --- | --- | --- |
| 1차시 | 도입 | QR 입장, 캐릭터·닉네임, 탐험 지도 | — | 7분 |
| | **미션 1. AI를 찾아라** | OX 스피드 챌린지 8문제 | 6개 이상 정답 | 8분 |
| | **미션 2. AI를 가르쳐라** | AI 선생님 되기 1라운드 → 2라운드 | 2라운드 모양마다 4개 이상 | 20분 |
| | 정리 | 반 평균 비교, 학습지 | — | 5분 |
| 2차시 | 도입 | "흰 고양이만 배운 AI" 발문 | — | 5분 |
| | **미션 3. AI의 실수를 찾아라** | AI 탐정 사건 파일 7개(목숨 3개) | 5개 이상 해결 | 12분 |
| | **미션 4. AI와 약속하기** | '이럴 때 AI 써도 될까?' 투표 + 약속 의견판 | 투표 4개 + 약속 1개 | 18분 |
| | 임무 완수 | 학습지 최종 O/X·소감, 임명 배지 | 배지 상자 열기 | 5분 |

### 미션 1. AI를 찾아라 — 규칙 프로그램 vs AI

유튜브 추천, 얼굴 인식 잠금, 번역기, 음성 스피커, 사진 앱 얼굴 모으기는 **AI**, 계산기·엘리베이터 버튼·자판기는 **AI 아님**이에요. 문제마다 생각 시간 2초 뒤 15초 제한이 있어 막 누르기를 막아요.

> 💡 **발문**: "계산기와 번역기는 무엇이 다를까요?" → 계산기는 사람이 정한 **규칙대로만** 움직이고, AI는 **많은 예시(데이터)를 보고 스스로 규칙을 찾아요.** 이것이 기계학습이에요.

### 미션 2. AI를 가르쳐라 — "많이보다 다양하게"

학생이 **AI 선생님**이 되어 ○△×를 그려 가르치고 AI에게 12문제 시험을 보게 해요. 그림은 **학생 기기 안에서만 계산**하고 서버에는 점수만 저장돼요.

![AI 선생님 되기: 1라운드(모양마다 1개)와 2라운드(많이·다양하게), ○△× 가르치기 화면](/images/ai-tamheom/m2.jpg)

1. **1라운드**: 모양마다 딱 1개만 가르치고 시험 → 거꾸로 된 세모, 납작한 동그라미를 틀려요.
2. **2라운드**: 모양마다 4개 이상, **크기·두께·방향을 다양하게** 가르치고 다시 시험해요.
3. 교사 화면 **AI 선생님 되기 결과** 카드로 1·2라운드 **반 평균**을 함께 봐요.

| 가르친 방법 (사전 실험) | 점수(12점 만점) |
| --- | --- |
| 모양마다 1개 | 약 8점 |
| **똑같은 모양** 5개씩 | 약 8점 (그대로) |
| **다양하게** 5개씩 | 약 10점 |
| 다양하게 8개씩 | 약 11점 |

> 💡 **발문**: "2라운드에서도 점수가 거의 그대로인 친구는 왜 그럴까요?" → 비슷한 그림만 여러 개 넣었기 때문! "**많이"보다 "다양하게**"를 학생이 스스로 말하도록 기다려 주세요.

> ⚠ 그림이 작거나 점만 찍으면 AI가 배우지 않아요. "캔버스를 꽉 채워서!"

### 미션 3. AI의 실수를 찾아라 — 편향과 환각

AI의 답 가운데 **틀린 문장**을 누르거나, AI 그림에서 **이상한 곳**을 찾아 사건을 해결해요. 답을 읽는 시간 3초가 지나야 누를 수 있고, 목숨은 3개예요.

![AI 탐정 사건 파일: 검은 고양이 사진에 대한 AI의 답 세 문장 중 '고양이는 모두 하얀색이니까 이건 고양이가 아니에요'라는 틀린 문장을 찾는 화면](/images/ai-tamheom/m3.jpg)

| 사건 | 핵심 |
| --- | --- |
| 검은 고양이 | **편향** — "고양이는 모두 하얀색"이라고 배운 AI |
| 고래 | 고래는 아가미가 아니라 폐로 숨 쉬는 포유류 |
| 장수풍뎅이 그림 | 곤충 다리는 6개인데 그림은 8개 (AI 그림의 실수) |
| 이순신 장군 | 맞는 말 사이에 섞인 거짓말 (조선 시대 비행기) |
| 독도 | 독도는 남해가 아니라 동해 |
| 세종대왕 | 그럴듯한 거짓말 (스마트폰 발명) |
| 무지개 | 모두 맞음 → AI가 맞을 때도 많지만 확인하는 습관은 그대로 |

> 💡 **발문**: "AI는 맞는 말과 틀린 말을 **똑같이 자신 있게** 해요. 어떻게 확인할 수 있을까요?" → 책·백과사전, 믿을 만한 기관 누리집, 어른께 묻기, **여러 곳 비교하기**. 이어서 딥페이크와 초상권 이야기로 넘어가요.

### 미션 4. AI와 약속하기 — 딜레마 투표와 약속 의견판

상황 6개마다 ⭕ 괜찮아 / 🤔 조심! / ❌ 안 돼로 투표하면, 반 친구들의 결과와 해설이 보여요.

![이럴 때 AI 써도 될까? 상황 투표: 독후감을 AI에게 통째로 써 달라고 해서 그대로 낸다 등 상황마다 괜찮아·조심·안 돼 단추](/images/ai-tamheom/m4.jpg)

| 상황 | 이야기 나눌 점 |
| --- | --- |
| 독후감을 AI에게 통째로 써 달라고 해 그대로 낸다 | 생각은 내가 먼저! AI는 돕는 친구 |
| AI 챗봇에게 집 주소·전화번호를 알려 준다 | 개인정보는 AI에게도 말하지 않기 |
| 낱말 뜻을 AI에게 묻고 사전으로 한 번 더 확인한다 | 최고의 사용법 — 묻고 확인하기 |
| AI 그림을 내가 그린 것처럼 대회에 낸다 | 'AI 활용'이라고 솔직하게 밝히기 |
| 친구 얼굴을 허락 없이 AI로 바꿔 단톡방에 올린다 | 장난이라도 상처, 반드시 허락 |
| 발표 아이디어를 AI와 떠올리고 내 생각을 더한다 | 함께 생각하고 내 생각 더하기 |

투표 뒤에는 **AI 탐정단 수칙 3+1**을 함께 정리하고, 학생마다 **나의 AI 약속**을 의견판에 올려요.

1. 🔍 **확인한다** — AI의 답은 한 번 더 확인
2. 🤝 **허락받는다** — 친구의 얼굴·목소리·작품은 허락받고, AI로 만든 것은 'AI 활용' 표시
3. 🔒 **지킨다** — 나와 친구의 개인정보
4. 🧠 **생각은 내가 먼저** — AI는 돕는 도구, 생각의 주인은 나

> 💡 투표는 정답 맞히기가 아니라 **이유**가 중요해요. 의견이 갈린 상황을 골라 2~3명의 이유를 들어 보고, 소수 의견을 존중하는 분위기를 만들어요.

### ✋ 실습② 교사 화면으로 한 판 진행해 보기 (15분)

1. 같은 크롬 창에서 탭 두 개를 열어요. 한 탭은 **교사 화면 — 연습 모드**, 다른 탭은 **학생 화면 — 연습 모드**예요. 연습 모드는 같은 브라우저 탭끼리 연결돼요.
2. 교사 탭 위쪽에서 **🕵️ AI 탐정단**을 고르고 **앞서가기 막기**를 켜요.
3. **지금 진행 중인 미션 → 미션 1**을 누르고, 학생 탭에 '지금!' 표시가 뜨는지 확인해요.
4. 학생 탭에서 미션을 해결한 뒤 교사 탭의 **탐험대 현황**이 바뀌는지 봐요.
5. 공지를 하나 보내고, 마지막에 **회차 기록 모두 지우기**까지 눌러 봐요.

## 5. 평가와 기록 활용

XP·순위·배지는 **동기 부여용**으로만 쓰고, 평가는 **과정 중심 관찰**에 활용해요.

| 평가 요소 | 근거 자료 |
| --- | --- |
| 생활 속 AI 구별, AI 학습 원리 이해 | 미션 1 정답 수, 발문 응답 (교사 화면 탐험대 현황) |
| 데이터 양·다양성과 AI 성능의 관계 | AI 선생님 1·2라운드 점수 변화, 학습지 "점수가 달라진 까닭" |
| AI의 오류(편향·환각) 판별 | 미션 3 해결 수·등급 |
| 윤리적 판단과 근거 제시 | 상황 투표 결과, 이유 발표, 학습지 투표 이유 |
| 실천 의지 | 나의 AI 약속, 최종 O/X, 한 줄 소감 |

> ⚠ **기록 모두 지우기**를 누르면 교사 화면 기록이 사라져요. 결과보고서나 평가에 쓸 자료는 **수업 직후 화면 캡처나 학습지**로 남겨 두세요.

## 6. 우리 반 버전으로 바꾸기

웹앱은 설치나 빌드 없이 `public/` 폴더가 그대로 웹사이트예요. 수업 내용을 바꾸는 곳은 거의 **두 파일**뿐이에요.

| 파일 | 내용 |
| --- | --- |
| `public/js/data.js` | **미션 문구·OX 문제·AI 실수 카드·질문 블록·투표 상황·게임 단어 전부** |
| `public/js/config.js` | 코스 이름·색·안내 문구, 배지에 찍힐 학교 이름, 교사 계정, 패들렛·띵커벨 링크, Firebase 설정 |
| `database.rules.json` | 실시간 데이터베이스 보안 규칙 (교사 계정 포함) |
| `리허설_실행.bat` | 내 컴퓨터에서 연습 모드로 열어 보기 (Python 또는 Node.js 필요) |

우리 동네 이야기를 넣으면 학생들이 훨씬 좋아해요. 예를 들어 질문 블록의 '어디서'에 "우리 동네 ○○공원"을, AI 실수 찾기 카드에 "○○시는 어떤 곳이야?" 같은 문제를 넣을 수 있어요.

### ✋ 실습③ AI 코딩 도구로 미션 내용 바꾸기 (15분)

웹앱 폴더를 Claude Code 같은 AI 코딩 도구로 열고 아래처럼 시켜요. 수정이 끝나면 **연습 모드로 열어 학생·교사 화면을 꼭 확인**해요.

```prompt 우리 지역 예시 넣기
public/js/data.js 의 기본 코스(explorer)에 [우리 지역 ○○]의 명소와 특산물 예시를 넣어 줘.

- 릴레이 그림 단어에 우리 동네 명소 3개
다 하면 연습 모드로 열어서 학생·교사 화면을 확인해 줘.
```


### 실제 수업용으로 배포하기 (Firebase 무료 요금제)

연습 모드는 한 기기 안에서만 연결돼요. 학생 기기들과 실시간으로 연결하려면 선생님 계정의 Firebase에 한 번 배포해요.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만들어요.
2. **Realtime Database**를 만들어요. 위치는 싱가포르(asia-southeast1)를 권장해요.
3. **Authentication**에서 **익명**(학생용)과 **Google**(교사용) 로그인을 켜요.
4. 웹 앱을 추가하고 나온 `firebaseConfig` 값을 `config.js`에 붙여 넣어요.
5. `config.js`와 `database.rules.json`의 **교사 계정을 내 구글 계정으로 모두 같게** 바꿔요.
6. 터미널에서 `npx firebase-tools login` → `npx firebase-tools deploy --only hosting,database` 를 실행해요.
7. 학생 주소 `https://(내 사이트).web.app/?s=myclass`, 교사 주소 `.../teacher.html?s=myclass` 를 확인해요.

> ⚠ `config.js`는 웹사이트와 함께 공개되는 파일이라 안에 적힌 교사 이메일은 누구나 볼 수 있어요. 실제 잠금은 서버의 보안 규칙이 담당하지만, 공개가 싫다면 **수업 전용 구글 계정**을 따로 만들어 쓰세요.

> 💡 배포가 어렵다면 처음에는 완성된 **AI 탐험 기지** 주소를 그대로 쓰고, 익숙해지면 우리 반 버전을 만들어도 충분해요.

## 7. 안전·개인정보와 운영 팁

**안전·개인정보**

1. 학생은 **실명 대신 닉네임**으로 입장해요. 닉네임·글의 욕설과 전화번호·주소는 자동으로 걸러요.
2. AI 선생님 되기의 **그림은 학생 기기 안에서만** 처리하고 서버에는 점수만 저장해요.
3. 수업 중 학생이 생성형 AI 서비스에 **직접 가입하거나 개인정보를 입력하지 않아요.** (만 14세 미만 가입 제한)
4. 교사 화면은 **등록된 교사 구글 계정**으로만 열려요.
5. 의견판은 실시간으로 확인하고, 부적절한 글은 바로 숨겨요.
6. 수업이 끝나면 **기록 모두 지우기**로 학생·투표·의견판·AI 선생님 기록을 삭제해요.

**운영 팁**

- 수업 5분 전에 QR을 띄워 두고, **학생 입장을 모두 마친 뒤** 시작해요. 지난 반 기록이 남아 있으면 먼저 지워요.
- 학교 와이파이에서 학생 주소가 열리는지 **크롬북 한 대로 미리** 확인해요. 막히면 `*.web.app`, `*.firebasedatabase.app` 허용을 요청해요.
- 'AI 선생님 되기'는 속도 차가 커요. 전자칠판의 **연습 모드 화면(주소 끝 `&local#m2`**)으로 먼저 시범을 보여요.
- 빨리 끝낸 학생에게는 **AI에게 물어보기**(직접 그린 그림 맞히기)나 학습지 정리를 안내해요.
- 인터넷이 끊기면 강사 노트북의 연습 모드로 시범을 보이고, **종이 학습지**로 활동을 이어 가요.
