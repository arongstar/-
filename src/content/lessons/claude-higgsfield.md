## 1. Claude × 힉스필드, 무엇이 달라졌나

예전 AI 영상은 카메라 위치·각도·조명·움직임을 프롬프트로 하나하나 적어야 했어요. 이제는 **"레퍼런스 이미지 → 영상"** 방식이 되면서, 초보자도 그림 한 장과 짧은 설명으로 영상을 만들 수 있게 되었어요.

여기에 **MCP**로 Claude와 힉스필드를 이으면, 선생님은 Claude와 대화만 하면 돼요.

![선생님이 Claude에게 말하면, Claude가 기획·대본을 쓰고 MCP를 통해 힉스필드에서 이미지·영상을 만들어 돌려주는 구조](/images/claude-higgsfield/how-it-works.svg)

| 역할 | 하는 일 |
| --- | --- |
| **Claude** | 수업 목표를 장면으로 나누고, 대본·나레이션을 쓰고, 프롬프트를 다듬고, 예상 크레딧을 계산 |
| **MCP** | Claude가 힉스필드 기능을 쓸 수 있게 이어 주는 연결 통로 |
| **힉스필드** | 여러 AI 모델로 이미지·영상·한국어 나레이션을 만들고 크레딧을 차감 |

> 📌 Claude 혼자서는 영상을 만들지 못해요. **기획은 Claude, 생성은 힉스필드**가 맡는 구조예요.

### MCP가 항상 정답은 아니에요

- **앱처럼 바로 쓰기**: 힉스필드 웹의 *APPS* 메뉴에는 클릭 몇 번으로 결과가 나오는 기능(사진에 캔버스 효과 입히기 등)이 있어요. 처음이라면 웹에서 먼저 둘러봐도 좋아요.
- **실제 인물·저작권 이미지**: 실존 인물 사진이나 영화 포스터 같은 이미지는 Claude에서 막힐 수 있어요. 수업 자료에서는 애초에 쓰지 않는 것이 원칙이에요.

## 2. 힉스필드 웹 기본기 먼저 익히기

힉스필드는 세계 여러 회사의 **이미지·영상·음성 AI를 한곳에 모은 플랫폼**이에요. 구독 하나로 수십 가지 모델을 골라 쓸 수 있어요. MCP로 연결하기 전에 웹 화면에서 기본 흐름을 한 번 해 보면 Claude에게 시킬 때도 훨씬 쉬워요.

> 💡 오른쪽 위 **프로필 → 언어**에서 **한국어**를 고르면 메뉴가 한글로 바뀌어요. 왼쪽 위 힉스필드 로고를 누르면 첫 화면으로 돌아와요.

### 메뉴 한눈에 보기

| 메뉴 | 기능 | 알아 둘 점 |
| --- | --- | --- |
| **이미지 › 이미지 만들기** | 글로 이미지 만들기, 올린 사진 합성·편집 | 모델·비율·해상도 선택, 한 번에 최대 4장 |
| **비디오 › 비디오 만들기** | 글 또는 이미지로 영상 만들기 | 가장 기본 기능 (모델에 따라 4~30초) |
| **비디오 › 비디오 편집** | 만든 영상 고치기 | |
| **비디오 › 모션 컨트롤** | 영상의 움직임은 두고 얼굴·배경 등 일부만 바꾸기 | 실존 인물 얼굴은 쓰지 않기 |
| **APPS** | 자주 쓰는 효과를 클릭 몇 번으로 | 처음이라면 둘러보기 좋아요 |

### 이미지 만들기

1. 상단 **이미지**에 마우스를 올리고 **이미지 만들기**를 눌러요.
2. 아래 입력창의 **+** 로 전에 만든 이미지를 불러오거나 내 컴퓨터 파일을 올려요.
3. 프롬프트에 **@** 를 입력하면 올린 요소(캐릭터, 물건 등)를 골라 지정할 수 있어요.
   예: "@캐릭터가 @후드티를 입고, 배경은 옷과 어울리는 분위기로"
4. 모델, 화면 비율, 해상도, **장수(1~4장)** 를 정하고 만들어요.

> 📌 영상 강의 기준으로 이미지 1장에 약 2.75크레딧이 들었어요. 모델과 해상도에 따라 달라요.

### 왜 '캐릭터 시트'를 먼저 만들까?

이미지 한 장으로 바로 영상을 만들면, 그림에 없던 **뒷모습이나 옆모습이 매번 다르게** 나와요. 그래서 앞·옆·뒷모습이 한 장에 담긴 **캐릭터 시트**를 먼저 만들어 두면, 이후 영상에서도 같은 캐릭터를 유지하기 쉬워요. (실습②에서 해 봐요.)

### 영상 만들기와 크레딧 아끼는 요령

1. 상단 **비디오 › 비디오 만들기**에서 모델을 고르고 길이·비율·해상도를 정해요.
2. 만들어 둔 이미지나 내 파일을 올리고, 프롬프트에서 **@** 로 지정해요.
3. 마음에 드는 결과가 나오면 다운로드 단추로 내려받아요.

| 설정 | 크레딧 영향 |
| --- | --- |
| 비트레이트(화질·용량) | 크레딧에는 영향 없음 |
| **해상도** | 크게 달라요 — 영상 강의 기준 15초 영상이 480p는 약 45크레딧, 1080p는 약 240크레딧 |
| 길이 | 길수록 많이 들어요 |

> 💡 **처음에는 가장 낮은 해상도로 시험**해 보고, 마음에 들면 그때 고해상도로 다시 만들어요.

### 구간별로 나눠 쓰는 영상 프롬프트

영상 프롬프트는 **시간 구간별로 장면을 나눠 쓰면** 원하는 연출이 잘 나와요. 결과가 아쉬운 구간만 골라 프롬프트를 고치면 돼요.

```prompt 구간별 연출 예시 (15초)
@싹싹이 캐릭터가 나오는 15초 영상.
0~5초: 하늘에서 커다란 비누 거품이 천천히 떨어진다.
5~10초: @싹싹이가 거품을 잡아 손을 꼼꼼하게 씻는다. 카메라가 옆에서 따라간다.
10~15초: @싹싹이가 깨끗해진 손을 들어 보이며 활짝 웃는다.
밝은 교실 배경, 귀여운 3D 애니메이션, 글자 없음.
```

> ⚠ 다른 사람의 유튜브·SNS 영상을 레퍼런스로 올려 움직임을 따라 하는 기능도 있지만, 수업 자료로 쓸 때는 **저작권과 초상권** 문제가 생길 수 있어요. 직접 만든 영상이나 힉스필드 안에서 만든 결과물을 레퍼런스로 써요.

## 3. 연결하기 — 두 가지 방법

| 방법 | 어디서 | 이런 분께 |
| --- | --- | --- |
| **커넥터(MCP)** | claude.ai 웹, Claude 데스크톱 앱 | 대화창에서 말로 시키고 싶은 분 (추천) |
| **CLI + 스킬** | 내 컴퓨터의 Claude Code | 여러 장면을 한꺼번에 만들거나 파일로 관리하고 싶은 분 |

### ✋ 실습① 커넥터로 연결하고 권한 설정하기

1. 힉스필드에 로그인한 뒤 **MCP** 페이지에서 연결할 AI 서비스로 Claude를 고르고 **MCP 주소를 복사**해요. 공식 안내의 주소는 `https://mcp.higgsfield.ai/mcp` 예요.
2. Claude에서 **설정 → 커넥터 → [추가] → [커스텀 커넥터 추가]** 를 누르고 주소를 붙여 넣어요.
3. **[연결]** 을 누르고 힉스필드 계정으로 로그인해요. API 키는 필요 없어요.
4. 커넥터의 **도구 권한**을 아래처럼 정해요.
5. 새 대화에서 커넥터가 켜져 있는지 확인하고, 아래 요청문으로 연결을 시험해요.

| 도구 종류 | 권한 | 이유 |
| --- | --- | --- |
| 읽기 전용 (크레딧 확인, 모델 목록 등) | **항상 허용** | 크레딧이 들지 않아요 |
| 미디어 올리기 | 항상 허용 또는 **승인 필요** | 내 파일이 힉스필드로 넘어가요. 학생 사진이 섞일 수 있으면 승인 필요로 |
| **생성(쓰기)·삭제** | **승인 필요** | '항상 허용'이면 Claude가 실패한 생성을 혼자 다시 시도하며 크레딧을 계속 쓸 수 있어요 |

```prompt 연결 시험 (크레딧 0)
힉스필드에 연결됐는지 확인해 줘.
내 남은 크레딧과 지금 쓸 수 있는 영상 모델 목록을 알려 줘.
아무것도 생성하지는 마.
```

> ⚠ 커넥터는 대화마다 켜져 있는지 확인하고, 로그인이 풀리면 다시 연결해야 할 수 있어요.

### 내 컴퓨터의 Claude Code에 연결하기 (선택)

Claude Code를 쓰는 분은 **힉스필드 CLI**와 **공식 스킬**을 설치해 연결해요. 터미널에서 한 줄씩 실행하고, 두 번째 줄에서 브라우저가 열리면 힉스필드 계정으로 로그인해요.

```
npm i -g @higgsfield/cli
higgsfield auth login
npx skills add higgsfield-ai/skills
```

> 💡 장면이 많은 영상을 한꺼번에 만들 때는 대화형 커넥터보다 CLI가 더 안정적이라는 사용 후기가 많아요.

## 4. 크레딧 아끼는 3단계 원칙

영상 만들기가 쉬워진 건 맞지만, **'쉬워졌다'와 '공짜다'는 달라요.** 비용 순서는 **영상 > 이미지 > 텍스트**예요.

![1단계 텍스트로 기획(크레딧 0) → 2단계 이미지로 확인(적게) → 3단계 영상으로 완성(많이)](/images/claude-higgsfield/credit-steps.svg)

대화를 시작할 때 아래 규칙을 먼저 붙여 넣으면, Claude가 만들기 전에 늘 허락을 받아요.

```prompt 크레딧 안전 규칙 (대화 시작할 때 붙여넣기)
앞으로 이 대화에서 힉스필드로 이미지나 영상을 만들 때는 꼭 지켜 줘.
1) 만들기 전에 사용할 모델, 해상도, 길이, 예상 크레딧을 표로 보여 주고, 내가 "진행"이라고 하면 그때 만들어.
2) 생성이 실패해도 혼자 다시 만들지 말고, 이유와 다음 방법을 먼저 알려 줘.
3) 실제 인물 얼굴, 학생 사진, 유명 캐릭터나 상표는 쓰지 마.
4) 한 번에 하나씩 만들고, 결과를 보여 준 뒤 다음 단계로 넘어가.
```

| --- | --- | --- | --- |
| Basic | $19 | $19 | 270 |

> ⚠ 그 뒤 요금제 이름과 가격이 바뀌었다는 자료도 있어요. 결제 전에 **힉스필드 공식 요금 페이지**를 꼭 확인하세요. 커넥터(MCP)로 만들면 웹의 '무제한' 혜택과 상관없이 **항상 크레딧이 차감**된다고 안내되어 있어요. 가이드북 기준으로 15초 설명 영상 한 편에 약 75크레딧이 들었어요.

## 5. 수업용 영상 만들기

### ✋ 실습② 우리 반 마스코트 캐릭터 시트 만들기

캐릭터를 한 장의 **캐릭터 시트**(여러 각도·표정)로 먼저 만들어 두면, 이후 쇼츠·포스터에서 같은 모습을 유지하기 쉬워요.

1. Claude에게 캐릭터를 설명하고 **프롬프트와 예상 크레딧**부터 받아요.
2. 확인 후 "진행"이라고 해서 이미지 1장을 만들어요.
3. 마음에 들면 이 이미지를 이후 실습의 **레퍼런스**로 써요.

```prompt 학급 마스코트 캐릭터 시트
우리 반 마스코트 캐릭터 시트를 만들고 싶어.
- 캐릭터: 동글동글한 초록 새싹 요정 '싹싹이', 큰 눈, 작은 잎사귀 모자
- 스타일: 초등학생이 좋아할 귀여운 3D 애니메이션
- 한 장 안에: 정면·옆모습·뒷모습, 웃는·놀란·생각하는 표정
- 흰 배경, 글자 없음
먼저 힉스필드에 보낼 프롬프트와 예상 크레딧을 보여 줘.
```

> ⚠ 학생 얼굴 사진이나 학생이 그린 그림을 올려 캐릭터로 만들 때는 반드시 보호자·학생 동의를 받고, 가능하면 선생님이 직접 만든 캐릭터를 써요.

### ✋ 실습③ 과학 설명 영상 — 물과 기름은 왜 안 섞일까?

얼굴이 나오지 않는 **애니메이션 + 한국어 나레이션** 설명 영상은 수업 도입에 바로 쓸 수 있어요. 3단계 원칙대로 진행해요.

1. **텍스트 기획** (크레딧 0): 장면표를 받아 함께 고쳐요.
2. **이미지 확인**: 장면마다 첫 화면을 만들어 골라요.
3. **영상 완성**: 고른 이미지만 영상으로 만들고 나레이션을 입혀요.

```prompt 1단계 — 설명 영상 기획 (크레딧 0)
초등학교 4학년 과학 '물과 기름은 왜 안 섞일까?'를 설명하는 15초 세로 영상을 기획해 줘.
- 얼굴이 나오지 않는 귀여운 애니메이션, 한국어 나레이션
- 장면 3개: 질문 던지기 → 원리(물 알갱이끼리 꼭 붙어 있어요) → 생활 속 예(샐러드 드레싱)
- 4학년이 이해할 수 있는 쉬운 말, 나레이션은 장면당 1~2문장
장면별 화면 설명, 나레이션, 길이를 표로 정리하고 예상 크레딧도 알려 줘. 아직 만들지는 마.
```

```prompt 2단계 — 장면 첫 화면 이미지
좋아. 장면 1~3의 첫 화면 이미지를 먼저 만들어 줘.
세 장 모두 같은 그림체와 색감으로, 글자는 넣지 마.
만들기 전에 예상 크레딧을 알려 줘.
```

```prompt 3단계 — 영상으로 완성
장면 2 이미지가 제일 좋아. 이 그림체로 세 장면을 이어 15초 세로 영상을 만들어 줘.
나레이션은 차분하고 또렷한 여성 목소리로, 1단계에서 정한 문장을 그대로 써 줘.
영상 프롬프트는 0~5초 / 5~10초 / 10~15초 구간으로 나눠 쓰고, 처음에는 낮은 해상도로 시험해 줘.
만들기 전에 모델·해상도·예상 크레딧을 표로 보여 줘.
```

> ⚠ 과학 설명이 정확한지 영상을 **처음부터 끝까지 직접 확인**해요. AI는 그럴듯하게 틀릴 수 있어요.

### ✋ 실습④ 마스코트가 말하는 생활 지도 쇼츠

```prompt 말하는 캐릭터 쇼츠
실습②에서 만든 싹싹이 캐릭터 시트를 참고해서 10초 세로 쇼츠를 기획해 줘.
- 내용: 싹싹이가 "급식 먹기 전에 비누로 30초 동안 손을 씻어요!"라고 말함
- 장면: 밝은 교실 → 손 씻는 순서 3가지(거품 내기·손등·손가락 사이) → 엄지 척
- 장면은 0~3초 / 3~7초 / 7~10초 구간으로 나눠서 프롬프트를 써 줘
- 목소리: 밝고 친근한 어린이 느낌
- 처음 만들 때는 가장 낮은 해상도로 시험해 줘
기획표와 예상 크레딧을 먼저 보여 주고, 내가 "진행"이라고 하면 만들어 줘.
```

### ✋ 실습⑤ 학예회 로고·포스터·홍보 영상

AI 그림은 **글자가 깨지기 쉬워요.** 그림만 만들고 글자는 캔바·미리캔버스에서 넣는 것이 깔끔해요.

1. 로고 시안 3가지를 만들어 하나를 골라요.
2. 고른 로고 느낌으로 포스터 배경 그림을 만들어요. 글자 넣을 빈 공간을 남겨 둬요.
3. 같은 그림으로 10초 홍보 영상을 만들어 학급 게시판·누리집에 올려요.

```prompt 학예회 로고 시안
우리 학교 학예회 '꿈꾸는 무대'의 상징 로고 시안을 3가지 만들고 싶어.
- 초등학생 무대, 별·커튼·음표 같은 상징을 단순하게
- 글자 없이 그림만, 흰 배경, 포스터와 영상에 같이 쓸 수 있는 깔끔한 스타일
먼저 세 시안의 콘셉트를 글로 보여 주고, 예상 크레딧을 알려 줘.
```

```prompt 포스터 배경 + 10초 홍보 영상
2번 시안이 좋아. 이 느낌으로
1) A4 세로 포스터 배경 그림 1장 — 위쪽 1/3은 제목 글자를 넣을 수 있게 비워 둬. 글자는 넣지 마.
2) 같은 그림이 천천히 움직이는 10초 홍보 영상 1편 — 커튼이 열리고 별이 반짝이는 느낌
각각 예상 크레딧을 보여 주고, 하나씩 승인받은 뒤 만들어 줘.
```

힉스필드에는 한국어 나레이션에 쓸 수 있는 목소리가 여러 개 있어요. 오빠두엑셀 가이드북에서 추천(⭐)한 목소리 가운데 수업에 어울리는 것들이에요.

| 쓰임 | 목소리 |
| --- | --- |
| 설명·정보 전달 | 깔끔_정보전달 **AVA**(여), 차분_나레이션 **MAYA**(여), 신뢰_다큐 **HARRISON**(남) |
| 이야기·동화 | 우아_스토리텔링 **ISABELLA**(여), 부드러운_감성 **LUNA**(여) |
| 생활 안내·브이로그 | 친근_브이로그 **GIA**(여), 편안_정보전달 **KEVIN**(남) |

### 한 번 만든 과정을 '스킬'로 저장하기

같은 종류의 영상을 자주 만든다면, 오늘 거친 과정을 **스킬**(작업 지침서)로 저장해 두면 다음에는 한 줄로 시작할 수 있어요. 오빠두엑셀 가이드북에도 설명 영상·캐릭터 쇼츠·로고·광고용 스킬 예제가 있어요.

```prompt 나만의 설명 영상 스킬 만들기
오늘 우리가 한 '과학 설명 영상 만들기' 과정을 다음에도 쓸 수 있게 스킬로 정리해 줘.
- 입력: 학년, 교과, 질문 하나
- 순서: 장면 3개 기획표 → 승인 → 첫 화면 이미지 → 승인 → 15초 세로 영상
- 규칙: 쉬운 말, 얼굴 없는 애니메이션, 차분한 여성 나레이션, 매 생성 전 예상 크레딧 확인
스킬 파일로 저장할 수 있게 내용을 써 줘.
```

## 6. 안전·저작권 수칙

1. **학생 얼굴·이름이 드러난 사진은 올리지 않아요.** 꼭 필요하면 보호자 동의를 받고, 학교 개인정보 지침을 따라요.
2. **실존 인물의 얼굴을 합성하지 않아요.** 유명인·동료 교사도 마찬가지예요. 딥페이크는 법적 문제가 될 수 있어요.
3. **유명 캐릭터·영화 장면·상표를 따라 만들지 않아요.** 선생님이 직접 만든 캐릭터를 써요.
4. **AI로 만든 영상임을 표시해요.** 수업 자료나 누리집에 올릴 때 "AI로 만든 영상" 문구를 넣어요.
5. **사실을 확인해요.** 설명 영상의 내용과 자막을 처음부터 끝까지 직접 검토해요.
6. **학생에게 직접 쓰게 하기 전에** 힉스필드 이용약관의 연령 기준과 학교 지침을 확인해요. 기본은 **교사용 도구**로 써요.
7. **생성 도구는 '승인 필요'로** 두고, 매번 예상 크레딧을 확인해요.

## 7. 내 수업에 적용하기

*영상 기획 시트*를 내려받아 내 수업에 쓸 영상 하나를 기획해 봐요. 여기까지는 크레딧이 들지 않아요.

```prompt 내 수업 영상 기획하기
나는 초등학교 [학년] 담임이고, [교과] '[단원/차시]' 수업 도입에 쓸 [15]초 영상을 만들고 싶어.
학생들이 궁금해할 질문 하나로 시작해서, 장면 3개로 기획해 줘.
장면별 화면 설명, 나레이션, 길이, 이미지·영상 단계별 예상 크레딧을 표로 정리해 줘.
아직 아무것도 만들지 마.
```
