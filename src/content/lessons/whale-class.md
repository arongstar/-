## 1. 웨일 스페이스와 웨일 클래스

**웨일 스페이스**는 공교육용 교육 플랫폼이에요. 계정 하나로 수업 관리(웨일 클래스), 협업 보드(팀보드), 화상 수업(웨일온), 업무 협업(네이버 웍스)을 함께 써요. 그중 **웨일 클래스**가 오늘의 주인공, 온라인 수업 관리 도구(LMS)예요.

![웨일 스페이스 계정 하나로 웨일 클래스, 팀보드, 웨일온, 네이버 웍스, 웨일 브라우저를 함께 쓰는 구조](/images/whale-class/whale-space.svg)

### 웨일 클래스로 할 수 있는 일

| 하고 싶은 일 | 웨일 클래스 기능 |
| --- | --- |
| 단원·차시별로 수업 자료 올리기 | **챕터형 수업 게시판** + 수업(글·사진·동영상·문서·링크·설문) |
| 배운 내용 바로 확인하기 | **퀴즈** — 객관식·단답형은 자동 채점 |
| 결과물 받고 피드백하기 | **과제** — 점수, 의견, 다시 제출, 제출 이력 |
| 친구끼리 서로 평가하기 | **동료평가** — 조별·개별, 익명 평가 |
| 함께 생각 모으기 | **클래스 전용 팀보드** |
| 원격·보강 수업 | **웨일온 수업 전용 회의실**, LIVE 수업 |
| 학급 운영 | 공지 게시판, 온라인 조종례, 설문, 학습 현황, 수업도구 |

### 클래스는 이렇게 생겼어요

![클래스 → 메뉴(게시판) → 챕터(단원) → 수업 콘텐츠(차시)로 이어지는 웨일 클래스 구조](/images/whale-class/class-structure.svg)

- **클래스** = 우리 반 하나 (또는 과목 하나)
- **메뉴(게시판)** = 과목마다 하나. 수업 게시판은 **일반형**과 **챕터형**이 있어요.
- **챕터** = 단원. 챕터형 수업 게시판에서만 써요.
- **수업 콘텐츠** = 차시. 수업·퀴즈·과제·동료평가·퀴즈형 설문 다섯 가지예요.

### 시작 전 확인: 로그인과 선생님 권한

1. 웨일 브라우저 오른쪽 위 **프로필 아이콘** → **로그인** → **학교/기관** 을 누르고 웨일 스페이스 아이디와 비밀번호를 넣어요.
2. 주소창에 `class.whalespace.io` 를 넣어 웨일 클래스로 가요. (학교에서 북마크·즐겨찾기를 넣어 두었으면 그걸 눌러도 돼요.)
3. 홈 화면에 **[클래스 개설하기]** 버튼이 보이면 선생님 권한이 있는 거예요.

> 💡 경북 선생님은 **경북AI배움터** 의 나의 강의실에서도 웨일 클래스로 들어갈 수 있어요.

> ⚠ **[클래스 개설하기] 버튼이 없다면** 선생님 권한이 없는 계정이에요. 학교의 웨일 스페이스 관리자(정보 담당 선생님)에게 선생님 권한을 요청해요.

## 2. 우리 반 클래스 열기

### ✋ 실습① 우리 반 클래스 개설하기 (8분)


📍 홈 › 클래스 개설하기 (또는 나의 클래스 › 클래스 추가하기 › 클래스 개설하기)

1. **클래스명**: 학생이 바로 알아보게 `○학년 ○반` 이나 `○학년 과학` 처럼 써요. 나중에 바꿀 수 있어요.
2. **클래스 URL**: 자동으로 만들어진 주소를 쓰거나 직접 넣어요. **한 번 정하면 바꿀 수 없어요.**
3. **클래스 커버**: 마음에 드는 색을 골라요. 개설 뒤에 직접 그림을 올릴 수도 있어요.
4. **노출 범위**: 우리 반만 쓰면 **노출 안 함**. **우리 스페이스** 를 고르면 같은 학교 구성원이 클래스를 찾아 들어올 수 있어요.
5. **[개설]** 을 누르면 끝. 나의 클래스 › **운영 클래스** 에 생겨요.

개설 뒤 📍 설정 › 기본 정보 에서 꼭 볼 것은 **클래스 기간** 이에요.

| | 기간 클래스 | 상시 클래스 |
| --- | --- | --- |
| 이런 반에 | 학기·학년처럼 기간이 정해진 반 | 언제나 열어 두는 자료방·방과후 |
| 쓸 수 있는 것 | 수업, 퀴즈(시험·자가학습), **과제, 동료평가, 서술형 문제** | 수업, 퀴즈 |
| 수료 처리 | 평가를 마치고 성적을 공개할 때 | 기준을 채우면 바로 |

> ⚠ 기간 클래스를 **상시로 바꾸면 과제·동료평가와 서술형 문제가 지워져요.** 평가에 쓸 반은 **기간 클래스** 로 두어요.

그 밖에 기본 정보에서 정할 것:

- **참여 승인 방식**: 자동 승인 / 선생님 승인. 선생님 승인이면 들어올 때 물어볼 질문도 넣을 수 있어요.
- **초대 코드**: '사용'으로 바꾸고 저장하면 코드가 생겨요. (아래 학생 초대 참고)
- **과목명**: 학교급(초등학교)을 고르면 과목 목록이 생겨요. 수업마다 **대표 과목** 을 꼭 골라야 해서 미리 만들어 두면 편해요.
- **클래스 용어**: 초등용(선생님)으로 두면 '교수자' 대신 '선생님'으로 보여요.

### ✋ 실습② 과목 게시판과 단원 챕터 만들기 (7분)


📍 설정 › 메뉴 관리

1. **[메뉴 추가]** 에서 **챕터형 수업 게시판** 을 골라 과목 이름을 붙여요. (예: `과학`, `사회`) 이미 있는 일반 수업 게시판은 **더보기(···) › 챕터 적용** 으로 챕터형으로 바꿀 수도 있어요.
2. 게시판에 들어가면 CHAPTER 1~5가 기본으로 있어요. 이름을 `1단원 ○○○` 처럼 단원으로 바꾸고, 필요 없는 챕터는 지워요. 더 필요하면 위쪽 **[챕터 추가]**.
3. **공지 게시판** 도 하나 만들어요. 계정 안내, 과제 내는 법, 자주 묻는 질문을 올려 두면 같은 질문에 여러 번 답하지 않아도 돼요.
4. 메뉴 타입을 **Tree형** 으로 바꾸면 왼쪽 메뉴에 차시 제목까지 펼쳐 보여요. (기본은 일반형)

| 메뉴 종류 | 언제 쓰나요 |
| --- | --- |
| 챕터형 수업 게시판 | 단원·차시가 있는 교과. 엑셀로 챕터·수업 제목을 한꺼번에 넣을 수도 있어요 |
| 일반 수업 게시판 | 미술처럼 단원 구분 없이 그날그날 올리는 수업 |
| 공지 게시판 | 선생님만 올리는 안내 |
| 자유 게시판 / 토론 | 학생도 글을 쓰고 댓글로 이야기 |
| 정보 페이지 · 외부 링크 · 영상 수업 링크 | 수업 계획, 자주 쓰는 사이트, 영상 모음 |

> 💡 **진도가 끝난 단원**은 챕터 오른쪽 **가로 막대 3개(≡)** 를 끌어 아래로 내리고, 다 쓴 수업은 **비공개** 로 바꾸면 학생 화면이 깔끔해져요.

### 학생 초대하기


| 방법 | 어디서 | 이럴 때 좋아요 |
| --- | --- | --- |
| **조직도로 추가** | 설정 › 구성원 관리 › 구성원 추가 | 학교 조직도에서 우리 반을 골라 한 번에 (최대 100명) |
| **초대 코드** | 설정 › 기본 정보 › 초대 코드 '사용' | 학생이 나의 클래스 › 클래스 참여하기에 코드 입력. **승인 없이** 바로 참여 |
| 클래스 URL | 설정 › 기본 정보 | 알림장·메신저로 주소 공유 |
| 초대장 메일 | 설정 › 수강생 초대 관리 | 학생 계정 메일로 한 번에 10명까지. 초대로 오면 자동 승인 |
| 직접·엑셀 등록 | 설정 › 구성원 관리 | 한 명씩 또는 **엑셀 샘플 파일** 로 여러 명 |

> 📌 참여 승인 방식이 **선생님 승인** 이면 URL로 들어온 학생은 📍 설정 › 클래스 참여 관리 에서 승인해야 들어와요. 초대 코드가 밖으로 퍼졌다면 같은 곳에서 **재설정** 해요.

> 💡 동학년·교과 선생님과 함께 운영하려면 📍 설정 › 구성원 관리 에서 그 선생님의 등급을 **선생님** 으로 바꿔요. 도우미는 **튜터** 로 두고 📍 설정 › 튜터 권한 설정 에서 할 수 있는 일을 정해요.

## 3. 차시 수업과 복습 퀴즈 만들기

### ✋ 실습③ 1차시 수업 만들기 (15분)


1. 챕터(단원) 아래 **[수업 추가]** → 제목을 `1차시 ○○○ 알아보기` 처럼 쓰고 **[저장 후 이동]**.
2. 편집 화면 위쪽에서 필요한 요소를 차례로 넣어요. **순서는 끌어서 바꿀 수 있어요.**
3. 아래 **수업 설정** 을 정하고 저장해요.
4. 다 만들었으면 게시판이나 수업 위쪽에서 **공개** 로 바꿔요.

| 수업 요소 | 이렇게 써요 |
| --- | --- |
| 텍스트 | 성취기준, **학습 문제(크고 굵게)**, 활동 순서. 중요한 안내는 빨간 글씨 |
| 이미지 | 교과서 쪽 사진, 판서 사진, 실험 결과 사진 |
| 동영상 | 직접 찍은 영상. **목차(00:00)** 와 **재생 구간** 을 정해 필요한 부분만 |
| URL | 유튜브·e학습터·디지털교과서 링크. 유튜브는 미리보기로 보여요 |
| 문서 | 활동지(doc·xls·ppt·pdf) |
| 설문 | 수업 중 간단한 의견 받기 |
| 콘텐츠함 | 예전 수업의 요소를 그대로 가져오기 |

**수업 설정에서 꼭 볼 것**

- **대표 과목**: 꼭 골라야 해요. 안 고르면 공개로 바꿀 수 없어요. 학생 시간표에 과목명으로 보여요.
- **학습 시간**: 정해 두면 학생 홈 **시간표** 에 나와요. '학습 활동 제한'을 켜면 그 시간 안에만 학습 완료를 누를 수 있어요.
- **공개 예약**: 정한 시각에 저절로 공개돼요. 아침 수업 자료를 전날 만들어 둘 때 좋아요.
- **댓글**: 수업마다 켜고 끌 수 있어요.

> 📌 새로 만든 수업은 **비공개** 로 저장돼요. 내용이 비어 있거나 대표 과목이 없으면 공개로 바뀌지 않아요.

> 💡 **학습 문제 한 줄, 활동 세 줄** 이면 충분해요. 처음부터 완벽하게 꾸미기보다, 학생이 '오늘 무엇을 하는지' 한눈에 보이게 만드는 게 먼저예요.

```prompt 차시 수업 안내문 만들기
너는 초등학교 4학년 담임교사를 돕는 수업 설계 도우미야.
웨일 클래스 '수업'에 올릴 학생용 안내문을 써 줘.

[교과·단원] 4학년 과학 · 물의 상태 변화
[차시] 2차시 · 물이 얼 때 부피와 무게는 어떻게 변할까요?
[성취기준] (교육과정 성취기준 코드와 문장을 붙여 넣기)
[활동] 실험 영상 보기 → 결과 표 채우기 → 생각 한 줄 쓰기

조건:
- 맨 위에 '오늘의 학습 문제' 한 문장 (크게 쓸 거야)
- 활동 순서를 ①②③ 세 줄로, 4학년이 읽기 쉬운 말로
- 끝에 '다 했으면 [학습 완료]를 눌러요' 안내
- 학생 이름 같은 개인정보는 넣지 마
```

### ✋ 실습④ 복습 퀴즈 3문항 만들기 (10분)

1. 같은 챕터에서 **[퀴즈 추가]** → 제목 `2차시 복습 퀴즈` → **[저장 후 이동]**.
2. **[만들기]** 로 문제를 넣어요. 문제마다 **질문 · 배점 · 문제 종류 · 보기와 정답 · 정답 풀이** 를 채워요.
3. 아래 **퀴즈 설정** 에서 **퀴즈 구분** 을 골라요.
4. 저장하고 공개해요.

| 문제 종류 | 채점 | 메모 |
| --- | --- | --- |
| 객관식 단일선택 | 자동 | 보기 순서를 섞을 수 있어요 |
| 객관식 다중선택 | 자동 | 정답이 둘 이상 |
| 주관식 단답형 | 자동 | **유사 정답** 과 인정률(%)을 넣으면 띄어쓰기·표현 차이도 맞게 처리 |
| 주관식 서술형 | 선생님이 직접 | **기간 클래스** 에서만. 모범 답안을 적어 둘 수 있어요 |

| 퀴즈 구분 (기간 클래스) | 성적 반영 | 이럴 때 |
| --- | --- | --- |
| **자가학습** | 반영 안 함 | 복습·연습. 기간·횟수 제한 없이 여러 번 |
| **시험** | 반영 | 단원 평가. 제출 기간·횟수를 정하고, **집중 모드** 를 켤 수 있어요 |

> 📌 **집중 모드** 를 켜면 퀴즈가 전체 화면으로만 열리고 새 탭·검색창을 쓸 수 없어요. 웨일북의 화면 캡처·녹화도 막혀요. **웨일 브라우저 PC 환경** 에서만 시작할 수 있어요.

> 💡 다른 퀴즈의 문제는 **[불러오기]** 로 다시 쓸 수 있어요. 시험 기간이 끝난 시험은 저절로 자가학습으로 바뀌어 복습용으로 남아요.

```prompt 복습 퀴즈 문항 만들기
4학년 과학 '물의 상태 변화' 2차시(물이 얼 때 부피와 무게 변화) 복습 퀴즈를 만들어 줘.
웨일 클래스 퀴즈에 바로 옮겨 적을 수 있게 아래 형식으로 써 줘.

- 객관식 단일선택 2문항, 주관식 단답형 1문항
- 문항마다: 질문 / 보기 4개(객관식만) / 정답 / 유사 정답(단답형만, 2~3개) / 정답 풀이(한두 문장)
- 4학년이 읽기 쉬운 말로, 교과서에 나오는 개념만
- 헷갈리기 쉬운 오개념(예: 얼면 무게가 늘어난다)을 보기에 하나 넣어 줘
```

### 퀴즈형 설문 — 배움 확인·의견 받기

수업 게시판의 **[퀴즈형 설문 추가]** 로 점수 없는 설문을 만들 수 있어요. 결과는 📍 설정 › 퀴즈형 설문 조사 에서 제출·미제출 명단과 함께 보고 엑셀로 받을 수 있어요. 주관식 문항에 **개인정보 항목** 을 켜면 답이 암호화되어 저장돼요.

## 4. 과제로 과정 중심 평가하기

![과제 만들기 → 학생 제출 → 평가·피드백 → 고쳐서 다시 제출 → 성적 탭에서 모아 보기](/images/whale-class/assignment-loop.svg)

### ✋ 실습⑤ 성취기준을 붙인 과제 만들기 (10분)

1. 챕터에서 **[과제 추가]** → 제목에 **성취기준과 차시** 를 붙여요. 예: `[성취기준 코드] 3차시 물이 얼 때 변화 설명하기` → **[저장 후 이동]**.
2. 과제 안내를 쓰고, 필요하면 이미지·문서·URL을 넣어요.
3. 설정에서 **배점**, **평가 기준**, **제출 기간**, **대표 과목** 을 채워요. (파란 * 표시는 꼭 채워야 해요)
4. 저장하고 공개해요.

> 📌 과제와 동료평가는 **기간 클래스** 에서만 만들 수 있어요. 버튼이 안 보이면 클래스 기간부터 확인해요.

**평가 기준(루브릭)** 은 성취기준별로 등급과 점수를 넣는 칸이에요. 예를 들면 `잘함 3 · 보통 2 · 노력 요함 1`. 등급은 10단계까지 만들 수 있어요. 자주 쓰는 기준은 📍 평가 기준 관리 에 저장해 두고, 학교 안에 **공개** 하면 동학년 선생님도 **[복사]** 해서 쓸 수 있어요.

```prompt 과제 안내와 평가 기준 만들기
4학년 과학 '물의 상태 변화' 단원 과제를 웨일 클래스에 올리려고 해.
과제: 물이 얼 때와 얼음이 녹을 때 부피·무게 변화를 그림과 글로 설명하기

1. 학생용 과제 안내를 5줄 이내로 써 줘. (무엇을, 어떻게, 언제까지, 어떻게 제출)
2. 평가 기준을 '잘함 / 보통 / 노력 요함' 3단계 표로 만들어 줘. 단계마다 관찰할 수 있는 행동으로.
3. 단계별로 학생에게 줄 피드백 예시를 한 문장씩 써 줘. 따뜻하지만 다음에 할 일이 분명하게.
학생 이름은 넣지 마.
```

### 평가하고 피드백하기


📍 성적 › 과제 › 평가 → 과제 이름 클릭

1. 학생이 **제출 · 평가 대기 · 미제출** 로 나뉘어 보여요. **평가 대기** 는 '냈는데 아직 내가 안 본 과제'예요.
2. **[평가]** 를 눌러 과제를 보고 **점수, 의견, 성취도** 를 넣어요. 만점이면 **[만점 입력]**.
3. 고칠 점이 있으면 **다시 제출** 에 체크하고, 무엇을 고치면 좋을지 의견에 적어요.
4. **[즉시 공개]** 하면 학생이 바로 보고, **[임시 저장]** 하면 나만 보여요. 임시 저장한 것은 나중에 골라서 한꺼번에 공개할 수 있어요.
5. 학생이 고쳐 내면 다시 **평가 대기** 로 와요. 과제의 **평가 상태** 를 누르면 몇 번 고쳤고 그때마다 몇 점이었는지 **기록** 이 보여요.

> ⚠ **[과제 종료]** 를 누르면 임시 저장한 평가가 한꺼번에 공개되고, 그 뒤로는 과제와 평가를 고칠 수 없어요. 다시 제출을 다 받은 뒤에 눌러요.

```prompt 과제 피드백 다듬기
초등학교 4학년 과학 과제에 남길 피드백을 다듬어 줘.
- 내가 쓴 메모: (예: 부피 변화는 맞게 그렸는데 무게는 설명이 없음)
- 잘한 점 1개 + 고칠 점 1개 + 다음에 해 볼 일 1개, 모두 합쳐 3문장
- 4학년이 이해하는 말, 칭찬은 구체적으로
- '다시 제출'을 부탁하는 경우라면 마지막 문장에서 무엇을 고쳐 내면 되는지 분명하게
```

### 성적 모아 보기 → 생활기록부 참고 자료

📍 성적 › 전체성적

- **과목(게시판)** 을 고르면 그 과목 과제와 점수만 모여요. 과제 제목에 성취기준을 붙여 두었으니 **어떤 성취기준의 점수인지** 바로 보여요.
- 오른쪽 검색란에 **학생 이름** 을 넣으면 한 학생의 과목 점수만 볼 수 있어요.
- 과제를 **비공개** 로 바꾸면 성적 화면에서도 빠져요. 보고 싶은 과제만 남겨 볼 때 쓰는데, 진도율·점수에서도 빠지니 조심해요.
- 📍 성적 › 과제 › 다운로드 에서 학생별·전체 과제물을 한 번에 받을 수 있어요.

> 💡 쌓인 점수와 고친 기록은 **학생 성장 관찰의 근거** 예요. 생활기록부 문장은 이 기록을 보고 선생님이 직접 판단해 써요.

### 동료평가 — 친구끼리 서로 평가하기

챕터에서 **[동료평가 추가]** 로 만들어요. 순서는 **과제 제출 → 동료평가·본인 평가 → 선생님 검토 → 결과 공개** 예요.

| 설정 | 고를 수 있는 것 |
| --- | --- |
| 평가 종류 | 과제 평가 / 과제 제출 즉시 동료평가 시작 / 과제 없이 평가 |
| 평가 방식 | **조별 활동**(정해 둔 모둠 안에서) / **개별 활동**(무작위) |
| 블라인드 평가 | 누구를 평가하는지 감추기 |
| 본인 평가 | 자기 평가 (점수에는 안 들어가요) |
| 기간 | 동료평가는 과제 제출이 끝난 **다음 날부터** |

> 💡 초등에서는 **블라인드 + 평가 기준 3단계 + 칭찬 한 줄** 로 시작하면 부담이 적어요. 결과를 학생에게 공개할지는 선생님이 정해요.

## 5. 팀보드·웨일온·학급 운영

### ✋ 실습⑥ 클래스 전용 팀보드로 생각 모으기 (8분)


1. 클래스 위쪽 **[팀보드 생성]** (회색 버튼)을 누르거나, 📍 설정 › 클래스 전용 팀보드 › 팀보드 생성하기.
2. 우리 반 구성원에게 **편집 권한** 이 저절로 주어져요. 링크를 따로 나누지 않아도 클래스 위쪽 **[팀보드]** 버튼으로 다 같이 들어와요.
3. 보드 이름이 클래스 이름과 같게 만들어져요. `2차시 생각 모으기` 처럼 **보드 이름을 바꿔** 두면 나중에 찾기 쉬워요.
4. 학생들이 **스티키 노트** 에 생각을 쓰고, 친구 의견에 **이모티콘 스티커** 로 공감해요. 웨일북은 펜으로 **드로잉** 도 돼요.

| 설정 | 내용 |
| --- | --- |
| 학생 사용 권한 | **편집** / **읽기** / 접근 제한. 읽기로 두고 한 명씩만 편집을 열어 줄 수도 있어요 |
| 학생 메뉴에 노출 | 학생 화면에 팀보드 버튼 보이기/숨기기 |
| 팀보드 연결 해제 | 보드는 남지만 **다시 이 클래스에 연결할 수 없어요** |

> 💡 보드가 넓어지면 오른쪽 아래 **미니맵** 으로 위치를 찾고, **모두에게 내 화면 공유** 로 한 학생의 화면을 전체에 보여 줄 수 있어요.

### 웨일온 수업 전용 회의실

📍 클래스 위쪽 [웨일온 수업 개설] 또는 설정 › 웨일온 수업 전용 회의실

- 설치 없이 웨일 브라우저에서 바로 화상 수업. 만든 뒤에는 클래스 위쪽 **[웨일온 수업]** 으로 들어가요.
- **대기실** 을 켜면 선생님이 승인한 사람만 들어와요. **호스트 없이 시작** 은 끄는 것을 권해요.
- 링크가 밖으로 퍼졌다면 **재설정** 으로 새 링크로 바꿔요.

### 동학년과 나누고 다시 쓰기

- **콘텐츠함**: 챕터형 게시판 위쪽 **[콘텐츠함]** → 내가 선생님인 다른 클래스의 수업·퀴즈·과제를 골라 **[가져오기]**. 수업 편집 화면에서는 요소(글·사진·영상…)만 가져올 수도 있어요.
- **내보내기**: 수업이나 공지의 **더보기(···) › 내보내기** → 운영 중인 다른 클래스에 한 번에 복사. 설정까지 그대로 복사되고, 처음에는 비공개로 들어가요.
- **불러오기**: 퀴즈 문제는 다른 퀴즈에서 **[불러오기]** 로 다시 써요. 매번 쓰는 성취기준·학습 문제 틀은 첫 수업을 만들어 두고 콘텐츠함으로 가져오면 편해요.

> 💡 동학년이 같은 진도라면 한 분이 단원을 만들고 **내보내기** 로 나누면 일이 확 줄어요.

## 6. 안전하게 쓰기

- **노출과 공개는 좁게**: 우리 반 클래스는 노출 범위를 **노출 안 함** 으로 두고, 기본 정보의 **클래스 내용 [공개하기]** 는 켜지 않아요. 공개하면 클래스를 방문한 누구나 수업 내용을 볼 수 있어요.
- **교과서 사진·영상은 우리 반 안에서만**: 수업 목적으로 올린 자료는 우리 반 학생만 보게 하고, 우리 스페이스·공개 클래스로 넓히지 않아요.
- **초대 코드·회의 링크가 새면 재설정**: 초대 코드는 승인 없이 들어오는 열쇠예요.
- **개인정보는 최소로**: 퀴즈형 설문에서 꼭 필요한 개인정보만 받고 **개인정보 항목** 을 켜요. AI에게 프롬프트를 쓸 때 학생 이름·번호를 넣지 않아요.
- **지우기 전에 한 번 더**: 삭제한 수업은 되살릴 수 없다고 생각해요. 안 쓰는 수업은 지우기보다 **비공개** 로.
- **되돌릴 수 없는 버튼**: 과제 종료(평가 수정 불가), 성적 공개(되돌리기 어려움), 팀보드 연결 해제(다시 연결 불가), 상시 클래스로 바꾸기(과제·동료평가 삭제)는 한 번 더 확인하고 눌러요.

### 학년 말 정리: 보관 vs 폐쇄

| | 보관 | 폐쇄 |
| --- | --- | --- |
| 어디서 | 나의 클래스 › 운영 클래스 › 클래스 카드 더보기 › **보관** | 클래스 › 설정 › **클래스 폐쇄** |
| 결과 | 고칠 수 없게 잠김. 학생은 **성적만** 볼 수 있어요 | **영구 삭제** (7일 유예 기간 안에는 취소 가능) |
| 되돌리기 | 클래스 보관함에서 **복원** | 안 돼요 |

> 📌 기록이 남아야 하는 반은 **보관**, 연습용 클래스는 **폐쇄** 로 정리해요.

## 자주 묻는 질문

**[클래스 개설하기] 버튼이 안 보여요.**
선생님 권한이 없는 계정이에요. 학교 웨일 스페이스 관리자에게 요청해요.

**과제·동료평가 추가 버튼이 없어요.**
상시 클래스예요. 📍 설정 › 기본 정보 › 클래스 기간 을 확인해요. 단, 기간 → 상시로 바꾸면 과제·동료평가가 지워져요.

**수업이 공개로 안 바뀌어요.**
내용이 비어 있거나 **대표 과목** 을 안 골랐어요.

**학생이 URL로 들어왔는데 수업이 안 보인대요.**
참여 승인 방식이 선생님 승인이면 📍 설정 › 클래스 참여 관리 에서 승인해야 해요. 수업이 비공개인지도 확인해요.

**유튜브 영상을 봤는지 확인하고 싶어요.**
동영상 시청률은 웨일 클래스에 **직접 올린 영상** 만 잴 수 있어요. 유튜브 같은 외부 링크는 재지 못해요.

**동학년 선생님과 같은 클래스를 같이 운영하고 싶어요.**
📍 설정 › 구성원 관리 에서 그 선생님 등급을 **선생님** 으로 바꿔요. 각자 반이 따로 있으면 **내보내기** 가 더 편해요.
