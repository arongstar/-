## 1. 생성형 AI란?

생성형 AI는 사람이 쓴 엄청난 양의 글을 학습해서, **다음에 올 말을 그럴듯하게 이어 쓰는** 프로그램이에요.
그래서 글쓰기·요약·아이디어 내기는 잘하지만, **사실이 아닌 내용을 자신 있게 말하기도** 합니다(환각).

| 잘하는 일 | 조심할 일 |
| --- | --- |
| 글 초안 쓰기, 말투 바꾸기 | 최신 정보, 숫자, 출처 |
| 아이디어 여러 개 내기 | 학생 개인정보 입력 |
| 긴 글 요약·정리 | 결과를 그대로 쓰기 |

> 💡 AI가 만든 결과물은 **초안**입니다. 마지막 확인과 판단은 언제나 선생님 몫이에요.

## 2. 좋은 프롬프트의 4가지 재료

1. **역할** — "너는 초등학교 3학년 담임교사야"
2. **상황·목적** — "학부모 상담 주간 안내 가정통신문을 쓰려고 해"
3. **조건** — "300자 이내, 따뜻하고 정중한 말투, 날짜는 빈칸으로"
4. **형식** — "제목 / 인사 / 본문 / 맺음말 순서로"

```prompt 기본 틀 — 역할·상황·조건·형식
너는 [역할]이야.
[상황과 목적]을 위해 [만들 것]을 만들어 줘.

조건:
- [분량]
- [말투]
- [꼭 들어갈 내용]

형식: [표 / 목록 / 문단 등]
```

## 3. 실습 ① 가정통신문 쓰기

```prompt 가정통신문 초안
너는 초등학교 3학년 담임교사야.
다음 주에 있을 '학부모 상담 주간'을 안내하는 가정통신문을 써 줘.

조건:
- 400자 내외
- 따뜻하고 정중한 말투
- 상담 신청 방법(회신서 제출)과 상담 방식(대면/전화) 선택 안내 포함
- 날짜와 시간은 [  ] 빈칸으로 남겨 줘

형식: 제목 / 인사말 / 안내 내용 / 맺음말
```

결과가 마음에 들지 않으면 **대화를 이어서** 고쳐 달라고 하세요.

```prompt 이어서 고치기
조금 더 짧게, 핵심 내용은 글머리표로 정리해 줘.
그리고 맞벌이 가정을 배려하는 문장을 한 줄 넣어 줘.
```

## 4. 실습 ② 수업 아이디어 얻기

```prompt 수업 도입 아이디어
초등학교 4학년 과학 '물의 상태 변화' 단원의 첫 차시 도입 활동 아이디어를 5개 제안해 줘.
각 아이디어마다 준비물, 소요 시간(5분 이내), 학생 활동을 표로 정리해 줘.
```

```prompt 수준별 문제 만들기
초등학교 5학년 수학 '분수의 덧셈' 문제를 만들어 줘.
- 기초 3문제, 보통 3문제, 도전 2문제
- 도전 문제는 실생활 상황이 들어간 문장제로
- 마지막에 정답과 간단한 풀이를 따로 정리해 줘
```

## 5. 꼭 지켜야 할 것

- 학생 **이름, 연락처, 성적, 상담 내용** 등 개인정보는 입력하지 않아요.
- 학생 계정으로 쓰게 할 때는 서비스의 **가입 연령·보호자 동의** 기준을 먼저 확인해요.
- AI가 알려 준 **사실·숫자·출처**는 반드시 다시 확인해요.
