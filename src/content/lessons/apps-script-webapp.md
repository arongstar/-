## 1. Apps Script 웹앱은 어떻게 움직일까?

**Apps Script**는 구글 시트·문서·드라이브를 자동으로 다루는 구글의 무료 코딩 도구예요. 여기에 화면(HTML)을 붙여 **'웹 앱'으로 배포**하면, 링크 하나로 열리는 우리 반 전용 앱이 돼요.

![학생·교사가 웹앱 주소로 접속하면, 화면(Index.html)이 처리 코드(Code.gs)를 부르고, 처리 코드가 구글 시트에 기록을 저장하는 구조](/images/apps-script/how-it-works.svg)

| 구성 | 하는 일 | 이 교안에서는 |
| --- | --- | --- |
| **구글 시트** | 학생 명단, 차시, 기록이 쌓이는 저장소 | 양식 사본으로 제공 |
| **Code.gs** | 누가 접속했는지 확인하고, 입력값을 검사해 시트에 저장 | 완성 코드 제공 |
| **Index.html** | 학생·교사가 보는 화면 | 완성 코드 제공 |

> 💡 코드는 **AI에게 맡기면** 돼요. 선생님이 할 일은 ① 시트를 준비하고 ② 코드를 붙여 넣고 ③ 배포 설정을 정확히 고르는 거예요.

### 학생을 어떻게 구분할까? — 학교 구글 계정

배움 기록장(B)과 독서 기록장(D)은 학생이 **학교 구글 계정으로 로그인한 상태**에서 앱을 열면, 앱이 로그인한 이메일을 보고 학생을 알아봐요. 그래서 학생은 **자기 기록만** 볼 수 있고, 평가는 **교사 계정만** 할 수 있어요.

> ⚠ 이 방식은 **교사 계정과 학생 계정이 같은 학교 구글 워크스페이스 도메인**일 때만 동작해요. 우리 학교 학생 계정이 어떤 도메인인지는 정보 담당 선생님께 확인해 주세요.

## 2. 앱 만들기 기본 5단계

1. **시트 사본 만들기**: 자료 내려받기의 *시트 사본 만들기* 링크를 누르고 [사본 만들기]를 눌러요.
2. **Apps Script 열기**: 사본 시트에서 [확장 프로그램 → Apps Script]를 눌러요.
3. **코드 붙여 넣기**
   - 처음 보이는 `Code.gs` 내용을 모두 지우고 받은 **Code.gs**를 붙여 넣어요.
   - 왼쪽 [+ → HTML]로 이름이 **Index**인 파일을 만들어 **Index.html**을 붙여 넣어요.
   - 💾 저장해요.
4. **웹 앱으로 배포**: [배포 → 새 배포 → 유형 선택(톱니) → 웹 앱]을 고르고, 아래 표대로 정한 뒤 [배포]를 눌러요.
5. **권한 승인 → 주소 공유**
   - 처음에는 권한 승인 창이 떠요. 내 계정을 고르고 허용해요.
   - 나온 **웹 앱 URL**을 학생에게 안내해요. 구글 클래스룸 공지나 QR 코드로 나누면 편해요.

| 앱 | 다음 사용자 인증 정보로 실행 | 액세스 권한이 있는 사용자 |
| --- | --- | --- |
| A. 태블릿 대여·반납 | 나 | 우리 학교 도메인의 모든 사용자 |
| B. 배움 기록장 + 평가 | 나 | 우리 학교 도메인의 모든 사용자 |
| C. 수업 관찰 체크 | 나 | **나만** |
| D. 독서 기록장 | 나 | 우리 학교 도메인의 모든 사용자 |

> 📌 '나'로 실행하면 학생은 **시트를 직접 볼 수 없고**, 앱 화면을 통해서만 기록해요. 시트 자체의 공유 범위는 계속 **나만**으로 두세요.

> 💡 코드를 고친 뒤에는 [배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포]로 다시 배포해야 학생 화면에 반영돼요. URL은 그대로예요.

## 3. 실습① 태블릿 대여·반납 기록부 (A)

![태블릿 12대가 카드로 보이고, 대여 중인 기기는 주황색, 보관 중인 기기는 초록색으로 표시된 화면](/images/apps-script/a-board.jpg)

### ✋ 실습① 첫 웹앱 배포해 보기 (15분)

1. **A 시트 사본**을 만들고 *기기* 시트에 우리 반 기기 번호를 적어요.
2. 기본 5단계대로 코드를 붙여 넣고 배포해요.
3. 웹 앱 URL을 열어 기기 카드를 누르고 번호를 넣어 **빌리기**, 다시 눌러 **반납하기**를 해 봐요.
4. 시트의 *기록* 시트에 시각과 함께 기록이 쌓였는지 확인해요.

> 💡 교사 계정으로 열면 화면 아래에 **최근 기록 표**가 보이고, 학생 계정으로 열면 보이지 않아요.

## 4. 실습② 배움 기록장 + 평가 대시보드 (B)

차시마다 학생이 **배운 점·어려운 점·자기평가**를 남기고, 교사는 성취기준 **루브릭**(잘함·보통·노력 필요)과 피드백을 남기는 앱이에요. 기록이 학생별·성취기준별로 쌓여 **과정 중심 평가의 근거**가 돼요.

| 화면 | 할 수 있는 일 |
| --- | --- |
| **학생** | 열린 차시 고르기 → 그 차시의 평가 기준 확인 → 배운 점·어려운 점·자기평가(★1~3) 저장 → 내 기록과 선생님 피드백 보기 |
| **교사 · 차시별 평가** | 제출 현황(미제출 학생 표시), 학생마다 잘함·보통·노력 필요 + 피드백 저장 |
| **교사 · 학생별 누적** | 한 학생의 차시별 기록, 자기평가 평균, 평가 분포, **평가 근거 모아보기** |
| **교사 · 성취기준 현황** | 학생 × 차시 표로 평가와 자기평가를 한눈에 |

![학생 화면: 차시를 고르면 성취기준과 평가 기준이 보이고, 배운 점·어려운 점·자기평가를 적어 저장하는 화면](/images/apps-script/b-student.jpg)

![교사 화면: 차시별로 학생의 기록과 자기평가를 보고, 잘함·보통·노력 필요 단추와 피드백을 저장하는 화면](/images/apps-script/b-teacher.jpg)

### 6학년 국어 차시 예시 (시트 양식에 들어 있어요)

| 차시 | 성취기준 | 학습 주제 | 잘함 기준 |
| --- | --- | --- | --- |
| 1 | [6국02-01] | 글의 구조를 생각하며 내용 요약하기 | 글의 구조에 맞게 중심 내용을 간추려 요약함 |
| 2 | [6국03-02] | 근거를 들어 주장하는 글 쓰기 | 타당한 근거 2개 이상을 들고 인용 출처를 밝혀 씀 |
| 3 | [6국01-07] | 절차와 규칙을 지키며 토론하기 | 절차를 지키며 타당한 근거로 주장하고 반론함 |
| 4 | [6국05-02] | 비유적 표현의 효과를 생각하며 시 감상하기 | 비유적 표현을 찾고 그 효과를 자신의 말로 설명함 |
| 5 | [6국04-04] | 호응 관계가 올바른 문장 쓰기 | 문장 성분의 호응을 살펴 스스로 고쳐 씀 |
| 6 | [6국06-02] | 뉴스의 신뢰성 평가하기 | 출처·근거·관점을 기준으로 신뢰성을 평가함 |

### ✋ 실습② 배움 기록장 배포하고 평가까지 해 보기 (40분)

1. **B 시트 사본**을 만들어요.
2. *학생* 시트의 예시 이메일을 **옆 선생님의 학교 계정**(연수에서는 학생 역할)으로 바꿔요.
3. *차시* 시트에서 오늘 쓸 차시의 **열기**를 Y로 해요. 학생은 Y인 차시에만 기록할 수 있어요.
4. 코드를 붙여 넣고 **나 / 우리 학교 도메인** 으로 배포해요.
5. 학생 역할 선생님은 URL을 열어 배운 점과 자기평가를 저장해요.
6. 내 계정으로 URL을 열어 **차시별 평가**에서 루브릭과 피드백을 저장해요.
7. 학생 역할 선생님 화면을 새로고침해 **피드백이 보이는지** 확인해요.
8. **학생별 누적 → 평가 근거 모아보기**를 복사해 봐요.

![학생별 누적 화면: 기록 수, 자기평가 평균, 평가 분포와 차시별 기록, 평가 근거 모아보기 칸이 보이는 화면](/images/apps-script/b-student-summary.jpg)

> ⚠ 평가 근거 모아보기는 **교사가 남긴 평가와 학생 기록을 모은 재료**예요. 생활기록부 문장은 AI 초안을 그대로 쓰지 말고, 관찰한 사실을 바탕으로 교사가 직접 다듬어요.

## 5. 실습③④ 수업 관찰 체크(C)와 독서 기록장(D)

### C. 수업 관찰 체크 — 교사 혼자 쓰는 앱

토론·토의·발표처럼 **활동 중에 보이는 모습**을 태블릿으로 바로 기록해요. 학생 계정이 필요 없어 개인정보 부담이 가장 적어요.

1. 성취기준을 고르면 학생 번호 단추가 나와요. 단추 아래 **색 띠**는 가장 최근 관찰 수준이에요.
2. 학생을 누르고 수준과 **관찰 포인트 단추**(예: + 타당한 근거 제시)로 메모를 빠르게 채워요.
3. **학생별 모아보기**에서 성취기준별 관찰 기록과, 이름이 빠진 **과세특 초안 요청문**을 복사할 수 있어요.

![수업 관찰 체크 화면: 성취기준 선택, 학생 번호 단추, 수준 단추와 관찰 포인트 단추, 최근 기록 목록](/images/apps-script/c-check.jpg)

### D. 우리 반 독서 기록장

학생이 다 읽은 책을 기록하면 **내 책장**에 꽂히고, 학기 목표까지 진행 막대가 차요. 학급 화면에는 **전체 권수와 이번 달 많이 읽은 책**만 보이고, 학생별 독서량은 **교사 화면**에서만 보여요. 교사는 기록마다 **확인** 표시를 남길 수 있어요. 국어 [6국02-05] 읽기 동기·태도와 이어서 쓸 수 있어요.

![독서 기록장 학생 화면: 책 제목·지은이·별점·한 줄 감상을 적는 칸과, 목표 대비 진행 막대가 있는 나의 책장](/images/apps-script/d-student.jpg)

### ✋ 실습③④ 둘 중 하나 골라 배포하기 (15분)

1. C 또는 D의 **시트 사본**을 만들고, 기본 5단계대로 배포해요. 배포 설정은 위 표를 확인해요(C는 **나만**).
2. C라면 내 반 학생 번호를 넣고 관찰을 3건 기록해 본 뒤 **학생별 모아보기**를 열어요.
3. D라면 옆 선생님과 학생 역할을 바꿔 책을 기록하고, 교사 화면에서 **확인**을 눌러요.

## 6. AI로 고치고 새 앱 만들기

받은 코드는 출발점이에요. 우리 반에 맞게 고칠 때는 **코드 전체와 원하는 점**을 AI(Claude, Gemini 등)에게 함께 주면 돼요.

```prompt 기능 더하기 (B 예시)
아래는 구글 Apps Script 웹앱 코드(Code.gs와 Index.html)야.
학생 화면에 '다음 시간 나의 목표' 입력 칸을 하나 더 만들고,
시트의 '기록' 탭 맨 오른쪽 열에 저장되게 고쳐 줘.
교사 화면의 차시별 평가 표에도 그 내용이 보이게 해 줘.
바뀐 부분만이 아니라 두 파일 전체를 다시 보여 줘.

[Code.gs 붙여 넣기]
[Index.html 붙여 넣기]
```

```prompt 오류 고치기
구글 Apps Script 웹앱을 배포했는데 아래 오류가 나와.
원인과 고치는 방법을 초보자도 따라 할 수 있게 순서대로 알려 줘.
코드를 고쳐야 하면 고친 전체 코드를 보여 줘.

오류 메시지: [화면이나 실행 기록에 나온 오류를 그대로 붙여 넣기]
[관련 코드 붙여 넣기]
```

```prompt 새 앱 처음부터 만들기
구글 시트와 Apps Script로 초등학교 교실에서 쓸 웹앱을 만들고 싶어.
- 앱: [예) 우리 반 칭찬 릴레이 — 친구를 칭찬하는 글을 쓰면 칭찬 나무에 잎이 늘어남]
- 사용자: 학생은 학교 구글 계정으로 로그인해 자기 글만 쓰고, 교사는 전체를 봄
- 시트 구성: 어떤 탭과 열이 필요한지 먼저 표로 제안해 줘
- 배포: '나'로 실행, 우리 학교 도메인 사용자만 접근
- 조건: 학생 개인정보는 최소로, 서버(Code.gs)에서 교사 여부를 꼭 확인
처음 한 번 실행할 setup 함수, Code.gs, Index.html 전체 코드와 배포 방법을 알려 줘.
```

> 💡 처음부터 크게 만들지 말고, **작게 만들어 배포 → 써 보기 → 한 기능씩 더하기**를 반복하는 것이 실패가 적어요.

## 7. 개인정보·보안 수칙

1. **시트 공유는 '나만'**: 앱은 '나'로 실행되므로 학생에게 시트를 공유할 필요가 없어요.
2. **접근은 우리 학교 도메인으로**: '모든 사용자(익명 포함)'로 배포하지 않아요.
3. **최소한의 정보만**: 번호·이름·학교 계정 이메일 외에 연락처·주소·건강 정보는 넣지 않아요.
4. **교사 확인은 서버에서**: 받은 코드는 교사 여부를 Code.gs에서 확인해요. AI로 고칠 때도 이 부분을 지우지 않게 해요.
5. **평가 기준을 학생과 공유**: B 앱처럼 학생이 기록 전에 평가 기준을 볼 수 있게 해요.
6. **보관과 삭제**: 학년이 끝나면 학교 지침에 따라 기록을 정리해요. 시트 사본이 여기저기 남지 않게 해요.
7. **학생 동의 절차 확인**: 학생이 쓰는 서비스는 학교의 개인정보 동의 절차를 따라요.

## 8. 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 학생 화면에 "등록되지 않은 계정" | 학생 시트의 이메일 오타, 학생이 **다른 구글 계정**으로 로그인했는지(크롬 오른쪽 위 프로필), 교사와 학생 계정이 **같은 도메인**인지 |
| "확인되지 않은 앱" 경고 | 내가 만든 앱이라 뜨는 경고예요. [고급 → (안전하지 않음)으로 이동]을 눌러 승인해요. 학교 관리자 설정에 따라 막혀 있을 수 있어요 |
| 코드를 고쳤는데 그대로 | [배포 관리 → 수정 → **새 버전**]으로 다시 배포했는지 |
| "시트가 없어요" 오류 | 시트 탭 이름(설정·학생·차시·기록 등)을 바꾸지 않았는지. 새 시트에서 시작했다면 편집기에서 **setup** 함수를 한 번 실행 |
| "Index 파일을 찾을 수 없음" | HTML 파일 이름이 정확히 **Index**인지 |
