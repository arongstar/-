## 1. 챗봇과 AI 에이전트는 무엇이 다를까?

지금까지 우리가 써 온 ChatGPT 대화창은 **챗봇**이에요. 방법을 *말해* 주지만, 엑셀을 열어 복사·붙여넣기를 하는 건 결국 선생님 몫이었죠.

**AI 에이전트**는 목표만 주면 스스로 **계획 → 실행 → 확인**을 반복하며 일을 *해* 줍니다. 파일을 열어 읽고, 새 엑셀을 만들고, 웹페이지를 클릭하고, 결과가 이상하면 다시 고쳐요.

![챗봇은 방법을 글로 알려 주고 일은 내가 하지만, 에이전트는 계획·실행·확인을 반복해 완성된 파일과 보고를 돌려준다](/images/ai-agent-automation/chatbot-vs-agent.svg)

오늘 써 볼 에이전트는 두 가지예요.

| | 클로드 코드 (Claude Code) | AI 브라우저 |
| --- | --- | --- |
| 일하는 곳 | **내 컴퓨터의 폴더** | **인터넷 웹사이트** |
| 하는 일 | 파일 읽기·만들기·정리, 계산, 간단한 프로그램 만들기 | 클릭, 입력, 탭 이동, 페이지 읽고 정리 |
| 잘 맞는 업무 | 회신서 집계, 설문 분석, 파일 정리 | 자료 조사·비교, 양식 만들기, 긴 글 요약 |
| 대표 도구 | Claude 데스크톱 앱의 *Code* | Claude in Chrome, Comet 등 |

> 이름에 '코드'가 들어가지만 **코딩을 몰라도 돼요.** 우리말로 시키면 클로드가 필요한 프로그램을 스스로 짜서 실행합니다. 선생님은 *무엇을* 원하는지만 정확히 말하면 돼요.

## 2. 먼저 약속하기 — 에이전트 안전 수칙

![선생님이 자물쇠 방패를 들고 있고, AI 조수 로봇이 폴더를 든 채 손을 들어 허락을 구하는 모습](/images/ai-agent-automation/safety.jpg)

에이전트는 실제로 파일을 바꾸고 웹에서 클릭을 하기 때문에, 챗봇보다 **조심할 것**이 더 많아요.

1. **복사본에서 시작해요.** 실제 업무 파일은 복사한 폴더에서 작업하고, 원본은 그대로 둬요.
2. **개인정보는 최소한으로.** 학생 실명·연락처·건강 정보가 꼭 필요한 일인지 먼저 생각하고, 가능하면 번호나 가명으로 바꿔요. 학교·교육청의 AI 활용 지침을 따라요.
3. **중요한 행동은 내가 승인해요.** 파일 삭제·덮어쓰기, 메일 보내기, 제출·결제 전에는 에이전트가 반드시 묻도록 해요. (클로드 코드와 Claude in Chrome은 기본적으로 허락을 구해요.)
4. **학교 행정 시스템에는 쓰지 않아요.** 나이스, 업무포털(K-에듀파인), 은행처럼 중요한 사이트에 로그인한 상태로 AI 브라우저에 일을 맡기지 않아요.
5. **웹페이지의 '숨은 지시'를 조심해요.** 웹페이지에 숨겨진 글이 AI에게 엉뚱한 일을 시킬 수 있어요(프롬프트 인젝션). 처음 보는 사이트에서는 에이전트가 하는 일을 지켜봐요.
6. **결과는 반드시 대조해요.** 인원수·이름·날짜는 원본과 직접 비교해 확인해요.

## 3. 실습 ① 클로드 코드로 파일 업무 자동화

### 시작하기

1. Claude 데스크톱 앱을 열고 로그인해요.
2. 왼쪽 메뉴에서 **Code**를 고르고, 작업 폴더로 압축을 푼 **업무자동화-실습파일** 폴더를 선택해요.
3. 아래 입력창에 우리말로 일을 시키면 돼요. 클로드가 파일을 고치거나 명령을 실행하기 전에는 **허락을 구하는 창**이 떠요. 내용을 읽고 [허용]을 눌러요.

> 💡 화면 구성은 앱 버전에 따라 조금 다를 수 있어요. 'Code' 메뉴가 보이지 않으면 앱을 최신 버전으로 업데이트해 보세요.

먼저 아무것도 고치지 말고 폴더를 살펴보게 해요.

```prompt 첫 대화 — 폴더 살펴보기
이 폴더에 어떤 파일들이 있는지 살펴보고, 각 파일이 무엇인지 쉽게 설명해 줘.
아직 아무 파일도 고치거나 만들지 마.
```

### CLAUDE.md — 에이전트에게 '우리 학교 규칙' 알려 주기

실습 폴더의 **CLAUDE.md** 파일을 열어 보세요. 클로드는 일을 시작할 때 이 파일을 먼저 읽어요. "원본은 고치지 말 것", "결과는 결과 폴더에", "어려운 말 쓰지 말 것" 같은 규칙을 한 번 적어 두면 매번 말하지 않아도 지켜요.

```prompt 나만의 CLAUDE.md 만들기
나는 초등학교 담임교사야. 내 업무 방식을 알 수 있게 질문을 5개만 하나씩 해 줘.
대답을 다 들은 뒤에, 이 폴더의 CLAUDE.md에 추가할 규칙을 제안해 줘.
내가 확인하기 전에는 파일을 고치지 마.
```

### 실습 1 — 반마다 양식이 다른 회신서 합치기

세 반 선생님이 각자 만든 현장체험학습 회신서는 열 이름도, 표시 방법(참가/O/예)도 제각각이에요. 3반 파일에는 이름 띄어쓰기 실수와 중복 제출도 숨어 있어요.

```prompt 회신서 합치기 + 미제출자 찾기
'실습1_회신서' 폴더에 있는 세 반의 현장체험학습 회신서를 하나로 합쳐 줘.

- 반마다 열 이름과 표시 방법(참가/불참, O/X, 예/아니오)이 다르니 '참가'와 '불참'으로 통일해 줘.
- '3학년_명렬표'와 비교해서 회신서를 내지 않은 학생을 찾아 줘.
- 이름 띄어쓰기 실수나 중복 제출이 있으면 바로잡고, 무엇을 고쳤는지 알려 줘.
- 결과는 '결과' 폴더에 엑셀 파일 하나로 만들고, 시트를 [전체 명단] [반별 집계] [미제출자] [특이사항]으로 나눠 줘.

원본 파일은 고치지 마. 시작하기 전에 계획을 먼저 보여 줘.
```

결과가 나오면 **반별 인원수**를 원본 파일과 직접 대조해 보세요. 그다음 이어서 시켜요.

```prompt 담임 선생님별 안내 메모 만들기
방금 만든 결과로 각 반 담임 선생님께 보낼 짧은 메모를 반별로 써 줘.
미제출 학생 번호, 특이사항(알레르기·건강)이 있는 학생 번호, 참가 인원을 넣고,
메신저에 바로 붙여넣을 수 있게 '결과/반별_안내메모.txt'로 저장해 줘.
```

### 실습 2 — 설문 결과 분석 보고서

구글 설문지에서 내려받은 응답 파일(CSV)을 분석해요.

```prompt 설문 분석 보고서
'실습2_설문' 폴더의 학급 설문 응답을 분석해 줘.

1. 문항별 응답 비율을 반별로 비교한 표를 엑셀로 만들어 줘.
2. 눈에 띄는 결과 3가지를 찾아 줘. (예: 스마트폰 사용 시간이 많은 반)
3. '학교에 바라는 점' 자유 의견은 비슷한 것끼리 묶어서 주제별로 몇 건인지 세어 줘.
4. 막대그래프 이미지 2개를 만들어 줘. 그래프 글자는 한글이 깨지지 않게 해 줘.
5. 학년 협의회에서 읽을 수 있게 A4 한 장 분량의 요약 보고서를 워드(.docx)로 만들어 줘.

결과는 모두 '결과/설문분석' 폴더에 저장해 줘.
```

> 💡 그래프의 한글이 네모(□)로 깨지면 "그래프 한글이 깨졌어. 컴퓨터에 있는 한글 글꼴을 찾아서 다시 그려 줘"라고 말하면 돼요. 에이전트는 이렇게 **스스로 고치는 것**이 강점이에요.

### 실습 3 — 행사 사진 파일 정리

IMG_…, KakaoTalk_…, 스크린샷… 이름이 제각각인 사진을 학사일정에 맞춰 정리해요. 파일을 옮기는 작업이니 **계획을 먼저 보고 승인**하는 연습을 해요.

```prompt 사진 정리 — 계획 먼저
'실습3_사진정리' 폴더의 사진들을 정리하고 싶어.
파일 이름 속 날짜와 '학사일정.txt'를 보고 어떤 행사 사진인지 알아내서,
'결과/행사사진/행사이름' 폴더에 '2026-10-21_현장체험학습_01.jpg'처럼 이름을 바꿔 '복사'해 줘.

먼저 어떤 파일이 어떤 이름으로 바뀌는지 표로만 보여 주고,
내가 "진행해"라고 하기 전에는 아무것도 하지 마.
```

표를 확인하고 이상이 없으면 **"진행해"**라고 입력해요.

### 실습 4 — 우리 반 전용 도구 만들기

에이전트는 간단한 프로그램도 만들어 줘요. 클릭 한 번으로 모둠을 짜 주는 도구를 만들어 봐요.

```prompt 모둠 편성 도구 만들기
'3학년_명렬표'의 1반 학생들로 모둠을 짜 주는 웹페이지를 HTML 파일 하나로 만들어 줘.

- [모둠 짜기] 버튼을 누를 때마다 4명씩 무작위로 모둠을 새로 짜 줘.
- 모둠마다 남녀가 골고루 섞이게 해 줘.
- 교실 TV에 띄울 거라 글씨를 아주 크고 알록달록하게 해 줘.
- 인터넷이 없어도 열리게 해 줘.

'결과/모둠편성.html'로 저장하고, 여는 방법을 알려 줘.
```

만든 파일을 더블클릭하면 브라우저에서 열려요. 마음에 들지 않는 부분은 대화로 계속 고쳐요.

```prompt 도구 고치기
좋아! 이제 아래 기능을 더해 줘.
- 같이 앉으면 안 되는 학생 짝을 내가 정할 수 있게 해 줘.
- 모둠 이름을 동물 이름으로 붙여 줘.
- 결과를 인쇄하기 좋게 [인쇄] 버튼도 만들어 줘.
```

### 클로드 코드에 일 잘 맡기는 5가지 요령

1. **결과물로 말하기** — "정리해 줘"보다 "시트 4개짜리 엑셀로 만들어 줘"
2. **재료 위치 알려 주기** — 어느 폴더의 어떤 파일인지
3. **규칙 정하기** — 원본 보존, 개인정보, 저장 위치
4. **계획 먼저** — "시작하기 전에 계획을 보여 줘"
5. **확인 방법 요구하기** — "원본과 인원수가 맞는지 확인해서 알려 줘"

```prompt 무엇을 했는지 설명 듣기
방금 한 일을 순서대로 쉽게 설명해 줘.
어떤 파일을 읽고, 무엇을 새로 만들었고, 내가 직접 확인해야 할 부분은 어디인지 알려 줘.
```

## 4. 실습 ② AI 브라우저로 웹 업무 자동화

![선생님이 찻잔을 들고 놀란 표정으로 보는 가운데, 브라우저 안의 AI 조수 로봇이 여러 웹페이지 정보를 양식과 비교표로 모으는 모습](/images/ai-agent-automation/browser.jpg)

AI 브라우저는 웹페이지를 **보고, 클릭하고, 입력하는** 에이전트예요. 오늘은 둘 중 하나를 골라 써요.

| 도구 | 특징 |
| --- | --- |
| **Claude in Chrome** | 평소 쓰는 크롬에 확장 프로그램으로 설치. Claude 유료 요금제 필요. 사이트마다 허락을 받으며 일해요. |
| **Comet** (퍼플렉시티) | AI가 들어 있는 브라우저를 새로 설치. 무료로 쓸 수 있어요(사용량 제한 있음). |

> 💡 구글 크롬의 Gemini, ChatGPT 에이전트 등도 비슷한 기능을 제공하지만 요금제와 국내 제공 범위가 서로 달라요. 학교에서 쓸 수 있는지 먼저 확인하세요. (OpenAI의 브라우저 'ChatGPT Atlas'는 2026년 8월에 서비스를 종료했어요.)

### 실습 5 — 체험학습 장소 조사·비교

여러 사이트를 돌아다니며 정보를 모으는 일은 AI 브라우저가 가장 잘하는 일이에요.

```prompt 체험학습 장소 비교표
초등학교 3학년 과학 현장체험학습 장소를 찾고 있어. (지역: 우리 학교에서 1시간 이내, 지역 이름을 여기에 적기)
후보 4곳을 골라서 각 기관의 공식 홈페이지에 직접 들어가 아래 내용을 확인해 줘.

- 단체(학교) 관람 예약 방법과 예약 시작 시기
- 초등학생 단체 관람료
- 휴관일
- 3학년 과학 교육과정과 관련된 전시나 체험 프로그램

확인한 내용을 표로 정리하고, 근거가 된 페이지 주소를 꼭 함께 적어 줘.
홈페이지에서 확인하지 못한 내용은 '확인 필요'라고 써 줘.
```

AI가 탭을 열고 페이지를 넘기는 모습을 **지켜보세요.** 다 끝나면 표에 적힌 주소를 몇 개 직접 눌러 사실인지 확인해요.

### 실습 6 — 열린 탭 정리·요약

```prompt 열린 탭 요약 → 할 일 목록
지금 열려 있는 탭들의 내용을 읽고, 초등학교 3학년 담임교사에게 필요한 내용만 골라 줘.
마감 날짜가 있는 일은 날짜순으로 '할 일 목록'을 만들고, 각 항목에 출처 탭 제목을 붙여 줘.
```

> 교육청 공지, 연수 안내, 공모전 페이지 같은 것을 3~4개 열어 두고 해 보세요.

### 실습 7 — 구글 설문지 만들기

로그인이 필요한 사이트에서 '만들기'까지 맡겨 봐요. **만들기만 하고 보내기는 내가** 하는 것이 원칙이에요.

```prompt 구글 설문지 초안 만들기
구글 설문지(forms.google.com)에서 새 설문지를 만들어 줘.

제목: 3학년 현장체험학습 참가 동의서
문항:
1. 학생 반 (객관식: 1반, 2반, 3반) — 필수
2. 학생 번호 (단답형) — 필수
3. 참가 여부 (객관식: 참가, 불참) — 필수
4. 알레르기나 건강상 유의할 점 (장문형)
5. 보호자 연락 가능 시간 (체크박스: 오전, 오후, 저녁)

만들기만 하고, 공유하거나 보내지는 마. 다 만들면 미리보기 화면을 열어 줘.
```

### 실습 8 — 수업 영상 자료 찾기

```prompt 수업 영상 목록
유튜브에서 초등학교 4학년 과학 '물의 상태 변화' 수업에 쓸 영상을 찾아 줘.
- 5분 이하, 교육 기관이나 신뢰할 만한 채널 영상만
- 자극적인 썸네일이나 광고성 영상은 빼 줘
제목, 채널, 길이, 주소, 수업 어디에 쓰면 좋을지 한 줄 설명을 표로 정리해 줘.
```

> ⚠ 영상 내용은 수업 전에 선생님이 처음부터 끝까지 직접 확인해요.

## 5. 두 에이전트를 이어서 쓰기

AI 브라우저로 **모은 정보**를, 클로드 코드로 **문서로 만드는** 식으로 이어 쓰면 더 큰 일을 맡길 수 있어요.

1. AI 브라우저: 실습 5의 체험학습 비교표를 만들고 내용을 복사해요.
2. 클로드 코드: 아래 프롬프트에 붙여넣어요.

```prompt 조사 결과 → 가정통신문 초안
아래는 현장체험학습 장소 조사 결과야. 이 가운데 [장소 이름]으로 가기로 했어.
이 내용으로 학부모님께 보낼 현장체험학습 안내 가정통신문 초안을 워드(.docx)로 만들어 줘.

- 일시, 장소, 준비물, 비용은 표로
- 회신서(참가 동의) 절취선 양식을 맨 아래에
- 날짜와 시간은 [  ] 빈칸으로

(여기에 조사 결과 붙여넣기)
```

## 6. 우리 학교 업무에 적용하기

**활동지**를 내려받아 함께 해 봐요.

1. 한 달 동안 반복하는 업무를 적고, **파일 / 웹 / 학교 시스템** 중 어디에서 일어나는 일인지 표시해요.
2. 하나를 골라 **목표·재료·규칙·결과물·확인 방법**으로 에이전트에게 줄 지시문을 설계해요.
3. 가상 데이터나 복사본으로 직접 시켜 보고, 옆 선생님과 결과를 나눠요.

```prompt 내 업무 자동화 아이디어 얻기
나는 초등학교 [학년] 담임이고, [업무 분장: 예) 방과후학교 담당]을 맡고 있어.
내가 매달 반복하는 일은 이런 것들이야: [반복 업무 나열]

이 가운데 AI 에이전트(내 컴퓨터 파일을 다루는 클로드 코드, 웹을 다루는 AI 브라우저)에
맡기기 좋은 일 3가지를 골라 주고, 각각 어떻게 지시하면 좋을지 예시 프롬프트를 써 줘.
개인정보나 학교 행정 시스템 때문에 사람이 직접 해야 하는 부분도 함께 짚어 줘.
```
