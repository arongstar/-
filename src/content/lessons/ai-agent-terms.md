## 1. 큰 그림

![AI 도구는 모델 → 앱 → 일 잘하게(스킬·메모리·프로젝트) → 밖과 연결(커넥터·MCP) → 묶음(플러그인) → 일하는 곳(앱·브라우저·CLI) 순서로 쌓여 있어요](/images/ai-agent-terms/layers.svg)

### 모델과 앱 — 엔진과 자동차

- **모델** 은 AI의 **두뇌(엔진)** 예요. 글을 이해하고 답을 만드는 부분이에요.
- **앱** 은 그 엔진을 얹은 **자동차** 예요. 우리가 보고 누르는 화면이에요.
- 같은 앱이라도 **요금제마다 쓰는 엔진(모델)이 달라요.** 무료는 가벼운 모델, 유료는 더 똑똑한 모델을 써요.

| | <img class="ai-ico" src="/images/ai-agent-terms/icons/gemini.svg" alt="">제미나이 | <img class="ai-ico" src="/images/ai-agent-terms/icons/chatgpt.svg" alt="">챗GPT | <img class="ai-ico" src="/images/ai-agent-terms/icons/claude.svg" alt="">클로드 |
| --- | --- | --- | --- |
| 만든 회사 | Google | OpenAI | Anthropic |
| 앱 | 제미나이 앱 (gemini.google.com · 휴대폰) | 챗GPT 앱 (웹 · 데스크톱 · 휴대폰) | 클로드 앱 (claude.ai · 데스크톱 · 휴대폰) |
| 모델 이름 예 (2026년 11월) | Gemini 4 Argon 등 | GPT-6 등 | Claude Opus 5.5, Fable 5.2 등 |

> ⚠ 모델 이름은 몇 달마다 바뀌어요. 교안의 모델 이름은 **예시** 로만 보고, 내 앱의 모델 고르는 칸에서 확인해요.

### 챗봇과 에이전트 — 말하는 AI, 일하는 AI

- **챗봇**: 물으면 **답(글)** 을 줘요. 실제로 일을 하는 건 사람이에요.
- **에이전트**: 스스로 **계획을 세우고** 웹사이트를 열고, 클릭하고, 입력하고, 파일을 만들어 **일을 끝내요.** 대신 실수할 위험도 있어서 중요한 순간에는 사람에게 확인을 받아요.

| | <img class="ai-ico" src="/images/ai-agent-terms/icons/gemini.svg" alt="">제미나이 | <img class="ai-ico" src="/images/ai-agent-terms/icons/chatgpt.svg" alt="">챗GPT | <img class="ai-ico" src="/images/ai-agent-terms/icons/claude.svg" alt="">클로드 |
| --- | --- | --- | --- |
| 에이전트 기능 | **작업(tasks)** — 채팅 시작하는 곳에서 바로 일 맡기기, 예약 실행 | **Work** — 여러 단계 일을 해서 문서 · 시트 · 슬라이드까지 (예전 이름 ChatGPT agent) | **Cowork** — 채팅과 하나로 합쳐지는 중 |
| 브라우저에서 | Chrome의 Gemini | 크롬 확장 사이드바 (전용 브라우저 Atlas는 2026년 8월 종료) | Claude in Chrome (크롬 확장) |
| 쓸 수 있는 사람 | Google AI Pro · Ultra, 18세 이상, 개인 계정 | 요금제 · 기기마다 다름 | 유료 요금제 |

> 📌 에이전트 이야기는 「AI 에이전트로 학교 업무 자동화하기」, 「AI 브라우저 Aside」, 「피클」 교안에서 실습해요.

## 2. 다섯 낱말 — 스킬 · 플러그인 · 커넥터 · MCP · CLI

![플러그인 상자 안에 스킬(업무 매뉴얼)과 커넥터(연결 케이블), 명령이 들어 있고, 커넥터는 MCP라는 공통 규격으로 메일·캘린더·드라이브·노션에 이어져요. 일하는 곳은 채팅 앱·브라우저·CLI예요](/images/ai-agent-terms/five-words.svg)

| 낱말 | 비유 | 한 줄 뜻 |
| --- | --- | --- |
| **스킬** | 📒 업무 매뉴얼 | 자주 하는 일의 방법을 적어 AI에게 맡겨 둔 설명서 |
| **플러그인** | 📦 꾸러미 상자 | 스킬 · 커넥터 · 명령을 한 상자에 담아 한 번에 설치 |
| **커넥터** | 🔌 연결 케이블 | AI가 메일 · 캘린더 · 드라이브 같은 다른 서비스를 보고 쓰게 이어 줌 |
| **MCP** | 🔋 공용 멀티탭 규격 | 어느 AI든 같은 모양의 플러그로 서비스에 꽂게 해 주는 약속 |
| **CLI** | ⌨️ 글자 명령 창 | 마우스 대신 글자로 명령하는 검은 창. 그 안에서 AI가 파일을 다뤄요 |

### 스킬 — 📒 업무 매뉴얼

"가정통신문은 이런 순서로, 이런 말투로 써 줘"처럼 **자주 하는 일의 방법** 을 적어 AI에게 맡겨 두는 거예요. 한 번 만들어 두면 이름만 불러도 그 방법대로 일해요. 필요한 때를 AI가 알아서 알아보고 쓰기도 해요.

| | <img class="ai-ico" src="/images/ai-agent-terms/icons/gemini.svg" alt="">제미나이 | <img class="ai-ico" src="/images/ai-agent-terms/icons/chatgpt.svg" alt="">챗GPT | <img class="ai-ico" src="/images/ai-agent-terms/icons/claude.svg" alt="">클로드 |
| --- | --- | --- | --- |
| 이름 | **스킬** (예전 **Gems** 가 스킬로 바뀌는 중) | **Skills** | **Skills(스킬)** |
| 쓰는 법 | 채팅에서 `/` + 스킬 이름 | 데스크톱 앱 · Codex에서, 웹은 플러그인으로 | 사용자 지정 › 스킬에서 켜기 |
| 누가 | 18세 이상, 개인 Google 계정 | 요금제 · 기기마다 다름 | 무료 포함 모든 요금제 (코드 실행 켜기) |

> 📌 **Gems → 스킬**: 개인 계정은 2026년 11월부터 Gems가 스킬로 바뀌어요. 만들어 둔 Gem은 자동으로 스킬로 옮겨지고, 학교 · 업무 계정은 2027년에 바뀌어요.

> 💡 스킬은 **세 회사가 비슷한 모양(SKILL.md라는 설명서 파일)** 으로 만들어요. 클로드가 처음 공개한 방식이 업계 공통 약속(Agent Skills)으로 자리 잡는 중이에요.

### 플러그인 — 📦 꾸러미 상자

**스킬 + 커넥터 + 명령** 을 한 상자에 담아 **한 번에 설치** 하는 묶음이에요. "수업 준비 플러그인"을 설치하면 수업 설계 스킬, 드라이브 커넥터, 자주 쓰는 명령이 한꺼번에 들어오는 식이에요.

| | <img class="ai-ico" src="/images/ai-agent-terms/icons/gemini.svg" alt="">제미나이 | <img class="ai-ico" src="/images/ai-agent-terms/icons/chatgpt.svg" alt="">챗GPT | <img class="ai-ico" src="/images/ai-agent-terms/icons/claude.svg" alt="">클로드 |
| --- | --- | --- | --- |
| 이름 | (같은 이름의 기능 없음 — 연결된 앱과 스킬로) | **Plugins** — 사이드바. 예전 앱 · 커넥터 목록이 플러그인 목록이 됐어요 | **Plugins(플러그인)** — 사용자 지정 › 플러그인, 클로드 코드는 `/plugin` |
| 알아 둘 것 | — | 맞춤 비서 **GPTs** 는 2026년 12월 11일 종료하고 플러그인으로 옮긴다고 발표했어요 | 공식 목록은 유료 요금제에서 보여요 |

> ⚠ "플러그인"은 회사마다 뜻이 조금씩 달랐어요. 2023년 챗GPT의 옛 플러그인과 오늘의 플러그인은 다른 기능이에요. **지금은 '여러 기능을 묶은 꾸러미'** 로 기억하면 돼요.

### 커넥터 — 🔌 연결 케이블

AI가 **다른 서비스(메일 · 캘린더 · 드라이브 · 노션)를 열어 보고 쓰게** 이어 주는 케이블이에요. 이어 두면 "이번 주 학년 협의 메일 요약해 줘"처럼 내 메일을 직접 읽고 일할 수 있어요.

| | <img class="ai-ico" src="/images/ai-agent-terms/icons/gemini.svg" alt="">제미나이 | <img class="ai-ico" src="/images/ai-agent-terms/icons/chatgpt.svg" alt="">챗GPT | <img class="ai-ico" src="/images/ai-agent-terms/icons/claude.svg" alt="">클로드 |
| --- | --- | --- | --- |
| 이름 | **연결된 앱 (Connected Apps)** | **앱 · 커넥터** (지금은 플러그인 안에) | **Connectors(커넥터)** |
| 예 | Gmail · Docs · Drive · Calendar · Keep · Tasks | 드라이브 · 메일 등 | 구글 드라이브 · 노션 · 캘린더 등 |
| 부르는 법 | 입력창에 `@` + 앱 이름 | 플러그인에서 켜기 | 채팅 `+` › 커넥터 |

> ⚠ 커넥터를 이으면 AI가 그 계정을 **넓게** 읽을 수 있어요. 학교 업무 메일 · 학생 정보가 든 드라이브는 잇지 않아요.

### MCP — 🔋 공용 멀티탭 규격

**MCP(Model Context Protocol)** 는 커넥터를 만드는 **공통 규격** 이에요. 나라마다 콘센트 모양이 다르면 불편하죠? MCP는 "AI와 서비스를 잇는 플러그 모양을 하나로 맞추자"는 약속이에요. 한 번 MCP로 만든 연결은 **제미나이 · 챗GPT · 클로드 어디에나** 꽂을 수 있어요.

- **누가 만들었나**: 2024년 11월 Anthropic(클로드 회사)이 공개했고, 2025년 12월 리눅스 재단의 AI 에이전트 재단(AAIF)에 기증해 모두의 규격이 됐어요.
- **우리가 직접 MCP를 만들 일은 거의 없어요.** 커넥터 · 플러그인 목록에서 고르기만 하면 그 뒤에서 MCP가 일해요.

| | <img class="ai-ico" src="/images/ai-agent-terms/icons/gemini.svg" alt="">제미나이 | <img class="ai-ico" src="/images/ai-agent-terms/icons/chatgpt.svg" alt="">챗GPT | <img class="ai-ico" src="/images/ai-agent-terms/icons/claude.svg" alt="">클로드 |
| --- | --- | --- | --- |
| 내가 MCP 주소로 직접 잇기 | **맞춤 앱** — 지금은 미국 · 18세 이상 · 영어만 | 플러그인 › **맞춤 MCP 서버 추가** | **맞춤 커넥터** (원격 MCP), 무료는 1개 |

### CLI — ⌨️ 글자 명령 창

**CLI(명령줄)** 는 마우스 대신 **글자로 명령하는 검은 창(터미널)** 이에요. 여기에 AI를 부르면 내 컴퓨터의 **파일과 폴더를 직접** 만들고 고치고 정리해요. 원래 개발자 도구지만, 요즘은 선생님도 "이 폴더의 회신서를 한 파일로 합쳐 줘" 같은 일에 써요.

| | <img class="ai-ico" src="/images/ai-agent-terms/icons/gemini.svg" alt="">Google | <img class="ai-ico" src="/images/ai-agent-terms/icons/chatgpt.svg" alt="">OpenAI | <img class="ai-ico" src="/images/ai-agent-terms/icons/claude.svg" alt="">Anthropic |
| --- | --- | --- | --- |
| 이름 | **Antigravity CLI** (개인용) · Gemini CLI는 2026년 6월부터 기업용 | **Codex CLI** | **Claude Code(클로드 코드)** |
| 요금 | Antigravity 무료 요금제 있음 | 무료 포함(사용량 한도) | Pro 이상 유료 |

> 💡 CLI가 어렵다면 **데스크톱 앱 안의 코드 · 작업 탭** 을 써도 돼요. 같은 에이전트를 마우스로 쓰는 창이에요. 클로드 코드는 「AI 에이전트로 학교 업무 자동화하기」 교안에서 실습해요.

### 그 밖에 자주 듣는 말

| 낱말 | 쉬운 뜻 |
| --- | --- |
| 프롬프트 | AI에게 하는 부탁 · 지시 글 |
| 토큰 | AI가 글을 세는 단위(낱말 조각). 사용량 · 요금의 기준 |
| 컨텍스트 (창) | AI가 한 번에 기억하며 볼 수 있는 대화 · 자료의 양 |
| 할루시네이션 | AI가 그럴듯하게 **지어낸** 틀린 답. 사실은 꼭 확인 |
| 메모리 | AI가 나에 대해 기억해 두는 메모장. 고치고 지울 수 있어요 |
| 프로젝트 | 한 주제의 자료 · 대화를 모아 두는 방 |
| 아티팩트 · 캔버스 | 대화 옆에 결과물(문서 · 웹페이지 · 그림)을 만드는 창 |
| 딥 리서치 | 여러 사이트를 오래 찾아 출처가 붙은 보고서로 정리 |
| API | 프로그램끼리 AI를 부르는 연결 통로. 앱 구독과 따로, 쓴 만큼 돈을 내요 |
| 구독 | 월정액을 내고 앱을 쓰는 것. 사용량 한도가 있어요 |

## 4. 실습

### ✋ 실습① 내가 쓰는 AI에서 다섯 낱말 찾기 (8분)

1. 평소 쓰는 AI 앱을 열어요.
2. 위 **한눈에 비교** 표에서 내 AI 칸을 보며 **스킬 · 플러그인 · 커넥터** 가 어디 있는지 찾아요.
3. 찾은 메뉴 이름을 활동지에 적어요. 없으면 "없음", 유료만이면 "유료"라고 적어요.
4. 옆 선생님과 다른 AI를 쓴다면 서로 화면을 보여 주며 비교해요.

```prompt 낯선 용어 풀어 달라고 하기
나는 초등학교 선생님이고 AI를 이제 막 쓰기 시작했어.
'커넥터', '플러그인', 'MCP'가 무엇인지 학교 생활에 빗대어 쉬운 말로 설명해 줘.
각각 한 문장 비유 + 선생님이 쓸 만한 예 하나씩. 전문 용어는 쓰지 마.
```

### ✋ 실습③ 나만의 첫 스킬 지침 써 보기 (6분)

스킬은 결국 **잘 쓴 업무 매뉴얼** 이에요. AI에게 초안을 받아 내 말로 고쳐요. 클로드 · 제미나이 · 챗GPT 어디서든 할 수 있어요.

```prompt 스킬 지침 초안 만들기
'가정통신문 도우미' 스킬의 지침을 만들고 싶어. 초등학교에서 쓸 거야.
아래 내용을 넣어서, AI가 읽고 그대로 따라 할 수 있는 지침을 10줄 이내로 써 줘.
- 언제 쓰는지: 행사 · 안내 가정통신문을 쓸 때
- 순서: 인사 → 목적 → 일시 · 장소 · 준비물 표 → 회신 안내 → 맺음말
- 말투: 학부모님께 정중하고 짧은 문장, 어려운 한자어는 쉬운 말로
- 꼭 지킬 것: 학생 이름 · 연락처 같은 개인정보는 넣지 않기, 날짜 · 금액은 [ ]로 비워 두기
```

> 💡 이렇게 만든 지침을 클로드는 **사용자 지정 › 스킬**, 제미나이는 **스킬 만들기** 에 넣으면 진짜 스킬이 돼요. 챗GPT는 데스크톱 앱이나 플러그인에서 써요.

```prompt 연결하기 전에 물어보기
지금 [플러그인 · 커넥터 이름]을 연결하려고 해.
연결하면 네가 내 계정에서 무엇을 볼 수 있고, 무엇을 바꾸거나 보낼 수 있는지 쉬운 말로 정리해 줘.
학교 업무용 계정에 연결해도 괜찮은지, 조심할 점은 무엇인지도 알려 줘.
```

| --- | --- | --- | --- |
| 기본 연령 | 한국은 만 14세부터 스스로 Google 계정 관리 (그보다 어리면 보호자가 Family Link로) | 13세 이상, 18세 미만은 보호자 동의 | **18세 이상** |
| 에이전트 · 메모리 · 스킬 | 대부분 18세 이상 | 요금제 · 나이마다 다름 | 18세 이상 |

- **초등학생이 자기 계정으로 직접 쓰기는 어려워요.** 수업에서는 **선생님이 시연** 하거나, 학교가 승인한 교육용 서비스를 써요.
- **커넥터 · 플러그인은 믿을 수 있는 것만**: 웹페이지나 파일 속에 AI를 속이는 숨은 지시가 들어 있을 수 있어요. 출처가 분명한 공식 목록에서 골라요.
- **학교 업무 계정 · 학생 정보는 연결하지 않아요.** 나이스 · 업무포털 · 학생 정보가 든 드라이브는 AI에 잇지 않아요.
- **메모리는 가끔 열어 봐요.** 잘못 기억한 내용, 남기고 싶지 않은 내용은 지워요.
- **이름보다 뜻을 기억해요.** 내일 이름이 바뀌어도 매뉴얼(스킬) · 꾸러미(플러그인) · 케이블(커넥터) · 규격(MCP) · 글자 창(CLI)은 그대로예요.
