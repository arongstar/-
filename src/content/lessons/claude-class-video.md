## 1. 영상이 '글'이 되었어요

지금까지 영상은 편집 프로그램에서 자막과 그림을 하나하나 끌어다 놓아 만들었어요. 이제는 영상을 **웹페이지처럼 글(HTML·코드)로** 만들 수 있어요. 글이니까 클로드가 읽고, 쓰고, 고칠 수 있고, 다 되면 컴퓨터가 한 장면씩 찍어 **MP4 영상**으로 바꿔 줘요.

오늘 만들 영상부터 볼게요. 클로드에게 말로만 시켜서 만든 43초짜리 4학년 과학 수업 영상이에요.

**수업에 잘 맞는 영상**: 1분 안팎의 개념 설명, 단원 도입 질문, 모둠 활동 안내와 타이머, 퀴즈, 수업 정리 카드, 학급 행사 인트로

## 2. 도구 세 가지

| 도구 | 하는 일 | 오늘 | 쓰는 조건 |
| --- | --- | --- | --- |
| **HyperFrames** | 웹페이지(HTML)로 만든 화면을 그대로 영상으로 | **주로 씀** | 무료 오픈소스 (Apache-2.0) |
| **Remotion** | 영상을 React 코드로. 그래프·정교한 애니메이션에 강함 | 맛보기 | 개인·소규모 무료, 규모가 큰 회사는 유료 |
| **OpenMontage** | 주제만 주면 조사→대본→음성→자막→편집까지 이어서 | 소개 | 오픈소스 (AGPL-3.0), 일부 기능은 유료 API 키 |

> 💡 처음에는 **HyperFrames 하나**로 충분해요. 셋 다 클로드 코드 안에서 "스킬"로 쓰기 때문에, 클로드가 도구 사용법을 알고 일해요.

## 3. 준비하기 — 설치는 클로드에게 맡겨요

### ✋ 실습 준비 — HyperFrames 설치 (10분)

1. Claude 데스크톱 앱을 열고 왼쪽 메뉴에서 **Code** 를 골라요.
2. 작업 폴더를 하나 만들어 골라요. 예: 바탕화면의 `수업영상` 폴더
3. 아래 요청문을 붙여 넣어요. 프로그램을 설치하거나 명령을 실행하기 전에 **허락을 구하는 창**이 뜨면 읽고 [허용]을 눌러요.

```prompt 영상 도구 설치 부탁하기
이 컴퓨터에서 수업 영상을 만들 수 있게 준비해 줘.
1. Node.js 22 이상과 FFmpeg가 있는지 확인하고, 없으면 설치해 줘.
2. HyperFrames 클로드 스킬을 설치해 줘. (npx skills add heygen-com/hyperframes)
3. 다 되면 'npx hyperframes doctor'로 점검하고, 결과를 쉬운 말로 설명해 줘.
명령을 실행하기 전에는 무엇을 하는 명령인지 먼저 알려 줘.
```

직접 입력하고 싶은 분은 이렇게 하면 돼요. (클로드 코드 플러그인으로 설치하는 방법도 있어요: `claude plugin marketplace add heygen-com/hyperframes` → `claude plugin install hyperframes@hyperframes`)

```
npx skills add heygen-com/hyperframes
npx hyperframes doctor
```

> ⚠ 학교 업무용 컴퓨터는 프로그램 설치가 막혀 있는 경우가 많아요. 연수에서는 개인 노트북을 쓰고, 학교 컴퓨터에는 정보 담당 선생님과 상의해 설치해요.

## 4. 수업 영상 만드는 5단계

![목표 한 문장 → 장면 설계 → 클로드에게 요청 → 보고 말로 고치기 → MP4로 렌더링](/images/claude-class-video/flow.svg)

영상을 잘 만드는 비결은 프롬프트 기술보다 **원하는 것을 구체적으로 전하는 것**이에요.

- **추상적인 말 대신 숫자로**: "짧고 깔끔하게"보다 "43초, 가로 1920×1080, 장면 6개, 글자는 80px 이상"
- **장면마다 메시지 하나**: 한 장면에 글자를 많이 넣지 않아요. 학생이 읽을 시간(한 문장에 3초 이상)을 줘요.
- **참고 자료를 글로 풀어서**: 마음에 드는 영상이 있으면 "바탕색·글꼴·자막 위치·움직임 속도"를 말로 적어 주면 훨씬 비슷하게 나와요.
- **시안을 여러 개**: "느낌이 다른 시안 3개를 만들어 줘"라고 하면 고르기 쉬워요.
- **계획 먼저**: "만들기 전에 장면별 계획을 표로 보여 줘"

## 5. ✋ 실습① 개념 설명 영상 — 「물의 상태 변화」 따라 만들기

설명 영상은 **아이들이 아는 장면 하나**에서 시작해 그 장면이 변하는 모습으로 개념을 보여 주면 좋아요. 이 영상은 '얼음물 한 컵' 하나로 녹음·응결·증발을 모두 보여 줘요.

### 1단계 — 장면 설계 (스토리보드)

| 시간 | 화면에 보이는 것 | 화면 글자 |
| --- | --- | --- |
| 0~5초 | 책상 위 얼음물 한 컵 | 얼음물 한 컵을 교실에 두면 어떻게 될까요? |
| 5~12초 | 얼음이 작아지다 사라짐 (물 높이는 그대로) | 얼음 → 물 · 얼음이 녹아요 |
| 12~20초 | 공기 중 점들이 컵으로 모여 물방울이 맺힘 | 수증기 → 물 · 응결 |
| 20~27초 | 며칠 뒤, 물 높이가 내려가고 점이 위로 | 물 → 수증기 · 증발 |
| 27~37초 | 얼음·물·수증기와 화살표가 하나씩 | 따뜻해지면 → / ← 차가워지면 |
| 37~43초 | 정리 문장과 질문 | 우리 교실에서 또 찾아볼까요? |

![얼음이 녹는 장면: 왼쪽에 얼음이 작아진 컵, 오른쪽에 '얼음 → 물, 얼음이 녹아요'](/images/claude-class-video/melt.jpg)

### 2단계 — 클로드에게 요청하기

```prompt 개념 설명 영상 만들기 (물의 상태 변화)
HyperFrames로 초등학교 4학년 과학 「물의 상태 변화」 수업 영상을 만들어 줘.
교실 TV에 띄우고 내가 설명하며 틀 거라 내레이션과 음악은 넣지 마.

- 길이 43초, 가로 1920×1080, 30fps
- 글꼴은 Pretendard, 바탕은 크림색, 글자는 남색
- 따뜻해지는 변화는 주황, 차가워지는 변화는 파랑으로 표시
- 화면 왼쪽에는 책상 위 얼음물 컵 하나를 계속 두고, 그 컵이 바뀌면서 설명해 줘.
- 오른쪽에는 큰 글자로 장면 설명 (제목 80px 이상)

장면은 아래 표대로 해 줘.
(여기에 스토리보드 표를 붙여 넣기)

과학 개념은 초등 4학년 수준으로, '열' 대신 '따뜻해지면/차가워지면'이라고 써 줘.
만들기 전에 장면별 계획을 먼저 보여 주고, 내가 확인하면 만들어 줘.
```

### 3단계 — 과학 개념은 선생님이 검토해요

AI는 그럴듯하지만 **틀린 그림**을 그릴 수 있어요. 이 영상을 만들 때도 이런 점을 직접 확인했어요.

> ⚠ **떠 있는 얼음이 녹아도 컵 속 물 높이는 그대로예요.** 얼음이 녹으며 물이 차오르는 그림은 틀린 그림이에요.

> ⚠ 주전자에서 나오는 하얀 김은 수증기가 아니라 **아주 작은 물방울**이에요. 그래서 영상에서는 수증기를 "눈에 보이지 않아요"라고 표시했어요.

> 💡 학년 수준에 맞는 말인지도 살펴요. 4학년에게는 '열을 얻는다'보다 '따뜻해지면'이 쉬워요.

![응결 장면: 컵 겉면에 물방울이 맺히고, '공기 중의 수증기가 차가운 컵에 닿아 물이 돼요. 이것을 응결이라고 해요.'](/images/claude-class-video/condense.jpg)

### 4단계 — 보고, 말로 고치기

미리보기를 보면서 **눈에 띄는 것을 그대로 말하면** 돼요. 이 영상을 만들며 실제로 고친 말이에요.

```prompt 말로 고치기 예시
- 첫 장면이 4초 동안 아무 변화가 없어서 지루해. 질문 아래에 "컵 속 얼음, 컵 겉면, 물의 양을 잘 살펴보세요"를 2초쯤에 띄워 줘.
- 정리 그림에서 아래쪽 화살표가 '액체' 글자를 가려. 화살표를 조금 아래로 내려 줘.
- 마지막 문장이 '모습이 / 바뀌어요'로 어색하게 끊겨. '물은 따뜻해지거나 차가워지면 / 모습이 바뀌어요'로 두 줄로 나눠 줘.
- 장면마다 화면을 한 장씩 캡처해서 보여 줘.
```

![정리 그림: 얼음·물·수증기 사이를 '따뜻해지면'(주황)과 '차가워지면'(파랑) 화살표가 잇는 장면](/images/claude-class-video/cycle.jpg)

### 5단계 — MP4로 만들기

```prompt 영상 파일로 만들기
점검(check)을 한 번 더 하고, 문제가 없으면 MP4로 렌더링해 줘.
파일 이름은 '4학년과학_물의상태변화.mp4'로 하고, 어디에 저장했는지 알려 줘.
```

> 💡 만든 영상은 교실 TV로 바로 틀거나, 패들렛·클래스룸에 올려 복습용으로 써요. **영상 원본 묶음**을 클로드에게 주고 "이 영상을 5학년 과학 「용해와 용액」으로 바꿔 줘"라고 하면 같은 틀로 다른 단원 영상을 금방 만들 수 있어요.

## 6. ✋ 실습② 우리 수업 도입·인트로 영상

수업이나 연수를 시작할 때 10~15초짜리 짧은 영상 하나로 분위기를 열어요.

<video controls preload="none" poster="/images/claude-class-video/intro-hook.jpg" src="/files/claude-class-video/연수인트로.mp4"></video>

<p class="video-caption">연수 인트로 예시 — 한 줄 메시지 → 소개 → 끝 화면 (12.5초)</p>

```prompt 단원 도입 영상 (빈칸 채우기)
HyperFrames로 초등 [학년] [교과] 「[단원]」 도입 영상을 15초로 만들어 줘.
- 1장면: 학생들이 궁금해할 질문 한 줄 "[질문]" 을 크게, 단어마다 나타나게
- 2장면: 오늘 배울 것 세 가지를 번호와 함께 하나씩
- 3장면: "[단원 이름]" 끝 화면
가로 1920×1080, 글꼴 Pretendard, 바탕은 [색], 강조색은 [색]. 소리는 넣지 마.
첫 화면부터 글자가 보이게 해 줘 (영상 썸네일이 비지 않게).
```

> 💡 끝 화면의 문구를 **바꿀 수 있는 칸**으로 만들어 달라고 하면, 단원마다 문구만 바꿔 여러 개를 금방 만들 수 있어요. ("끝 화면 제목과 부제는 나중에 바꾸기 쉽게 변수로 만들어 줘")

## 7. ✋ 실습③ 수업 활동 영상 — 타이머·퀴즈·정리 카드

수업 중에 TV에 띄워 두는 영상도 쉽게 만들 수 있어요. 하나를 골라 만들어 봐요.

```prompt 모둠 활동 타이머 영상
5분짜리 모둠 활동 안내 영상을 만들어 줘.
- 화면 위: "모둠 토의 — 우리 고장의 자랑거리 3가지 찾기"
- 가운데: 남은 시간이 숫자와 줄어드는 막대로 보이게 (5:00 → 0:00)
- 1분 남았을 때 막대가 주황색으로 바뀌고 "1분 남았어요!" 표시
- 끝나면 "활동 끝! 모둠 칠판에 정리해요"
교실 뒤에서도 보이게 숫자는 아주 크게. 소리는 넣지 마.
```

```prompt 퀴즈 카운트다운 영상
6학년 국어 「비유하는 표현」 확인 퀴즈 영상을 만들어 줘.
문제 3개, 각 문제마다: 문제 보여 주기(5초) → 10초 카운트다운 → 정답과 짧은 설명(5초)
정답은 카운트다운이 끝난 뒤에만 나오게 해 줘.
문제와 정답은 만들기 전에 표로 먼저 보여 줘. 내가 확인할게.
```

```prompt 수업 정리 카드 영상
오늘 수업 내용을 20초짜리 정리 카드 영상으로 만들어 줘.
핵심 문장 3개를 한 장면에 하나씩, 마지막에 "다음 시간에는 ○○을 알아봐요"
(여기에 오늘 수업 핵심 내용 붙여 넣기)
```

> ⚠ 퀴즈·정리 영상의 **문제와 정답은 꼭 선생님이 확인**해요. 만들기 전에 표로 먼저 받아 보면 고치기 쉬워요.

## 8. 더 나아가기 — Remotion과 OpenMontage

### Remotion — 그래프·데이터 영상

학급 설문 결과 그래프가 자라나는 영상, 지도가 확대되는 영상처럼 정교한 장면에 좋아요.

```prompt Remotion 스킬 설치와 그래프 영상
Remotion 공식 스킬을 설치해 줘. (npx skills add remotion-dev/skills)
그다음 Remotion으로 '우리 반이 좋아하는 계절' 막대그래프가 하나씩 자라는 10초 영상을 만들어 줘.
봄 8명, 여름 6명, 가을 9명, 겨울 4명. 숫자는 막대 위에, 글꼴은 Pretendard.
```

> 📌 Remotion은 개인·소규모 사용은 무료지만, 규모가 큰 회사는 유료 라이선스가 필요해요. 학교 수업용은 대개 문제없지만, 쓰기 전에 클로드에게 "Remotion 라이선스 조건을 알려 줘"라고 확인해 보세요.

### OpenMontage — 주제만 주면 영상 제작 공장처럼

주제를 말하면 조사 → 대본 → 장면 계획 → 음성 → 자막 → 편집까지 단계별로 진행하고, 중요한 순간마다 선생님에게 확인을 받아요.

```prompt OpenMontage 설치와 시작
OpenMontage를 설치해 줘. (git clone https://github.com/calesthio/OpenMontage.git 후 make setup)
설치가 끝나면 그 폴더에서 "초등 5학년 「태양계」 45초 설명 영상을 만들어 줘. 실제 자료 화면은 NASA 공개 자료만 써 줘"로 시작해 줘.
단계마다 계획을 보여 주고 내 확인을 받아 줘.
```

> ⚠ OpenMontage는 AGPL-3.0 라이선스예요. 무료 음성(Piper)과 공개 자료(NASA, 위키미디어 등)로 만들 수 있지만, 일부 기능은 유료 API 키가 필요해요. **한국어 음성**이 자연스러운지는 설치한 뒤 꼭 들어 보고 쓰세요.

> 💡 내레이션은 선생님 목소리로 직접 녹음해 얹는 게 가장 자연스러워요. 클로드에게 "이 녹음 파일(.m4a)을 영상에 넣고 장면 길이를 녹음에 맞춰 줘"라고 할 수 있어요. 마지막 손질은 캡컷 같은 편집 프로그램에서 해도 돼요.

## 9. 안전하고 바르게 쓰기

1. **내용 검토는 교사가** — 교과 개념, 숫자, 맞춤법을 직접 확인해요. 그럴듯한 그림이 틀릴 수 있어요.
2. **학생 얼굴·이름·목소리는 넣지 않아요** — 꼭 필요하면 보호자 동의와 학교 지침을 따라요.
3. **저작권 확인** — 교과서 그림·인터넷 이미지·음악을 그대로 넣지 않아요. 글꼴도 무료 사용 조건을 확인해요(오늘 쓴 Pretendard는 무료 글꼴).
4. **도구 라이선스** — HyperFrames는 무료, Remotion은 회사 규모에 따라 유료, OpenMontage는 AGPL이에요.
5. **공개 업로드는 학교 지침대로** — 유튜브 등에 올릴 때는 AI로 만든 영상임을 밝히는 것이 좋아요.

## 마무리
