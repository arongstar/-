## 1. 티픽스는 어떤 곳일까?

**티픽스(TPICKS, Teacher's smart picks)** 는 교실 웹도구, 선생님이 만든 설치형 프로그램, 교사 커뮤니티, AI 트렌드를 한곳에 모은 교사용 플랫폼이에요. 운영은 RIICH가 하고, 이용약관 기준으로 **별도 유료 표시가 없는 기능은 무료**예요.

![찾기 → 쓰기 → 모으기 → 나누기 → 만들기로 이어지는 티픽스 활용 흐름](/images/tpicks/flow.svg)

| 메뉴 | 하는 일 |
| --- | --- |
| **교실 도구** | 학교급(유·초등 / 중·고등)과 분야별로 웹도구·프로그램 찾기, 월간 인기, 계기교육 모아보기 |
| **PICK BOT** | 하고 싶은 일을 말로 물으면 알맞은 도구를 찾아 주는 챗봇 |
| **메이커 라운지** | 티픽스가 주목한 **교사 제작 사이트** 모음 |
| **교사 커뮤니티** | 자유이야기, 정보공유, 수업 활용 사례, 질문·도움 |
| **TOP PICKERS** | 도구를 만들고 나눈 선생님 순위 (PICK 점수·배지) |
| **학부모 답장 AI** | 받은 메시지와 전할 말을 넣으면 답장 초안 작성 |

## 2. 교실 도구 찾고 바로 쓰기

📍 교실 도구 › 유·초등 도구 둘러보기

- **분야 거르기**: 학급 운영, 국어·수학·사회·과학·영어, 범교과 등
- **인기순 보기**: 11월 인기, 10월 인기처럼 달마다 인기 도구를 볼 수 있어요.
- **웹도구보기**는 브라우저에서 바로 실행, **설치하기**는 내 컴퓨터에 설치하는 프로그램이에요.
- 마음에 든 도구는 **즐겨찾기**로 모아 두면 어느 기기에서나 이어서 쓸 수 있어요(로그인 필요).

이런 도구들이 있어요. (2026년 11월, 유·초등 기준 예시)

| 쓰임 | 도구 예시 |
| --- | --- |
| 학급 운영 | 교실 타이머, 팀 점수판, 교실 소리 센터(데시벨 측정기·목소리 코치), 교실 행동 루틴 |
| 교과 놀이 | 구구단 개굴 리듬(수학), 맞춤법 응급실(국어), 세계지도 국가 퀴즈·세계 국기 퀴즈(사회), 달의 위상 퀴즈(과학), 영어 단어 카드 |
| 화면 도구 | T-Point 판서위젯(설치형, 어떤 화면 위에서도 판서) |

### ✋ 실습① 오늘 바로 쓸 학급 운영 도구 띄워 보기 (5분)

1. **교실 도구 › 유·초등**에서 분야를 **학급 운영**으로 걸러요.
2. **교실 타이머**나 **팀 점수판**의 **웹도구보기**를 눌러 실행해요.
3. 교실 TV에 띄운다고 생각하고 글자 크기와 화면 구성을 확인해요.
4. 활동지 **① 도구 탐색 기록표**에 도구 이름과 쓸 장면을 적어요.

### ✋ 실습② PICK BOT에게 물어보기 (10분)

PICK BOT은 하고 싶은 일을 말로 물으면, 티픽스에 공개된 도구 가운데 알맞은 것을 골라 설명과 함께 보여 줘요. 오른쪽(또는 아래) **PICK BOT** 단추나 **PICK BOT으로 검색**에서 열어요.

1. 아래 질문 가운데 하나를 복사해 물어봐요.
2. 추천된 도구의 **상세 보기**로 들어가 실제로 실행해 봐요.
3. 원하는 도구가 없으면 학년·교과·활동을 더 구체적으로 다시 물어요.

```prompt PICK BOT 질문 — 수업 준비
초등 4학년 과학 '달의 모양 변화' 수업에서 학생들이 직접 해 볼 수 있는 도구가 있어?
```

```prompt PICK BOT 질문 — 학급 운영
쉬는 시간이 끝나고 교실이 시끄러울 때 학생들이 스스로 목소리를 줄이게 돕는 도구가 있어?
```

```prompt PICK BOT 질문 — 업무
생기부 작성이나 학부모 소통에 도움이 되는 도구가 있어?
```

> ⚠ PICK BOT 화면에도 안내되어 있듯, **학생·학부모 개인정보, 비밀번호, API 키는 입력하지 않아요.**

## 3. 계기교육 모아보기

📍 교실 도구 › PICK 모아보기 › 계기교육

특별한 날에 맞춰 선생님들이 나눈 도구를 한곳에 모아 둔 곳이에요. 2026년에는 **추석, 한글날, 독도의 날, 할로윈** 모음이 올라와 있고, **월간 인기** 탭에서는 달마다 많이 쓰인 도구를 볼 수 있어요. 첫 화면의 **친구사랑** 같은 주제 묶음도 함께 살펴보세요.

### ✋ 실습③ 다음 주 계기교육 수업 한 차시 짜기 (10분)

1. 계기교육 모음 하나를 골라 들어가요. 예: 한글날, 독도의 날
2. 함께 나눈 도구 가운데 **도입·전개·정리**에 쓸 도구를 하나씩 골라요.
3. 활동지 **② 계기교육 수업 설계**에 40분 흐름으로 적어요.
4. 원하는 도구가 없으면 PICK BOT에게 물어봐요.

> 💡 다른 선생님이 만든 도구를 수업에 썼다면, **좋아요와 댓글**로 고마움을 전해 주세요. 메이커에게 다음 도구를 만드는 힘이 돼요.

## 4. 학부모 답장 AI

📍 https://tpicks.kr/parent-reply

학부모님께 받은 메시지를 **그대로 붙여 넣고**, 답장에 꼭 넣고 싶은 내용만 더하면 카카오톡에 보낼 답장 초안을 만들어 줘요. 메시지 맥락을 분석해 민원·상담·생활지도·일정 안내 등을 스스로 판단해요.

| 설정 | 고를 수 있는 것 |
| --- | --- |
| 종류 | **답장 작성** / **안내 보내기** |
| 말투 | 부드럽게 · 짧고 명확하게 · 정중하지만 단호하게 |
| 길이 | 초간단 · 짧게 · 보통 · 자세히 |

> 📌 화면 안내에 따르면 **무료**이고, 입력 내용은 초안 생성에만 쓰며 **저장하거나 학습 데이터로 쓰지 않는다**고 해요. 그래도 학생 이름·연락처·건강 정보 같은 개인정보는 지우고 넣어요.

### ✋ 실습④ 가상 메시지로 답장 초안 만들기 (10분)

1. 아래 가상 메시지를 복사해 **학부모님께 받은 메시지** 칸에 붙여 넣어요.
2. **답장에 꼭 넣고 싶은 내용**에 학교의 조치나 일정을 적어요.
3. 말투와 길이를 바꿔 가며 초안이 어떻게 달라지는지 비교해요.
4. 초안을 그대로 보내지 말고, **사실관계와 학교 규정**을 확인해 고쳐 써요.

```prompt 가상 메시지 ① 결석 안내 (부드럽게·짧게)
선생님 안녕하세요. 아이가 어젯밤부터 열이 나서 오늘 학교에 못 갈 것 같아요. 병원 다녀와서 서류는 어떻게 내면 될까요?
```

```prompt 가상 메시지 ② 친구 관계 상담 (부드럽게·보통)
선생님, 요즘 아이가 쉬는 시간에 같이 놀 친구가 없다고 학교 가기 싫다고 하네요. 학교에서는 어떤지 궁금해서 연락드렸어요.
```

```prompt 가상 메시지 ③ 무리한 요구 (정중하지만 단호하게)
선생님, 다음 주 현장체험학습에 우리 아이만 개인 차량으로 따로 가도 될까요? 버스를 타면 멀미를 해서요. 선생님이 그냥 허락해 주시면 될 것 같아요.
```

> ⚠ 체험학습·출결·생활기록처럼 **규정과 관련된 답장**은 반드시 학교와 교육청의 최신 기준을 확인해요. AI 초안은 학교의 공식 판단을 대신하지 않아요.

## 5. 메이커 라운지와 교사 커뮤니티

### 메이커 라운지 — 선생님이 만든 사이트들

📍 메이커 라운지

티픽스가 주목한 교사 제작 사이트를 모아 둔 곳이에요. (2026년 11월, 12곳)

| 분야 | 사이트 |
| --- | --- |
| 학급 운영 | 클래너(올인원 학급일지), 쏭쌤(교실 도구 모음) |
| 교사 업무 | 에듀잇티(알림·수합·서명), 문수네집(업무·수업 도구), 개발하는홍쌤(디지털 교무수첩) |
| 교실 도구 | 반짝넷(수업·학급 운영 도구 허브), Matto(교사가 만드는 도구 실험실), 엽쌤스쿨, 왕관유자(AI 교육 도구) |
| 바이브코딩 | 무궁무진클래스(교사 바이브코딩 앱 커뮤니티), kimju.zip(바이브코딩 아카이브) |
| 유아 수업 | 솔티처(놀이·마음 성장 수업 아카이브) |

> 💡 학생 기록이나 나이스 입력을 다루는 사이트는 **개인정보를 어디에 저장하는지** 사이트의 안내를 먼저 확인하고 써요.

### 교사 커뮤니티와 PICK 점수

📍 교사 커뮤니티 — 자유이야기 · 정보공유 · **수업 활용 사례** · 질문·도움 · 역대 설문결과

티픽스는 도구를 만들고 나눈 기여를 **PICK 점수**로 모아 **TOP PICKERS** 순위와 배지로 보여 줘요.

| 활동 | PICK |
| --- | --- |
| 교실 웹도구 공개 | 메이커 +10 |
| 설치형 프로그램 공개 | 메이커 +10 |
| 다른 회원의 좋아요·즐겨찾기·댓글 받기 | 메이커 각 +1 |
| 게시글 작성 | 커뮤니티 +3 |
| 다른 사람 콘텐츠에 댓글 작성 | 커뮤니티 +1 |

> 📌 자기 반응은 빠지고, 같은 회원이 같은 콘텐츠에 반복한 반응은 종류별로 한 번만 인정돼요. 삭제·비공개하면 점수도 회수돼요.

## 6. 나도 메이커 되기

티픽스의 도구 대부분은 **현장 선생님이 직접 만든 것**이에요. AI 덕분에 코딩을 몰라도 우리 반에 필요한 작은 도구를 만들 수 있어요. 만든 도구는 **교실 도구 › 도구 올리기**로 나눌 수 있어요.

```prompt Claude로 우리 반 도구 만들기
교실 TV에 띄워 쓸 '발표 순서 뽑기' 웹도구를 HTML 파일 하나로 만들어 줘.
- 번호(1~25번)를 입력하면 순서를 무작위로 섞어 큰 글씨로 보여 줘
- 이미 발표한 번호는 회색으로 표시
- 학생 이름은 넣지 않고 번호만 사용
- 인터넷 없이도 열리게, 초등학생이 보기 좋은 밝은 디자인
마지막에 다른 선생님이 쓸 수 있게 도구 소개 문구(한 줄 설명 + 사용법 3줄)도 써 줘.
```

**도구를 올리기 전 체크리스트**

1. 학생 이름·사진·연락처 등 **개인정보가 들어 있지 않다.**
2. 그림·글꼴·음원 등 **저작권**에 문제가 없다.
3. 대상 학교급, 교과, **사용법**을 알기 쉽게 적었다.
4. 실제 교실에서 **한 번 써 보고** 오류를 고쳤다.

> 💡 Claude로 도구를 만드는 자세한 방법은 이 사이트의 [AI 에이전트로 학교 업무 자동화하기](/lessons/ai-agent-automation) 교안 *실습 4*를 참고하세요.

## 7. 안전하게 쓰기

1. PICK BOT·학부모 답장 AI에 **학생·학부모 개인정보를 넣지 않아요.**
2. AI 초안은 **교사가 확인한 뒤** 보내요. 규정 관련 내용은 학교·교육청 기준을 따라요.
3. 다른 선생님의 도구는 **표시된 사용 조건**을 지켜 써요.
4. 학생 정보를 저장하는 외부 사이트는 **저장 위치와 동의 절차**를 먼저 확인해요.
