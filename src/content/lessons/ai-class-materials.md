## 1. 오늘 만들 것

1. 수업에 쓸 **삽화 이미지**
2. 바로 인쇄할 수 있는 **활동지**
3. 수업 마무리용 **퀴즈**

## 2. 이미지 만들기

이미지 프롬프트는 **무엇을 + 어떤 모습으로 + 어떤 그림체로** 쓰면 좋아요.

```prompt 수업용 삽화
초등학생 교과서 삽화 느낌으로 그려 줘.
여러 나라 어린이들이 지구본을 둘러싸고 손을 잡고 웃고 있는 장면.
밝은 파스텔 색감, 단순한 선, 글자는 넣지 마.
```

> ⚠ 실존 인물, 캐릭터 저작권이 있는 그림은 피하고, 만든 이미지가 수업 목적에 맞는지 꼭 확인하세요.

## 3. 활동지 만들기

```prompt 활동지 내용 만들기
초등학교 6학년 사회 '민주주의와 선거' 단원 활동지 내용을 만들어 줘.
- 활동 1: 낱말 뜻 연결하기 (5개)
- 활동 2: 우리 반 회장 선거 공약 만들어 보기 (빈칸 양식)
- 활동 3: 오늘 배운 점 한 줄 쓰기
한글(HWP)에 붙여넣기 좋게 표 없이 번호와 들여쓰기로만 정리해 줘.
```

만든 내용은 **Canva**나 **미리캔버스** 템플릿에 붙여 넣으면 예쁜 활동지가 됩니다.

## 4. 퀴즈 만들기

```prompt 퀴즈 문항 만들기 (표 형식)
초등학교 4학년 '지층과 화석' 단원 복습 퀴즈 10문제를 만들어 줘.
4지선다형으로, 아래 열을 가진 표로 정리해 줘.
문제 | 보기1 | 보기2 | 보기3 | 보기4 | 정답 번호
너무 쉬운 문제와 헷갈리는 문제를 골고루 섞어 줘.
```

표를 복사해서 띵커벨 같은 퀴즈 도구에 옮기면 학생들이 코드로 바로 참여할 수 있어요.

## 5. 발표 자료까지 한 번에

```prompt 발표 자료 개요
'우리 동네 환경 지킴이' 프로젝트 수업 소개 발표 자료 개요를 7장으로 만들어 줘.
각 장마다 제목과 핵심 문장 2~3개만 써 줘.
```

개요를 **Gamma**에 붙여 넣으면 디자인까지 된 발표 자료가 만들어져요.
