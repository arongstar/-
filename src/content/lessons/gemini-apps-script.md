> 📌 **2026년 11월 화면 기준**이에요. 제미나이와 Apps Script는 메뉴 이름이 가끔 바뀌어요. 화면이 조금 달라도 같은 이름의 메뉴를 찾으면 돼요. 이 교안의 일부 그림은 **예시 그림**(단순하게 다시 그린 화면)이에요.

> 💡 **발표 화면**에서도 프롬프트 옆 **[복사]** 버튼을 누르면 바로 복사돼요. 이 페이지에서는 각 프롬프트 카드의 **[복사]** 를 쓰면 돼요.

## 0. 오늘의 흐름

| 시간 | 내용 |
| --- | --- |
| 15분 | 1부 · 웹앱은 어떻게 움직일까 (세 가지 재료, 역할, 계정) |
| 60분 | 2부 · 제미나이와 10단계로 만들기 (**실습**) |
| 25분 | 3부 · 오류 고치기, 기능 더하기, 나만의 Gem, 안전하게 쓰기 |

**준비물**

- 노트북과 크롬 브라우저 (태블릿보다 노트북이 편해요)
- **제미나이 유료 계정**(Google AI Pro) — gemini.google.com
- 구글 계정 — 시트와 Apps Script를 쓸 계정 (아래 *어떤 계정으로 만들까?* 참고)
- 휴대폰 한 대 — 다 만든 앱을 학생처럼 열어 볼 때

**오늘 만들 앱 — 우리 반 복습 퀴즈**

![번호를 고른 뒤 한 문제씩 큰 버튼으로 답을 고르는 퀴즈 화면](/images/gemini-apps-script/quiz-question.jpg)

- 학생은 웹앱 주소로 들어와 **번호만** 고르고, 5문제를 한 문제씩 풀어요.
- 다 풀면 **바로 점수와 해설**을 봐요. 틀린 문제는 정답도 보여 줘요.
- 결과는 선생님의 구글 시트 **결과 탭**에 쌓이고, **요약 탭**에 문제별 정답률이 자동으로 계산돼요.

## 1. 웹앱은 어떻게 움직일까?

### 웹앱 = 세 가지 재료

| 재료 | 비유 | 하는 일 |
| --- | --- | --- |
| **구글 시트** | 기록이 쌓이는 공책 | 문제, 학생 결과, 정답률 요약을 저장 (선생님만 봐요) |
| **Code.gs** | 보이지 않는 주방 | 채점하고 시트에 저장. 정답은 여기에만 있어요 |
| **Index.html** | 학생이 보는 화면 | 번호 고르기, 문제, 점수. 휴대폰에서도 열려요 |

**Apps Script**는 구글 시트에 딸린 무료 코딩 도구예요. Code.gs와 Index.html을 시트에 붙여 넣고 **웹 앱으로 배포**하면, 링크 하나로 열리는 우리 반 앱이 돼요.

### 누가 무엇을 할까

| 제미나이 | 선생님 |
| --- | --- |
| 앱 설계를 표로 정리 | 무엇을 만들지 정하기 (주문서) |
| 코드 두 파일 작성 | 붙여 넣기 · 실행 · 배포 |
| 오류 원인 설명과 수정 | 결과 확인 · 학생 정보 지키기 |

> 💡 코딩은 몰라도 돼요. **주문을 정확히 하고, 결과를 꼼꼼히 확인하는 것**이 선생님 몫이에요.

### 어떤 구글 계정으로 만들까?

| | 학교 구글 계정 | 개인 구글 계정 |
| --- | --- | --- |
| 좋은 점 | 학생이 학교 계정으로 로그인하면 누가 냈는지 알 수 있어요 | 설정이 쉽고 막히는 일이 적어요 |
| 접근 설정 | 우리 학교 도메인의 모든 사용자 | 모든 사용자 (로그인 없이 열림) |
| 주의할 점 | 학교 관리자가 Apps Script나 외부 앱 승인을 막았을 수 있어요 | 링크를 아는 누구나 열 수 있어요 |

> 📌 오늘 퀴즈 앱은 **이름 없이 번호만** 받아서 두 계정 모두 괜찮아요. 학교 계정에서 막히면 제미나이를 구독한 **개인 계정**으로 만들어요.

## 2. 제미나이와 10단계로 만들기

| 단계 | 어디서 | 할 일 |
| --- | --- | --- |
| 1~3 | 제미나이 | 만들 앱 정하기 → 설계를 표로 받기 → 코드 두 파일 받기 |
| 4~7 | 구글 시트 | Apps Script 열기 → Code.gs 붙여 넣기 → Index.html 만들기 → setup 실행·권한 승인 |
| 8~10 | 배포 | 웹 앱으로 배포 → 학생처럼 테스트 → 링크·QR로 나누기 |

### ✋ 1단계 · 무엇을 만들지 정하기 (주문서)

제미나이에게 말하기 전에 네 가지만 정해요.

1. **누가 쓰나요?** 학생 · 선생님 · 둘 다
2. **무엇을 하나요?** 번호 고르기 → 5문제 풀기 → 점수와 해설
3. **무엇이 남나요?** 결과 탭에 번호 · 점수 · 고른 답
4. **무엇은 받지 않나요?** 이름 · 연락처 같은 개인정보

### ✋ 2단계 · 코드보다 설계부터 받기

1. gemini.google.com 에서 **새 채팅**을 열어요.
2. 아래 요청문을 붙여 넣어요. 제미나이가 **화면 · 시트 · 동작 순서**를 표로 정리해 줘요.
3. 표를 읽고 바꾸고 싶은 점을 말해요. 예) "문제는 10개로", "결과 화면에 응원 문구도"

```prompt 앱 설계 요청
너는 초등학교 선생님을 돕는 구글 Apps Script 전문가야.
구글 시트와 Apps Script로 우리 반 웹앱을 만들고 싶어. 코드를 쓰기 전에 설계부터 같이 하자.

[만들 앱] 4학년 과학 복습 퀴즈 앱
- 학생: 웹앱 주소로 들어와 자기 번호를 고르고, 5문제를 하나씩 풀고, 바로 점수와 해설을 봐요.
- 교사: 문제는 시트에서 고치고, 학생 결과와 문제별 정답률을 시트에서 봐요.
- 학생 이름은 받지 않고 번호만 받아요.

먼저 ① 화면 구성 ② 시트 탭과 열 구성 ③ 동작 순서를 표로 정리해 줘. 코드는 아직 쓰지 마.
```

> 💡 처음부터 "코드 짜 줘"라고 하면 제미나이가 마음대로 정한 구조로 길게 만들어요. **설계를 먼저 확인**하면 고칠 일이 훨씬 줄어요.

### ✋ 3단계 · 코드 두 파일 받기

```prompt 코드 만들기 요청
좋아, 이 설계대로 코드를 만들어 줘. 아래 조건을 꼭 지켜 줘.
1. 파일은 Code.gs와 Index.html 두 개. 각각 따로, 처음부터 끝까지 전체 코드를 보여 줘.
2. Code.gs에 setup 함수를 만들어서, 한 번 실행하면 시트 탭과 예시 문제 5개가 생기게 해 줘.
3. 정답은 학생 화면으로 보내지 말고, 서버(Code.gs)에서 채점해 줘.
4. 여러 학생이 동시에 제출해도 기록이 섞이지 않게 LockService를 써 줘.
5. 태블릿과 휴대폰에서도 보기 좋게, 버튼은 크고 글은 쉽게.
6. 코드 주석은 초등 교사가 읽을 수 있는 쉬운 한국어로.
마지막에 붙여 넣는 순서와 웹 앱 배포 설정을 단계별로 알려 줘.
```

![제미나이 답변의 Code.gs 코드 블록 오른쪽 위 ①복사 버튼](/images/gemini-apps-script/gemini-chat-marked.jpg)

- 코드 블록 오른쪽 위 **복사 버튼**을 누르면 코드 전체가 한 번에 복사돼요. 마우스로 드래그하지 않아요.
- Code.gs와 Index.html은 **따로** 복사해요.
- 코드가 중간에 끊겼다면: "Index.html만 처음부터 끝까지 다시 보여 줘"

### ✋ 4단계 · 구글 시트에서 Apps Script 열기

![구글 시트 위쪽 메뉴의 ①확장 프로그램 → ②Apps Script](/images/gemini-apps-script/sheet-menu-marked.jpg)

1. 구글 드라이브에서 **새로 만들기 → Google 스프레드시트**. 이름은 `우리 반 퀴즈`로 바꿔요.
2. 시트 위쪽 메뉴에서 **[확장 프로그램]** 을 눌러요.
3. **[Apps Script]** 를 누르면 새 탭에 코드 편집기가 열려요.

### ✋ 5단계 · Code.gs에 붙여 넣기

![Apps Script 편집기 왼쪽 ①Code.gs와 오른쪽 ②코드 칸(제미나이 코드를 붙여 넣은 모습)](/images/gemini-apps-script/editor-paste-marked.jpg)

1. 왼쪽 파일 목록에서 **Code.gs** 를 눌러요.
2. 원래 들어 있던 `function myFunction() {}` 을 **모두 지워요.** (Ctrl + A → Delete, 맥은 ⌘ + A)
3. 제미나이의 **Code.gs** 코드를 붙여 넣어요. (Ctrl + V)
4. **저장**해요. (Ctrl + S 또는 💾) 위쪽의 '제목 없는 프로젝트'를 눌러 이름도 `우리 반 퀴즈 앱`으로 바꿔 두면 찾기 쉬워요.

### ✋ 6단계 · Index.html 파일 만들기

![Apps Script 편집기 왼쪽 ①파일 옆 + → ②HTML](/images/gemini-apps-script/add-html-marked.jpg)

1. 왼쪽 **파일** 옆 **[+]** 를 눌러요.
2. **[HTML]** 을 골라요. (스크립트가 아니라 HTML)
3. 이름에 `Index` 라고 써요. `.html` 은 저절로 붙어요. **대문자 I까지 똑같이** 써야 해요.
4. 새 파일 안의 글을 모두 지우고 제미나이의 **Index.html** 코드를 붙여 넣은 뒤 저장해요.

> ⚠ 파일 이름이 `index`(소문자)나 `Index.html.html` 이 되면 앱이 화면을 못 찾아요. 제미나이 코드의 `createHtmlOutputFromFile('Index')` 안 이름과 똑같아야 해요.

### ✋ 7단계 · setup 한 번 실행하고 권한 승인하기

![①함수 목록에서 setup 고르기 ②▶ 실행](/images/gemini-apps-script/run-setup-marked.jpg)

1. 위쪽 가운데 **함수 목록**에서 `setup` 을 골라요.
2. **[▶ 실행]** 을 눌러요.
3. 처음 실행하면 **권한 승인** 창이 떠요. (아래 그림)
4. 아래 **실행 로그**에 '실행이 완료됨'이 나오면 성공이에요. 시트로 돌아가면 setup이 만든 탭(예: 문제 · 기록 · 요약)이 생겨 있어요.

> 💡 함수 이름과 탭 이름은 제미나이가 만든 코드마다 조금씩 달라요. (예: `문제은행`, `제출기록`, `getQuestionsForStudent`) 함수 목록에 **setup** 만 있으면 괜찮아요.

![권한 승인: ①권한 검토 ②고급 ③(으)로 이동(안전하지 않음) ④허용 — 예시 그림](/images/gemini-apps-script/permission-marked.svg)

1. **[권한 검토]** 를 누르고 시트를 만든 **바로 그 계정**을 골라요.
2. 'Google에서 확인하지 않은 앱' 화면이 나오면 **[고급]** 을 눌러 펼쳐요.
3. 아래쪽 **'우리 반 퀴즈 앱(으)로 이동(안전하지 않음)'** 을 눌러요.
4. **[허용]** 을 눌러요.

> 📌 '확인하지 않은 앱'은 **내가 만든 앱**이라 구글이 따로 검사하지 않았다는 뜻이에요. 내가 붙여 넣은 코드라면 허용해도 돼요. 남이 보낸 모르는 코드는 승인하지 않아요.

### ✋ 8단계 · 웹 앱으로 배포하기

![새 배포 창: ①유형 선택 톱니 → 웹 앱 ②실행: 나 ③접근: 모든 사용자 ④배포](/images/gemini-apps-script/deploy-new-marked.jpg)

1. 오른쪽 위 파란 **[배포] → [새 배포]** 를 눌러요.
2. **유형 선택** 옆 **⚙(톱니)** → **웹 앱** 을 골라요.
3. 설정을 아래처럼 정해요.

| 항목 | 고를 것 | 까닭 |
| --- | --- | --- |
| 설명 | 첫 배포 | 나중에 버전을 구분해요 |
| 다음 사용자 인증 정보로 실행 | **나** | 학생은 시트를 직접 못 보고, 앱을 통해서만 기록해요 |
| 액세스 권한이 있는 사용자 | 개인 계정: **모든 사용자** / 학교 계정: **우리 학교 도메인의 모든 사용자** | 학생이 링크로 열 수 있게 |

4. **[배포]** 를 눌러요. 처음이면 권한 승인을 한 번 더 해요.

![배포 완료 창의 ①웹 앱 주소 복사 — 예시 그림](/images/gemini-apps-script/deploy-done-marked.svg)

5. 나온 **웹 앱 URL**(`…/exec` 로 끝나는 주소)을 **복사**해 메모장에 붙여 두어요. 이 주소가 우리 반 앱이에요.

### ✋ 9단계 · 학생처럼 테스트하기

1. 크롬 **시크릿 창**(Ctrl + Shift + N)을 열고 웹 앱 주소를 붙여 넣어요. 로그인 안 한 학생처럼 열려요.
2. 번호를 고르고 문제를 풀어요. **일부러 한 문제는 틀려** 보세요.
3. 시트의 **결과** 탭에 번호 · 점수 · 고른 답이 쌓였는지 봐요.
4. **요약** 탭에서 문제별 정답률을 확인해요.

![제미나이가 만든 코드를 그대로 배포한 실제 웹앱 첫 화면 — 위쪽에 Apps Script 안내 줄이 보여요](/images/gemini-apps-script/real-app.jpg)

> 📌 맨 위에 **'이 애플리케이션은 Google Apps Script 사용자가 만들었습니다.'** 라는 줄이 보여도 정상이에요. 구글이 Apps Script 웹앱에 붙여 주는 안내예요. 학생에게 "선생님이 만든 앱이라 나오는 줄"이라고 미리 알려 주세요. 화면 모양과 문구는 제미나이가 만든 코드마다 조금씩 달라요.

![학생 결과 화면: 점수와 문제별 정답·해설](/images/gemini-apps-script/quiz-result.jpg)

> 💡 문제는 시트의 **문제** 탭에서 고치면 바로 바뀌어요. 문제만 바꿀 때는 **다시 배포하지 않아도** 돼요.

### ✋ 10단계 · 학생에게 나누기

![학생이 처음 보는 번호 고르기 화면](/images/gemini-apps-script/quiz-number.jpg)

- **클래스룸 · 패들렛**에 웹 앱 주소를 올려요.
- **QR 코드**: 크롬에서 앱 주소를 연 뒤 **[공유 → QR 코드 만들기]** 로 만들어 TV에 띄워요.
- **태블릿 홈 화면에 추가**하면 앱처럼 바로 열려요.
- 퀴즈가 끝나면 시트 **설정** 탭의 **제출 받기**를 `끄기` 로 바꿔요. 링크가 퍼져도 더 이상 기록되지 않아요.

## 3. 고치고, 넓히고, 안전하게

### 자주 만나는 오류

| 이런 메시지가 보이면 | 이렇게 해 보세요 |
| --- | --- |
| 'Index 파일을 찾을 수 없음' | HTML 파일 이름이 정확히 **Index** 인지 |
| '시트가 준비되지 않았어요' | **setup** 을 먼저 한 번 실행했는지 |
| 고쳤는데 학생 화면이 그대로 | **배포 관리 → ✏️ → 새 버전** 으로 다시 배포했는지 |
| '확인하지 않은 앱' 경고 | [고급] → '(으)로 이동(안전하지 않음)' → [허용] |
| 학교 계정에서 승인이 막힘 | 학교 관리자 설정이에요. 개인 계정으로 만들거나 정보 담당 선생님께 문의 |
| 화면은 열리는데 버튼이 안 눌림 | 실행 로그 또는 크롬 개발자 도구(F12) 콘솔의 빨간 글씨를 제미나이에게 |

### ✋ 오류는 제미나이에게 그대로 보여 주기

```prompt 오류 고치기 요청
구글 Apps Script 웹앱에서 오류가 났어. 나는 코딩을 잘 몰라.
원인을 쉬운 말로 설명하고, 고치는 방법을 순서대로 알려 줘.
코드를 고쳐야 하면 고친 파일의 전체 코드를 다시 보여 줘.

[어디서] 예) setup 실행할 때 / 웹앱 주소를 열 때 / 제출 버튼을 눌렀을 때
[오류 메시지] (화면이나 실행 로그의 빨간 글씨를 그대로 붙여 넣기)
[내 코드] (Code.gs와 Index.html 붙여 넣기)
```

> 💡 오류 화면을 **캡처해서 붙여 넣어도** 돼요. 학생 정보가 보이면 가리고 붙여요.

### ✋ 기능은 한 번에 하나씩 더하기

```prompt 기능 추가 요청
지금 만든 퀴즈 앱에 기능을 하나 더하고 싶어.
- 문제마다 20초 타이머를 보여 주고, 시간이 지나면 자동으로 다음 문제로 넘어가게 해 줘.
- 시간 안에 답을 못 고른 문제는 오답으로 채점해 줘.
바뀐 부분만이 아니라 Code.gs와 Index.html 전체를 다시 보여 주고,
다시 배포할 때 ‘새 버전’으로 하는 방법도 알려 줘.

(지금 코드 붙여 넣기)
```

![배포 관리: ①연필(수정) ②버전: 새 버전 ③배포 — 예시 그림](/images/gemini-apps-script/new-version-marked.svg)

코드를 고친 뒤에는 꼭 **새 버전**으로 배포해요.

1. **[배포] → [배포 관리]** 에서 연필 모양 **✏️(수정)** 을 눌러요.
2. **버전**을 `새 버전` 으로 바꾸고, 설명에 고친 내용(예: 타이머 추가)을 적어요.
3. **[배포]** 를 눌러요. **웹 앱 주소는 그대로**라 학생에게 다시 알려 줄 필요가 없어요.

> 💡 고치는 동안에는 **[배포 → 배포 테스트]** 의 주소로 미리 확인할 수 있어요. 이 주소는 늘 저장된 최신 코드로 열리고, 편집 권한이 있는 나만 열 수 있어요.

### ✋ 나만의 Gem 만들기

매번 같은 조건을 말하기 번거롭다면 **Gem**(나만의 제미나이 도우미)에 저장해요.

1. 제미나이 왼쪽 메뉴에서 **Gem** → **새 Gem 만들기**를 눌러요. (메뉴 이름은 조금 다를 수 있어요)
2. 이름: `우리 반 앱 도우미`
3. 지침 칸에 아래 글을 붙여 넣고 저장해요.
4. 다음부터는 이 Gem을 열고 "칭찬 도장판 앱 만들어 줘"처럼 짧게만 말해도 돼요.

```prompt Gem 지침
너는 코딩을 모르는 초등학교 선생님을 돕는 구글 Apps Script 도우미야.
- 코드를 쓰기 전에 화면 구성과 시트 구성을 표로 먼저 보여 주고 확인을 받아.
- 파일은 Code.gs와 Index.html 두 개로, 고친 파일은 항상 전체 코드를 보여 줘.
- 처음 한 번 실행하는 setup 함수로 시트 탭을 자동으로 만들어 줘.
- 학생 개인정보는 최소로(이름 대신 번호), 정답과 점수 계산은 서버(Code.gs)에서 해.
- 설명은 쉬운 한국어로, 붙여 넣기와 배포 순서는 번호를 붙여 알려 줘.
```

### 이런 길도 있어요 (보너스)

| 좋은 점 | 코드를 보면서 바로 "이 함수 고쳐 줘" | 색, 버튼 모양을 마음껏 바꿔 보기 |

### ✋ 이런 앱도 같은 방법으로

```prompt 칭찬 도장판
앞에서처럼 설계부터 같이 하자. [만들 앱] 우리 반 칭찬 도장판 — 학생은 번호를 고르면 내 칭찬 도장 개수와 도장판을 보고, 교사는 시트의 '도장' 탭에 번호와 날짜, 칭찬 내용을 적어 도장을 줘. 학생 이름은 받지 않고 번호만. 먼저 화면 구성, 시트 탭과 열 구성, 동작 순서를 표로 정리해 줘. 코드는 아직 쓰지 마.
```


```prompt 우리 반 독서 나무

```

> 📌 학교 계정으로 학생 로그인까지 쓰는 기록·평가 앱은 「구글 Apps Script로 우리 반 웹앱 만들기」 교안의 완성 앱 4종도 함께 보세요.

### 안전하게 쓰는 여섯 가지

1. **이름 대신 번호** — 연락처 · 건강 정보는 넣지 않아요.
2. **제미나이에 실제 학생 정보를 넣지 않아요** — 예시 데이터로 만들고 시험해요.
3. **시트 공유는 '나만'** — 앱이 '나'로 실행되므로 학생에게 시트를 공유할 필요가 없어요.
4. **결과는 교사가 확인** — 정답과 채점 기준을 꼭 점검해요. AI가 만든 문제와 해설도 틀릴 수 있어요.
5. **다 쓰면 '제출 받기' 끄기** — 링크가 퍼져도 더 기록되지 않게 해요.
6. **학교 지침 확인** — 학생이 쓰는 서비스는 학교의 개인정보 동의 절차를 따라요.

## 마무리

- **주문서(설계)가 반**이에요. 코드는 제미나이가 써요.
- 선생님은 **붙여 넣기 · setup · 배포** 세 가지만 기억하면 돼요.
- 코드를 고치면 **새 버전**으로 배포해요. 주소는 그대로예요.
- 제미나이 코드가 잘 안 되면 **완성 코드**(자료 내려받기)와 비교해 보세요.
