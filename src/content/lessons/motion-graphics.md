## 1. 모션 그래픽이란

**모션 그래픽**은 글자 · 도형 · 숫자 · 그래프가 **움직이며 이야기하는 영상**이에요. 사람이나 풍경을 찍은 영상이 아니라, 그림을 움직여서 만들어요.

| 학교에서 이런 때 | 예 |
| --- | --- |
| 학급 경영 | 학년 말 「숫자로 보는 우리 반 1년」, 학기 초 우리 반 소개 |
| 수업 도입 | 오늘 배울 낱말이 하나씩 나타나는 10초 오프닝 |
| 수학 · 사회 | 그래프가 자라나는 통계 영상, 인구 변화 막대그래프 |
| 행사 | 학예회 · 졸업식 오프닝, 상장 수여 화면 |

예전에는 애프터이펙트 같은 어려운 프로그램이 필요했지만, 이제는 클로드에게 **말로 장면을 설명**하면 클로드가 웹 화면(HTML)으로 만들고 HyperFrames가 MP4로 바꿔 줘요.

```prompt 처음 버전 만들기
제목: 숫자로 보는 우리 반 1년 (4학년 2반의 2026년)
숫자 세 개를 카드로 보여 줘: 함께한 날 190, 읽은 책 1,248, 칭찬 스티커 3,650

```

만들어지면 "미리보기 열어 줘"라고 해서 봐요. 그리고 활동지 3번 **체크리스트**로 점검해 봐요. 몇 개에 표시가 되나요?

## 5. 좋아지게 만드는 7가지 방법


### ① 숫자는 한 번에 하나씩

v1은 세 숫자가 **동시에** 올라가요. 눈은 한 번에 한 곳만 볼 수 있어서, 셋 다 보다가 아무것도 기억하지 못해요.

- **장면 하나에 숫자 하나.** 숫자가 멈추면 설명 글이 나오고, 읽을 시간을 준 뒤 다음 숫자로 가요.
- 숫자가 0에서 올라가는 대신 **바퀴처럼 굴러가다 착 멈추게** 하면 "도착했다"는 느낌이 생겨요.

```prompt 숫자 하나씩
숫자 세 개가 한 화면에 동시에 나오지 않게, 장면 하나에 숫자 하나씩 나오게 바꿔 줘.
숫자는 슬롯머신 바퀴처럼 굴러가다가 멈추게 하고, 멈춘 뒤에 설명 글이 나오게 해 줘.
```

### ② 숫자를 사물로 보여 주기

"1,248권"은 크기가 잘 느껴지지 않아요. 숫자를 **눈에 보이는 물건**으로 바꾸면 기억에 남아요.

![190일은 달력 칸, 1,248권은 월별 책 막대, 3,650개는 스티커 병](/images/motion-graphics/objects.jpg)

| 숫자 | v2에서 보여 준 사물 | 덤으로 생긴 이야기 |
| --- | --- | --- |
| 190일 | 칸 190개가 초록으로 차오르는 달력 | "3월 2일 입학식부터 2월까지" |
| 1,248권 | 3월~2월 월별 책 막대 | 가장 높은 7월에만 주석 하나 — "여름 독서 캠프" |
| 3,650개 | 스티커가 쏟아져 차는 병 | "하루에 약 19개씩 서로 칭찬했어요" |

장면마다 **바탕색**도 바꿨어요(초록 · 크림 · 하늘). 색만 봐도 지금 어떤 숫자인지 알 수 있어요.

```prompt 숫자를 사물로
190일은 칸 190개짜리 달력이 하나씩 초록색으로 차오르게,
1,248권은 3월부터 2월까지 월별 책 막대그래프가 자라나게(가장 높은 달만 주황색으로 강조하고 주석 하나),
3,650개는 병에 색색 스티커가 쏟아져 차오르게 보여 줘.
장면마다 바탕색을 다르게 해 줘.
```

### ③ 움직임에도 성격이 있어요 — 속도 곡선(이징)

같은 1초라도 **어떻게 빨라지고 느려지는지**에 따라 느낌이 완전히 달라요. 이것을 **이징(easing)** 이라고 해요.

![일정한 속도는 딱딱하고, 들어올 때는 빠르게 와서 천천히 멈추고, 나갈 때는 천천히 떠나다 휙 사라져요](/images/motion-graphics/ease.svg)

- **들어올 때**: 빠르게 와서 천천히 멈춰요(`expo.out`). "착!" 하고 자리 잡아요.
- **나갈 때**: 등장보다 **더 짧게**, 천천히 떠나다 휙(`power3.in`). 다음 장면에 빨리 자리를 내줘요.
- v1은 모든 것이 같은 속도 · 같은 방식(아래에서 위로 살짝)으로 움직여서 단조로웠어요.

```prompt 움직임의 성격
등장하는 것은 빠르게 들어와서 천천히 멈추게(expo.out), 퇴장은 등장보다 짧게 해 줘.
모든 요소가 똑같이 아래에서 올라오지 않게, 요소마다 어울리는 움직임을 골라 줘.
```

### ④ 차례대로, 그리고 멈춤

여러 개가 나올 때는 **읽는 순서대로 조금씩 시간 차**를 두고 나오게 해요(스태거). 다 나온 뒤에는 **읽을 시간**을 줘요.

![축이 그어지고, 막대가 3월부터 차례로 자라고, 마지막에 숫자가 착지해요](/images/motion-graphics/stagger.jpg)

- 막대그래프: 축 → 막대(3월부터 0.07초씩) → 숫자 → 주석 하나
- 제목도 낱말 하나씩 흐릿함이 걷히며 나타나요.
- **3초 넘게 아무것도 안 바뀌면** 지루해져요. v1의 6.75~10.9초 구간이 그랬어요.
- 거꾸로, 글자가 너무 빨리 사라지면 못 읽어요. 한 문장은 **"0.5초 + 낱말마다 0.3초"** 이상 보여 줘요.

![v1 첫 화면, v2는 0초부터 작은 제목이 있고 낱말이 하나씩 나타나요](/images/motion-graphics/hook.jpg)

### ⑤ 이유 있는 전환

v1은 장면이 그냥 흐려지며 바뀌어요. v2는 **화면 속 물건이 다음 장면을 불러와요.**

![작은 달력 카드가 점점 커져서 화면 전체가 되고, 달력 장면이 시작돼요](/images/motion-graphics/transition.jpg)

| 바뀌는 곳 | 전환 방법 |
| --- | --- |
| 제목 → 190일 | 작은 **달력 카드가 커져서** 화면이 돼요 |
| 190일 → 1,248권 | 왼쪽으로 휙 빠지고, 막대그래프가 **같은 방향으로** 들어와요 |
| 1,248권 → 3,650개 | 가장 높은 **주황 막대가 위로 솟아올라요** |
| 3,650개 → 고마워 | **초록색이 아래에서 차올라** 화면을 덮어요 |

![초록색이 차오르고 인사가 내려앉아요](/images/motion-graphics/ending.jpg)

```prompt 이유 있는 전환
장면이 그냥 사라지고 나타나지 않게, 앞 장면의 물건이 다음 장면으로 이어지게 전환을 바꿔 줘.
예를 들어 제목 화면의 작은 달력 카드가 커져서 달력 장면이 되게 해 줘.
마지막 장면은 초록색이 아래에서 차올라 화면을 덮은 뒤 인사가 나오게 해 줘.
```

### ⑥ 소리 — 숫자가 멈출 때 "톡"

소리가 없으면 아무리 잘 움직여도 허전해요. v2는 **숫자가 착지하는 순간**(5.05초 · 10.45초 · 15.25초)에 짧은 "톡" 효과음을 넣었어요.


- 효과음은 **눈에 보이는 움직임과 같은 순간**에 넣어요. 엇나가면 오히려 어색해요.
- 15초가 넘는 영상은 **배경 음악**이 있으면 좋아요. 이번 예시에는 음악을 넣지 않았어요. HyperFrames로 음악을 새로 만들려면 HeyGen 계정 로그인이 필요해서예요.
- 음악을 넣을 때는 **저작권**을 꼭 확인해요. 출처 표시(CC BY)가 필요한 음악은 영상 끝에 출처를 적어요.

```prompt 소리 넣기
숫자가 멈추는 순간마다 짧은 '톡' 효과음을 넣어 줘. 소리가 너무 크지 않게 해 줘.
어디서 가져온 소리인지, 출처 표시가 필요한지도 알려 줘.
```

### ⑦ 이미 있는 블록 쓰기 · 안전 영역 · 점검

- **블록 쓰기**: 숫자 바퀴 같은 효과는 처음부터 만들지 말고 HyperFrames **레지스트리**(약 450개 블록)에서 가져와요. v2의 숫자 바퀴(number-wheel)도 여기서 가져왔어요.
- **안전 영역**: 글자가 화면 가장자리에 붙으면 TV에서 잘려요. 중요한 글자는 화면 가운데 80% 안에 둬요. (v2를 만들 때 숫자가 오른쪽 끝에 닿아서 안쪽으로 옮겼어요.)
- **첫 화면**: 0초 화면은 섬네일(미리보기 그림)이 돼요. 비어 있지 않게 작은 제목을 0초부터 보여 줘요.
- **글꼴**: 제목은 둥글고 친근한 **주아(Jua)**, 본문은 읽기 쉬운 **프리텐다드**. 둘 다 무료로 영상에 쓸 수 있어요.

```prompt 점검하기
npx hyperframes check 로 점검하고, 오류와 경고를 쉬운 말로 설명해 줘.
고칠 것은 고치고, 일부러 그대로 둔 것은 왜 그런지 알려 줘.
장면마다 스냅숏(정지 화면)을 찍어서 글자가 잘리거나 겹치는 곳이 없는지도 확인해 줘.
```

## 6. ✋ 실습② v1을 v2처럼 고치기

①~⑦을 하나씩 부탁해도 되고, 한 번에 부탁해도 돼요. 한 번에 부탁할 때는 **장면표를 먼저 보여 달라고** 하면 실수가 줄어요.

```prompt 한 번에 고치기
지금 영상을 아래 7가지 방법으로 고쳐 줘. 고치기 전에 장면별 계획을 표로 먼저 보여 줘.
1. 장면 하나에 숫자 하나 (숫자는 바퀴처럼 굴러가다 멈추게)
2. 숫자를 사물로: 190일은 달력 칸, 1,248권은 월별 책 막대, 3,650개는 스티커 병
3. 등장은 빠르게 와서 천천히 멈추고, 퇴장은 더 짧게
4. 여러 개는 차례대로, 다 나온 뒤 읽을 시간 주기 (3초 넘게 멈춘 곳 없게)
5. 앞 장면의 물건이 다음 장면으로 이어지는 전환
6. 숫자가 멈출 때 짧은 효과음
7. 중요한 글자는 화면 안쪽 80% 안에, 0초 화면에도 제목이 보이게
제목 글꼴은 주아(Jua), 본문은 프리텐다드로 해 줘. 전체 20초 안팎.
```

**말로 고치기 팁**

- "더 멋있게" 대신 **무엇을 · 어떻게**: "두 번째 장면 숫자를 지금보다 1초 늦게 나오게 해 줘"
- **시간으로 말하기**: "8초쯤 막대가 너무 빨라. 0.1초 간격으로 천천히 자라게 해 줘"
- **한 번에 한두 가지**만 고치고 다시 봐요.

## 7. ✋ 실습③ 우리 반 숫자로 바꾸고 MP4 만들기

[원본 묶음(.zip)](/files/motion-graphics/숫자로보는우리반1년_원본_HyperFrames.zip)을 내려받아 압축을 풀고, 클로드 코드에서 그 폴더를 열어요.

```prompt 우리 반 숫자로 바꾸기
2_고친뒤_v2 폴더의 영상을 우리 반 숫자로 바꿔 줘.
반 이름: ○학년 ○반
함께한 날: ○일 / 읽은 책: ○권 (월별 권수: 3월 ○, 4월 ○ …) / 칭찬 스티커: ○개
가장 많이 읽은 달의 주석은 "○○○"로 해 줘.
다 바꾸면 미리보기를 열어 주고, 내가 괜찮다고 하면 MP4로 만들어 줘.
```

- 숫자를 다른 것으로 바꿔도 돼요: 줄넘기 횟수, 받아쓰기 100점 횟수, 텃밭 방울토마토 개수…
- 다 만들면 **"MP4로 만들어 줘"**. 21초 영상이 1분 안쪽으로 만들어져요.


## 8. 스스로 고칠 점 찾기

이번 v2의 고칠 점은 이렇게 찾았어요. 선생님도 같은 방법을 쓸 수 있어요.

1. **점검 도구(check)** — "4초 동안 아무것도 안 바뀌어요", "글자가 너무 빨리 사라져요", "첫 화면이 비었어요", "글자와 배경 색 차이가 작아요"처럼 숫자로 알려 줘요.
2. **장면마다 정지 화면(snapshot)** — 장면 시작 · 중간 · 전환 직전과 직후를 한 장에 모아 보고 잘림 · 겹침을 찾아요.
3. **클로드에게 묻기** — 아래 요청문으로 고칠 점을 먼저 듣고, 마음에 드는 것만 고르게 해요.

```prompt 고칠 점 찾아 달라고 하기
이 영상을 모션 디자이너의 눈으로 봐 줘.
더 좋아지게 할 방법 5가지를 '지금 어떤지 → 어떻게 바꾸면 좋은지 → 왜 좋은지' 표로 알려 줘.
아직 고치지는 말고, 내가 번호를 고르면 그것만 고쳐 줘.
```


## 9. 안전하고 바르게 쓰기

- **학생 개인 정보 넣지 않기**: 학생 이름 · 얼굴 사진 · 성적은 넣지 않아요. 학급 전체 숫자만 써요.
- **숫자는 사실대로**: 클로드가 계산한 평균(예: 한 사람에 50권)은 직접 다시 확인해요.
- **글꼴 · 음악 · 그림 저작권**: 무료 글꼴(프리텐다드 · 주아는 SIL 오픈 폰트 라이선스)을 쓰고, 음악은 출처를 확인해 적어요.
- **공유 전 확인**: 학급 밖(학교 누리집, SNS)에 올릴 때는 학교 방침과 학부모 동의를 먼저 확인해요.

## 마무리

| 고치기 전 (v1) | 고친 뒤 (v2) |
| --- | --- |
| 숫자 세 개가 동시에 | 장면 하나에 숫자 하나 |
| 숫자만 | 숫자를 사물로 (달력 · 막대 · 병) |
| 모두 같은 속도, 같은 방향 | 등장은 "착!", 퇴장은 짧게 |
| 4초 동안 그대로 | 차례대로 + 읽을 시간 |
| 그냥 흐려지며 바뀜 | 물건이 다음 장면을 불러옴 |
| 소리 없음 | 숫자가 멈출 때 "톡" |
| 숫자가 가장자리에, 빈 첫 화면 | 안전 영역 안, 0초부터 제목 |
