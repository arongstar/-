## 0. 오늘의 목표와 진행

**학습 목표**

1. 경북AI배움터에서 내 수업에 맞는 에듀테크를 찾아 바로 쓸 수 있다.
2. 경북형 웍스AI 에이전트로 학교 업무 시간을 줄일 수 있다.
3. 웍스AI로 만든 수업 자료를 배움터 서비스로 이어 수업에 쓸 수 있다.

**준비물**: 노트북, 경북AI배움터 교직원 계정, 경북형 웍스AI 계정, 실습 패들렛(오른쪽 *자료 내려받기*)

| 시간 | 단계 | 내용 |
| --- | --- | --- |
| 0~10분 | 열기 | 패들렛 첫 질문, 왜 경북형 플랫폼인가 |
| 10~35분 | 1부 경북AI배움터 | 첫 화면 위젯 → 에듀테크 → 나의 강의실 → 자료실·대시보드, **실습①** |
| 35~75분 | 2부 경북형 웍스AI | 화면 구성 → 업무 효율화 4가지 → **실습②** → 수업 활용 4가지 → **실습③** |
| 75~85분 | 3부 둘을 잇기 | 웍스AI 문항 → 배움터 코들·띵커벨 수업, **실습④** |
| 85~90분 | 닫기 | AI 안전하게 쓰는 5가지, 소감 나누기 |

> 💡 오늘은 듣는 시간보다 **직접 눌러 보는 시간**이 더 길어요. 시작 전에 두 사이트 로그인부터 해 두세요.

## 2. 1부 경북AI배움터

경북AI배움터는 경상북도교육청이 운영하는 **교사·학생 통합 학습 플랫폼**이에요.

- 에듀테크 서비스를 한 계정으로 이용
- 구글 클래스룸·웨일 클래스 연결
- 나의 강의실, 학급 관리
- 수업·학습 자료실
- 학습 분석 대시보드

### 첫 화면 위젯 둘러보기

- **위젯 편집하기** (오른쪽 위): 자주 쓰는 것만 앞으로 꺼내 내 수업에 맞는 첫 화면 만들기
- **통합검색 · 학급 관리 바로가기**
- **학사일정 · 급식표 · 공지사항 · FAQ**: 첫 화면을 아래로 내리면 나와요
- 각 위젯의 **[수정하기]**로 보이는 서비스를 고를 수 있어요

### 에듀테크, 수업 목적별로 나눠 보기

20여 종을 다 외울 필요는 없어요. **수업 목적**에 따라 골라요.

| 목적 | 서비스 |
| --- | --- |
| AI 도움 | 자작자작(글쓰기 피드백), 마타수학(맞춤 문제), 코들(문항·자동 채점), 위툰(웹툰), 브루(영상 자막), AI 마음일기 |
| 수업 참여 | 띵커벨, 젭 퀴즈, 퀴즈앤, 클래스게임 |
| 만들기 | 캔바, 미리캔버스, 북크리에이터, 노션 |
| 영어 | 리딩앤, 보카트레인 |
| 교과서 연계 자료 | 아이스크림, T셀파, 비바샘, 엠티처, Y클라우드, 두클래스, 티솔루션, 티칭허브 |
| 찾아보기 | 두피디아(백과사전) |

> 💡 서비스별 사용법은 **이용 안내 › 안내 자료실**에 있어요. 띵커벨 유료 이용권은 **공모**로 나누니 공지사항에서 차수별 안내를 확인하세요.

### 나의 강의실과 학급 관리

| 메뉴 | 하는 일 |
| --- | --- |
| 나의 강의실 | 웨일 클래스·구글 클래스룸에 한곳에서 입장 |
| 학급 관리 | 우리 반 학생 계정 관리 |
| 개인정보 동의 | 학생 개인정보 동의 양식은 공지사항에서 내려받기 |
| 교사 매뉴얼 | 이용 안내 › 안내 자료실 › 경북AI배움터 교사 매뉴얼 (학생 계정 만드는 법 포함) |

### 자료실에서 찾고, 대시보드에서 읽기

- **수업·학습 자료실**: 다른 선생님의 수업 자료를 학교급·교과별로 찾아 복사해서 내 수업에 맞게 고쳐 써요.
- **학습 분석 대시보드**: 에듀테크 종합·클래스 종합 대시보드에서 퀴즈·과제·게시판 참여 현황을 한눈에 확인해요.

### ✋ 실습① 내 첫 화면 만들기 (10분)

1. 배움터 첫 화면 오른쪽 위 **[위젯 편집하기]**
2. 에듀테크 서비스 칸의 **[수정하기]**에서 자주 쓸 서비스 4개를 앞으로
3. AI 서비스 하나(**코들** 또는 **자작자작**)에 들어가 보기
4. 패들렛 **1 배움터** 칸의 실습① 글에 댓글로 **'고른 서비스 + 쓸 수업'** 남기기

## 3. 2부 경북형 웍스AI

### 화면 구성

- **입력창**: 질문을 쓰고, **+ 단추**로 파일(PDF·한글 등)을 올려요.
- **모델 선택 · 생각의 깊이**: 기본 모델로도 충분하고, 어려운 문제는 생각의 깊이를 올려요.
- **오른쪽 위 도구 메뉴**: 에이전트, 워크플로우, 이미지, 비디오, 회의록, 슬라이드, 문서 번역, 문서 작성

### 에이전트란?

**업무에 맞춘 AI 동료**예요. 지시문과 도구를 미리 넣어 둔 AI라서, 긴 요청문 없이 **카드를 눌러 바로 시작**할 수 있어요. 에이전트 화면에는 세 개의 탭이 있어요.

| 탭 | 들어 있는 것 |
| --- | --- |
| 웍스 공식 에이전트 | **우리 업무 맞춤존**(가정통신문·행사 알리미, 민원 답변 도우미, 과세특·평어 작성기, 행발·창체 작성기, 통계로 수업하기, 수업·자율시간 설계사 등), 문서·글쓰기 스튜디오, 크리에이티브·홍보 스튜디오 등 |
| 경상북도교육청 에이전트 | **업무**(법령 검색, 개인정보 Q&A, AI 청렴 등) / **자체 제작**(학교는 가볍게 업무비서·행정실 비서, 가정통신문 검토 등) |
| 나만의 에이전트 | 자주 쓰는 지시문을 내가 직접 저장 |

### 업무 효율화① 가정통신문·행사 알리미

📍 웍스 공식 에이전트 › 우리 업무 맞춤존 › **가정통신문·행사 알리미**

- 문서번호부터 회신란(동의서)까지 표준 서식
- 학부모용·학생용·알림장용을 한 번에
- 날짜·비용·준비물은 꼭 직접 확인

```prompt 가정통신문 요청문 (빈칸 채우기)
[행사 이름] 가정통신문을 써 줘.
- 날짜와 시간:
- 장소:
- 대상 학년:
- 준비물과 비용:
- 회신(동의서) 필요 여부:
학부모용 가정통신문과 학생 알림장용 짧은 글, 두 가지로 써 줘.
```

> 💡 빈칸 재료가 없으면 *실습 재료(가상 자료)* 파일의 **A. 가정통신문 재료**를 붙여 넣어요. 경상북도교육청 탭의 **가정통신문** 에이전트로 발송 전 규정·문법 검토도 할 수 있어요.

### 업무 효율화② 공문 요약과 민원 답변

📍 문서·글쓰기 스튜디오 › **요약·정리의 달인** — **+ 단추**로 공문 PDF·한글 파일을 올려요.

```prompt 긴 공문 3줄 요약
올린 공문을 담임교사 입장에서 정리해 줘.
1) 3줄 요약
2) 내가 해야 할 일과 마감일
3) 학생·학부모에게 안내할 내용
```

> 💡 연습용으로 **요약 실습용 가상 공문(PDF)** 을 내려받아 올려 보세요. 결과에 나온 마감일이 원문과 맞는지 꼭 대조해요.

📍 우리 업무 맞춤존 › **민원 답변 도우미** — 실제 법령명과 조 번호를 인용해 공감→근거→안내 구조로 답을 써 줘요.

```prompt 학부모 민원 답변 초안
초등학교 학부모 민원에 답하는 글 초안을 써 줘.
- 민원 요지:
- 학교가 이미 한 조치:
- 앞으로 할 조치:
공감 → 근거 → 안내 순서로, 정중하고 짧게.
```

> ⚠ 민원인 이름·연락처, 학생 이름은 **지우고** 넣어요. 법령 근거는 국가법령정보센터에서 한 번 더 확인해요.

### 업무 효율화③ 경상북도교육청 에이전트

📍 에이전트 › **경상북도교육청 에이전트** 탭

- **학교는 가볍게 업무비서**: 번호만 고르면 기안문·계획서를 한글 파일로 만들어 줘요. 답마다 경북교육청 「학교업무 길라잡이 1000」 근거 쪽을 붙여요.
  순서: ① 메뉴 보기 → ② 내 업무 고르기 → ③ 번호 보내고 파일 받기
- **학교는 가볍게 행정실 비서**: 지출·계약·예산 업무 처리 순서
- **업무** 탭: 국가법령정보 법령 검색, 개인정보 Q&A, AI 청렴 에이전트

### 업무 효율화④ 대화 예약과 문서 번역

- **대화 예약**: 에이전트 화면 아래 *+ 대화 예약 추가*. 반복 업무를 정해진 시간에 자동으로 실행해요. (예: 매주 월요일 학년 알림장 초안)
- **문서 번역 · 만능 번역가**: 가정통신문을 학부모 모국어로 번역해 함께 보내요. 번역문은 가능하면 그 언어를 쓰는 분께 한 번 확인받아요.

### ✋ 실습② 내 업무 하나 줄이기 (10분)

1. 패들렛에 적은 **'시간 많이 드는 업무'** 를 알맞은 에이전트에 맡기기
2. 결과를 그대로 쓰지 말고 **고칠 곳 1군데** 찾기
3. 잘 된 요청문은 패들렛 **2 웍스AI 업무** 칸에 공유하기

### 수업 활용① 수업·자율시간 설계사

📍 우리 업무 맞춤존 › **수업·자율시간 설계사** — 2022 개정 교육과정 학교자율시간 운영계획을 차시별 표, 성취기준 연계, 과정 중심 평가까지 만들어요.

```prompt 학교자율시간 운영계획
초등 [학년] 학교자율시간 [주제] [차시 수]차시 운영계획을 짜 줘.
차시별 활동, 관련 성취기준, 과정 중심 평가 계획을 표로.
```

```prompt 예시 — 5학년 우리 고장 AI 탐험대
초등 5학년 학교자율시간 '우리 고장 AI 탐험대' 8차시 운영계획을 짜 줘.
차시별 활동, 관련 성취기준, 과정 중심 평가 계획을 표로.
```

> ⚠ 성취기준 코드는 교육과정 문서와 대조해 확인해요.

### 수업 활용② 통계로 수업하기

📍 우리 업무 맞춤존 › **통계로 수업하기** — 통계청(KOSIS)·한국은행 실제 통계로 표와 차트를 만들고, 성취기준·3단계 탐구 질문·교사용 가이드가 든 활동지로 만들어요.

```prompt 실제 통계로 활동지 만들기
초등 [학년] [교과] 수업용으로, [우리 지역] 인구 변화를 그래프로 탐구하는 활동지를 만들어 줘.
탐구 질문 3단계와 교사용 지도 도움말도 함께.
```

> ⚠ 숫자는 통계청(KOSIS) 원본과 한 번 대조해요.

### 수업 활용③ 그림 스튜디오와 슬라이드

📍 크리에이티브·홍보 스튜디오 › **그림 스튜디오** — 클립아트·2D 애니메이션·실사 중 골라 수업용 그림을 만들어요. 빠른 도구의 **슬라이드**나 **파워포인트 설계사**로 발표 자료도 만들 수 있어요.

```prompt 수업용 그림 만들기
초등 [학년] [교과] 수업 자료에 넣을 그림을 만들어 줘.
장면:
스타일: 흰 배경 클립아트 / 2D 애니메이션 / 실사 중 하나
글자는 넣지 말아 줘.
```

> ⚠ 실제 인물·캐릭터를 닮게 만들지 않아요. AI 그림은 글자가 깨지기 쉬우니 글자는 따로 넣어요.

### 수업 활용④ 평어 작성 도우미

📍 우리 업무 맞춤존 › **과세특·평어 작성기 / 행발·창체 작성기** — NEIS 글자 수, 금지 표현, ~함/~임 종결 규칙이 들어 있고 우수·보통·기초 3수준 초안을 만들어요.

```prompt 평어 초안 (관찰 사실만 익명으로)
초등 [학년] [교과] 평어 초안을 써 줘.
- 성취기준:
- 관찰한 학생 모습(익명):
우수·보통·기초 세 수준으로, NEIS 글자 수에 맞게.
```

> ⚠ 학생 이름·성적은 넣지 않아요. 학교생활기록부는 **교사가 관찰한 사실**에 근거해야 하므로 AI가 쓴 평어를 그대로 붙여 넣지 말고, 초안을 참고해 직접 고쳐 써요. 연습할 때는 *실습 재료*의 **D. 익명 관찰 기록**을 쓰세요.

### 나만의 에이전트 만들기

공식 에이전트를 써 보다가 **같은 말을 자주 덧붙이게 되면**, 그 지시문을 *나만의 에이전트*로 저장해 단추 하나로 써요.

- 예시 1: 우리 학년 알림장 말투
- 예시 2: 학급 신문 기사 다듬기
- 예시 3: 수업 나눔 협의록 정리

### ✋ 실습③ 수업 자료 하나 만들기 (10분)

1. 다음 주 수업 **한 차시** 고르기
2. 웍스AI로 **활동지 또는 퀴즈 문항 5개** 만들기
3. 패들렛 **3 웍스AI 수업** 칸에 결과 캡처 올리기

## 4. 3부 웍스AI → 배움터, 수업으로 잇기

![웍스AI로 초안을 만들고, 교사가 검토한 뒤, 배움터 코들·띵커벨로 수업하고, 대시보드로 참여 현황을 확인하는 4단계](/images/gb-aischool-worksai/flow.svg)

### ✋ 실습④ 두 도구를 이어서 쓰기 (10분)

1. 웍스AI에 확인 문제를 요청해요.

```prompt 확인 문제 5개 만들기
초등 [학년] [단원] 확인 문제 5개를 만들어 줘. 객관식 3개와 서술형 2개, 정답과 해설 포함.
```

2. 정답과 문장을 **교사가 확인하고 고쳐요.**
3. 배움터 › **코들**(자동 채점) 또는 **띵커벨·퀴즈앤**(퀴즈 참여)에 옮겨요.
4. 수업 뒤 배움터 **학습 분석 대시보드**에서 참여 현황을 확인해요.

## 5. 닫기 — AI 안전하게 쓰는 5가지

1. 학생 **이름·주민번호·연락처·성적**은 넣지 않기
2. AI 결과는 **초안**, 최종 책임은 교사
3. 법령·통계·사실은 **출처를 한 번 더** 확인
4. 생기부 문장은 **관찰 사실**을 바탕으로 직접 고쳐 쓰기
5. 학생이 쓰는 서비스는 학교 **개인정보 동의 절차** 확인
