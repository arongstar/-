학부모용 가정통신문과 학생 알림장용 짧은 글, 두 가지로 써 줘.

2) 요약·정리의 달인 (문서·글쓰기 스튜디오, + 단추로 공문 올리기)

4) 경상북도교육청 에이전트 > 학교는 가볍게 업무비서
메뉴 보기 → 내 업무 고르기 → 번호 보내고 한글 파일 받기

[실습③] 웍스AI로 수업 자료 만들기
---------------------------------
5) 수업·자율시간 설계사 (우리 업무 맞춤존)
초등 [학년] 학교자율시간 [주제] [차시 수]차시 운영계획을 짜 줘.
차시별 활동, 관련 성취기준, 과정 중심 평가 계획을 표로.

6) 통계로 수업하기 (우리 업무 맞춤존) — 숫자는 KOSIS 원본과 대조
초등 [학년] [교과] 수업용으로, [우리 지역] 인구 변화를 그래프로 탐구하는 활동지를 만들어 줘.
탐구 질문 3단계와 교사용 지도 도움말도 함께.

7) 그림 스튜디오 (크리에이티브·홍보 스튜디오)
초등 [학년] [교과] 수업 자료에 넣을 그림을 만들어 줘.
장면:
스타일: 흰 배경 클립아트 / 2D 애니메이션 / 실사 중 하나
글자는 넣지 말아 줘.

8) 과세특·평어 작성기 / 행발·창체 작성기 — 관찰 사실만 익명으로
초등 [학년] [교과] 평어 초안을 써 줘.
- 성취기준:
- 관찰한 학생 모습(익명):
우수·보통·기초 세 수준으로, NEIS 글자 수에 맞게.

[실습④] 웍스AI → 배움터(코들·띵커벨)
-------------------------------------
9) 확인 문제 만들기
초등 [학년] [단원] 확인 문제 5개를 만들어 줘. 객관식 3개와 서술형 2개, 정답과 해설 포함.
→ 교사가 정답 확인 → 배움터 > 코들 또는 띵커벨·퀴즈앤에 옮기기 → 대시보드에서 참여 확인

AI 안전하게 쓰는 5가지
----------------------
1. 학생 이름·주민번호·연락처·성적은 넣지 않기
2. AI 결과는 초안, 최종 책임은 교사
3. 법령·통계·사실은 출처를 한 번 더 확인
4. 생기부 문장은 관찰 사실을 바탕으로 직접 고쳐 쓰기
5. 학생이 쓰는 서비스는 학교 개인정보 동의 절차 확인
