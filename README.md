# 디지털·AI 연수 교안 사이트

초등 선생님 대상 디지털·AI 연수 교안을 모아 두는 사이트입니다.

- **교안 목록**: 검색, 주제(태그)별로 거르기
- **교안 보기**: 목차, 글자 크게/작게(발표용), 인쇄, QR 코드 공유
- **예시 프롬프트**: 하나씩 [복사] / [.txt 받기], 교안 전체 프롬프트 한 번에 받기
- **자료 내려받기**: 활동지·한글 파일·PDF 등 첨부, 구글 드라이브 링크도 가능
- **사이트 모음**: 교안에서 소개한 사이트를 분류별로 모아 보기, "학생 활동 가능"만 거르기
- **교안 PDF**: 배포할 때 교안마다 A4 PDF가 자동으로 만들어져요. 표지에 연수 정보와 강사 정보, 온라인 교안 QR이 들어가요. (강사비 제출용)

---

## 교안 추가·수정하는 법 (GitHub 웹에서, 프로그램 설치 없이)

모든 내용은 파일로 관리합니다. `main` 브랜치에 저장(commit)하면 1~2분 뒤 사이트에 자동으로 반영돼요.

### 1) 새 교안 만들기

1. `src/content/lessons/_템플릿.md` 파일을 열어 내용을 복사합니다.
2. `src/content/lessons` 폴더에서 **Add file → Create new file** 을 누릅니다.
3. 파일 이름을 정합니다. 영문·숫자·하이픈을 추천해요. 예: `2026-12-ai-assessment.md`
   이 이름이 주소가 됩니다. 예: `…/lessons/2026-12-ai-assessment`
4. 복사한 템플릿을 붙여 넣고 고친 뒤, 맨 위의 `draft: true` 를 `draft: false` 로 바꾸고 저장합니다.

교안 맨 위 `---` 사이의 정보는 아래와 같습니다.

| 항목 | 설명 |
| --- | --- |
| `title` | 교안 제목 |
| `summary` | 목록에 보일 짧은 소개 |
| `date` | 날짜 (예: `2026-12-01`). 최신 날짜가 목록 맨 앞에 와요. |
| `audience`, `duration` | 대상, 연수 시간 |
| `tags` | 주제 태그. 목록 페이지에서 이 태그로 거를 수 있어요. |
| `materials` | 내려받을 자료 목록 (아래 2번 참고) |
| `sites` | 이 교안에서 소개하는 사이트의 id (아래 3번 참고) |
| `draft` | `true` 면 사이트에 안 보임 (작성 중일 때) |

### 예시 프롬프트 넣기

본문에 아래처럼 쓰면 **[복사] [.txt 받기]** 버튼이 달린 프롬프트 카드가 됩니다.
교안 오른쪽 상자에 프롬프트 목록과 **전체 받기** 버튼이 자동으로 생겨요.

````markdown
```prompt 가정통신문 초안
너는 초등학교 3학년 담임교사야.
학부모 상담 주간 안내 가정통신문을 써 줘.
```
````

`prompt` 다음에 쓴 글이 카드 제목이 됩니다.

### 교안을 보기 좋게 쓰는 기호

| 이렇게 쓰면 | 이렇게 보여요 |
| --- | --- |
| `> 💡 ...` | 초록 **도움말** 상자 |
| `> ⚠ ...` | 노란 **주의** 상자 |
| `> 📌 ...` | 파란 **안내** 상자 |
| `### ✋ 실습① ...` | 다음 제목 전까지 **실습 카드**로 묶이고, 번호 목록은 동그라미 단계로 |
| `📍 메뉴 › 하위 메뉴` | 메뉴 위치 표시 |
| 첫 칸이 `시간`인 표 | 진행표 모양 |
| `cover: /images/...jpg` (맨 위 정보) | 목록 카드와 교안 머리에 대표 그림 |

### 2) 다운로드 자료 올리기

1. `public/files` 폴더 안에 교안별 폴더를 만들어 파일을 올립니다.
   (GitHub에서 **Add file → Upload files**, 끌어다 놓기 가능)
   예: `public/files/2026-12-ai-assessment/활동지.hwp`
2. 교안의 `materials` 에 경로를 적습니다. 경로는 `/files/` 로 시작해요.

```yaml
materials:
  - title: 평가 활동지
    file: /files/2026-12-ai-assessment/활동지.hwp
    description: 한글 파일
  - title: 발표 자료
    file: https://docs.google.com/presentation/d/...   # 외부 링크도 됩니다
```

> 큰 파일(수십 MB 이상, 영상 등)은 구글 드라이브에 올리고 링크로 연결하는 것을 추천해요. (GitHub은 파일 하나당 100MB 제한)

### 교안에 이미지 넣기

1. `public/images/교안이름/` 폴더에 그림 파일을 올립니다. (jpg·png·svg, 1장에 500KB 이하 권장)
2. 본문에 아래처럼 씁니다. `[ ]` 안의 글은 그림을 설명하는 대체 글이에요.

```markdown
![AI 조수가 파일을 정리하는 모습](/images/ai-agent-automation/hero.jpg)
```

### 3) 사이트 모음에 사이트 추가하기

`src/data/sites.yaml` 파일 맨 아래에 이어서 씁니다.

```yaml
- id: padlet                 # 영문 고유 이름 (교안의 sites: 에 이 id를 씀)
  name: Padlet
  url: https://padlet.com
  category: 협업·소통         # 같은 분류끼리 묶여 보여요
  description: 온라인 협업 게시판
  use: 학생 활동 가능          # "교사용" 또는 "학생 활동 가능"
  note: 무료 요금제는 보드 수 제한이 있어요.   # (선택) 주의 사항
```

분류가 보이는 순서는 `src/site.config.ts` 의 `CATEGORY_ORDER` 에서 바꿀 수 있어요.
PDF 표지의 강사 정보(이름·소속)도 같은 파일의 `INSTRUCTOR` 에서 고쳐요. 이 정보는 사이트 화면에는 나오지 않아요.
사이트 제목·소개 문구도 같은 파일에서 고칩니다.

## 처음 한 번만: 사이트 공개(배포) 설정

1. 이 저장소의 **Settings → Pages** 에서 **Source** 를 **GitHub Actions** 로 바꿉니다.
2. 작업 내용이 `main` 브랜치에 들어가면 자동으로 배포됩니다. (**Actions** 탭에서 진행 상황 확인)
3. 주소는 `https://<GitHub아이디>.github.io/<저장소이름>/` 입니다.
   나만의 도메인을 연결하려면 Settings → Pages → Custom domain 에 입력하세요.

> 저장소 이름을 바꾸면 사이트 주소도 바뀝니다. 연수에서 안내하기 전에 이름을 정해 두세요.
> 지금 이름은 `-` 이라서 주소가 `…github.io/-/` 가 됩니다. `ai-training` 처럼 알아보기 쉬운 이름을 추천해요.

## 내 컴퓨터에서 미리 보기 (선택)

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:4321 을 엽니다.

## 폴더 구조

- `apps-script/` : Apps Script 웹앱 4종의 원본 코드와 테스트. 코드를 고친 뒤 `python3 apps-script/package.py` 로 내려받기용 zip 을 다시 만들고, `node apps-script/test/test-B.cjs` 처럼 테스트할 수 있어요.

```
src/content/lessons/   교안 (.md 파일 하나 = 교안 하나)
src/data/sites.yaml    사이트 모음
public/files/          내려받을 자료
src/site.config.ts     사이트 제목, 소개 문구, 분류 순서
src/pages, layouts, components, styles   화면 구성 (보통 고칠 일 없음)
```

## 나중에 할 일: 접근 관리

지금은 주소를 아는 사람은 누구나 볼 수 있습니다. 나중에 아래 방법 중 하나로 막을 수 있어요.

- **Cloudflare Pages + Cloudflare Access**: 이메일 인증이나 비밀번호를 통과한 사람만 보기 (무료 범위 있음)
- **연수별 비밀번호 페이지**: 간단하지만 보안이 약함
- **로그인 기능이 있는 서버로 옮기기** (예: Supabase 등): 관리자 페이지에서 교안을 올리는 기능까지 가능

참고: GitHub Pages는 무료 요금제에서 **공개 저장소**만 지원하므로, 저장소의 파일(교안 원본)도 공개됩니다.
